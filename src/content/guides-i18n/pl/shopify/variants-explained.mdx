## Jak Shopify zapisuje warianty w pliku CSV

W pliku CSV produktów Shopify produkt z wieloma wariantami to **kilka wierszy z tym samym Handle**. Pierwszy wiersz jest „nadrzędny” – zawiera dane produktu. Każdy kolejny wiersz z tym samym Handle to wiersz wariantu.

### Minimalny przykład: koszulka w dwóch rozmiarach

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Variant SKU,Image Src
blue-shirt,Blue T-Shirt,Size,Small,19.99,BLUE-SM,https://cdn.example.com/shirt.jpg
blue-shirt,,Size,Medium,21.99,BLUE-MD,
```

Na co zwrócić uwagę:
- Oba wiersze mają Handle `blue-shirt`.
- Drugi wiersz ma puste Title, puste Image Src i nową wartość Option1 Value.
- Każdy wiersz to jeden wariant, który można kupić (jedna kombinacja wartości opcji).

---

## Wiersz nadrzędny

Pierwszy wiersz danego Handle to wiersz nadrzędny. Ustala pola produktu:

| Kolumna | Wymagana w nadrzędnym | Uwagi |
|---|---|---|
| Handle | Tak | Unikalny identyfikator produktu; małe litery, tylko myślniki |
| Title | Tak | Nazwa produktu |
| Body HTML | Nie | Opis produktu; potrzebny tylko w wierszu nadrzędnym |
| Vendor | Nie | Nazwa marki |
| Type | Nie | Typ produktu (dla kolekcji) |
| Tags | Nie | Tagi oddzielone przecinkami |
| Published | Nie | TRUE lub FALSE |
| Option1 Name | Tak (przy opcjach) | Nazwa pierwszej opcji (np. „Size”) |
| Option1 Value | Tak (przy opcjach) | Wartość pierwszego wariantu (np. „Small”) |
| Image Src | Nie | Adres URL głównego zdjęcia |

**Wiersz nadrzędny musi mieć Title.** Jeśli Title jest puste, Shopify nie rozpozna go jako nadrzędnego i import może dać błędne wyniki.

---

## Wiersze wariantów

Każdy wiersz po pierwszym z tym samym Handle to wiersz wariantu. Wiersze wariantów:
- Mają ten sam Handle co wiersz nadrzędny.
- Mają puste Title (albo to samo – Shopify ignoruje je poza wierszem nadrzędnym).
- Mają własną wartość Option1 Value (oraz Option2 Value, Option3 Value, jeśli są).
- Mają własne Variant Price, Variant SKU, Variant Inventory Qty itd.

### Kolumny dotyczące wariantu

| Kolumna | Uwagi |
|---|---|
| Variant Price | Wymagana dla każdego wariantu; liczba dziesiętna (bez symbolu waluty) |
| Variant SKU | Opcjonalna, ale mocno zalecana; musi być unikalna w całym sklepie |
| Variant Grams | Waga w gramach |
| Variant Inventory Qty | Początkowy stan magazynowy |
| Variant Inventory Policy | `deny` lub `continue` (continue = sprzedaż bez stanu) |
| Variant Fulfillment Service | Zwykle `manual` |
| Variant Requires Shipping | TRUE lub FALSE |
| Variant Taxable | TRUE lub FALSE |
| Variant Barcode | EAN, UPC lub inny kod kreskowy |

## Kilka opcji (rozmiar I kolor)

Shopify obsługuje do trzech opcji za pomocą kolumn Option1, Option2 i Option3.

Przykład: koszulka z rozmiarem i kolorem

```
Handle,Title,Option1 Name,Option1 Value,Option2 Name,Option2 Value,Variant Price,Variant SKU
blue-shirt,Blue T-Shirt,Size,Small,Color,Blue,19.99,BLUE-SM-BLU
blue-shirt,,Size,Small,Color,Red,19.99,BLUE-SM-RED
blue-shirt,,Size,Medium,Color,Blue,21.99,BLUE-MD-BLU
blue-shirt,,Size,Medium,Color,Red,21.99,BLUE-MD-RED
```

- Option1 Name i Option2 Name wystarczy podać w wierszu nadrzędnym (pierwszym dla danego Handle). Powtarzanie ich w wierszach wariantów nie szkodzi.
- Każda kombinacja opcji potrzebuje osobnego wiersza.
- Produkt z 3 rozmiarami i 4 kolorami wymaga 12 wierszy wariantów.

## Typowe błędy

### Błąd 1: różne Handle dla tego samego produktu

**Objaw:** Coś, co powinno być jednym produktem z wariantami, po imporcie pojawia się jako kilka osobnych produktów.

**Rozwiązanie:** Wszystkie wiersze jednego produktu muszą mieć dokładnie ten sam Handle. Literówka (`blue-shirt` zamiast `blue-shirt-`) sprawia, że Shopify tworzy nowy produkt.

### Błąd 2: Title w każdym wierszu

**Objaw:** Import się udaje, ale Shopify tworzy zduplikowane produkty albo traktuje wiersze wariantów jako osobne produkty.

**Rozwiązanie:** Tylko pierwszy wiersz danego Handle powinien mieć Title. W wierszach wariantów zostaw Title puste.

### Błąd 3: brak kolumny Option1 Name

**Objaw:** Błąd importu „Option1 Name is required” albo wszystkie warianty pojawiają się jako jedna opcja „Default Title”.

**Rozwiązanie:** Zawsze dodawaj `Option1 Name` do nagłówka i wpisz wartość przynajmniej w wierszu nadrzędnym. Jeśli produkt nie ma prawdziwych opcji, ustaw Option1 Name na `Title`, a Option1 Value na `Default Title`.

### Błąd 4: wartości opcji różnią się między wierszami

**Objaw:** Shopify tworzy więcej wariantów niż powinien albo nazwy opcji się dublują.

**Rozwiązanie:** Option1 Name musi być dokładnie takim samym tekstem we wszystkich wierszach danego Handle. Jeśli wiersz nadrzędny ma `Size`, każdy wiersz wariantu też musi mieć `Size` (albo pozostać pusty). Mieszanie `Size`, `size` i `Sizes` daje niespójne dane opcji.

### Błąd 5: puste Variant Price

**Objaw:** Import kończy się błędem „Variant Price is required” albo warianty dostają cenę 0.00.

**Rozwiązanie:** Variant Price jest wymagane w każdym wierszu. Nie ma dziedziczenia – nawet jeśli wszystkie warianty mają tę samą cenę, każdy wiersz musi ją podać.

### Błąd 6: dodanie nowego wariantu nadpisuje istniejące

**Objaw:** Po częściowym imporcie (dodaniu jednego nowego wariantu) wszystkie pozostałe warianty znikają.

**Rozwiązanie:** Aktualizując produkt importem CSV, musisz umieścić w pliku **wszystkie** istniejące warianty, a nie tylko nowy. Import Shopify zastępuje cały zestaw wariantów danego Handle. Pominięte warianty zostaną usunięte.

## Wskazówki dla dużych katalogów

- **Generuj wiersze wariantów automatycznie.** Dla produktów z wieloma kombinacjami (3 rozmiary × 4 kolory × 2 materiały = 24 wiersze) użyj formuły w arkuszu lub skryptu zamiast wpisywać je ręcznie.
- **Stosuj spójne wzorce SKU.** SKU w stylu `BAZA-ROZMIAR-KOLOR` (np. `SHIRT-SM-BLU`) ułatwia rozpoznawanie i sortowanie wariantów.
- **Najpierw przetestuj na jednym produkcie.** Zaimportuj jeden produkt (wiersz nadrzędny i wszystkie warianty), zanim prześlesz cały katalog. Sprawdź strukturę wariantów w panelu Shopify, zanim przejdziesz dalej.
