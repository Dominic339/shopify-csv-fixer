## 为什么会这样

Excel 是为财务数据设计的。当单元格的值看起来像数字时，它就会把它转换为数字格式。这会给电商 CSV 文件带来两个问题：

1. **科学计数法**：像 `4006381333931` 这样的 13 位 EAN 条形码会变成 `4.00638E+12`。导出为 CSV 时，写入的就是 `4.00638E+12`，这不是有效的条形码。
2. **前导零丢失**：像 `00714` 这样的 SKU 会变成 `714`，像 `01234565` 这样的 8 位 EAN-8 会变成 `1234565`。导入平台收到的是错误的值。

这些转换是悄无声息地发生的。你可能要等到导入失败或库存对不上时才会发现。

---

## 受影响的字段

任何包含较长数字串或前导零的字段都有风险：

- **条形码**：EAN-13、UPC-A、EAN-8、ISBN-13、ASIN
- 带前导零的 **SKU**（在服装和五金类目录中很常见）
- 沿用制造商零件编号的 **多属性 SKU**
- Shopify 的 **Variant Barcode** 列
- **Amazon ASIN / FNSKU**（字母数字混合，但部分只含数字）
- WooCommerce 的 **SKU** 列

## 预防：输入数据前先把列设为文本格式

最安全的做法是在列中输入或粘贴任何内容之前，先把它设为 **文本** 格式。

### 在 Excel 中（新表格）

1. 选中将要存放条形码或 SKU 的整列（例如点击列标 `C` 选中 C 列）。
2. 右键 → **设置单元格格式**。
3. 在 **分类** 列表中选择 **文本**。
4. 点击 **确定**。
5. 现在再输入或粘贴数值。Excel 会把它们当作文本，原样保留。

> **重要**：在输入数字*之后*再把单元格设为文本格式，并不能撤销转换。必须先设置格式，再输入数据。如果粘贴到预先设好格式的列中，请 **只粘贴值**（Ctrl+Shift+V 或 选择性粘贴 → 值），以免把源数据的数字格式也带进来。

### 在 Excel 中（在前面加撇号）

对个别单元格的快速办法：在数字前输入一个撇号（`'`）：

```
'4006381333931
```

Excel 会把所有以 `'` 开头的值当作文本。撇号不会保存在单元格的值中，保存的只有数字。这种方法适合逐个单元格处理，但数据量大时很繁琐。

## 修复已有文件：用导入向导打开 CSV

如果你已经有一个条形码被 Excel 弄坏的 CSV，请使用导入向导，而不是双击打开文件：

### Excel 2016 及更高版本（获取和转换）

1. 打开一个空白工作簿。
2. 选择 **数据 → 从文本/CSV**。
3. 选择你的 CSV 文件。
4. 预览对话框会打开。查看条形码或 SKU 列。如果显示为科学计数法，说明类型被自动识别成了"整数"。
5. 点击 **转换数据**（会打开 Power Query 编辑器）。
6. 选中受影响的列。
7. 在 **主页** 选项卡的 **数据类型** 下拉列表中选择 **文本**。Power Query 询问时，点击 **替换当前转换**，这样类型更改会取代自动的数字转换，原始数字得以保留。
8. 关闭并上载。
9. 通过 **文件 → 另存为 → CSV UTF-8** 重新导出为 CSV。

### Excel（旧版文本导入向导）

如果你可以使用旧版向导：

1. 选择 **数据 → 自文本**，或者把文件扩展名从 `.csv` 改为 `.txt`，再通过 **文件 → 打开** 打开，这样就会启动向导。
2. 在向导的 **第 3 步** 中选中该列，把数据格式设为 **文本**。
3. 完成导入。

## 修复已保存 CSV 中的科学计数法

如果你已经有一个包含 `4.00638E+12` 这类数值的 CSV 文件：

### 方案 A：重新输入数值（小文件）

一旦 CSV 文件本身写入了 `4.00638E+12`，缺失的数字就已经不在文件中了，任何文本编辑器都无法恢复。你只能根据自己的记录重新输入正确的值，这最多适用于少数几行。

### 方案 B：从源头重建

如果原始数据在数据库、PIM 或供应商文件中，请在不经 Excel 打开的情况下重新导出。很多供应商门户都支持下载 `.xlsx`。打开它，把相关列设为文本格式，然后另存为 CSV。

### 方案 C：用公式还原

如果工作簿仍在 Excel 中打开（或保存为 .xlsx），Excel 可能仍保存着完整的数字（例如 `4006381333931`），只是以科学计数法显示：

1. 添加一个辅助列。
2. 使用 `=TEXT(A2, "0")` 把数字转换为没有科学计数法的文本。
3. 复制辅助列，以 **值** 的形式粘贴覆盖原列。
4. 删除辅助列。
5. 另存为 CSV。

> 只有在 Excel 仍保存着完整数字时，这种方法才有效。如果数值已被截断（超过 15 位有效数字），精度就永久丢失了，你必须从原始来源重新获取数据。

## Google 表格中的对应做法

Google 表格也有同样的数字转换问题：

- **粘贴前设为纯文本**：选中该列 → **格式 → 数字 → 纯文本**。
- **通过 文件 → 导入 导入**：在导入对话框中取消勾选 **将文本转换为数字、日期和公式**，让编码保持为文本，导入后再确认条形码显示正确。
- **修复已有数值**：和 Excel 一样使用 `=TEXT(A2, "0")`。

---

## 安全地从 Excel 导出为 CSV

在修复列或正确设置格式之后：

1. **文件 → 另存为 → CSV UTF-8（逗号分隔）(.csv)**。
2. Excel 可能会提示该格式不支持多个工作表。点击 **是/保留当前格式**。
3. **不要为了检查而在 Excel 中重新打开 CSV**：请使用文本编辑器（VS Code、Notepad++）确认条形码是普通数字，而不是科学计数法。
