## 什么是重复的表头行？

重复的表头行是指 CSV 的第一行（列名）又出现在数据区域的某个位置。例如：

```
Handle,Title,Vendor,Variant Price
blue-shirt,Blue T-Shirt,Acme,19.99
Handle,Title,Vendor,Variant Price   ← 重复的表头行
red-shirt,Red T-Shirt,Acme,21.99
```

导入工具在数据行中遇到 `Handle` 时，无法把这一行读成商品。大多数平台会静默跳过这一行，或报告格式错误。有些平台会把它算作失败的行。

---

## 为什么会出现重复表头

### 合并了多个导出文件

最常见的原因是在 Excel 或 Google 表格中复制粘贴来合并两个 CSV。第二个文件的表头行就落在了合并后文件的中间。

### 分页导出

有些平台按页导出数据（例如每个文件 500 行）。如果把所有页面下载下来再拼接，每个文件的表头行也会被一起拼进去。

### 定时报表系统

每天向 CSV 追加行的自动系统，有时会在每个追加块的开头重复表头。

### Excel 的“全部刷新”或 Power Query 导出

在 Excel 中刷新数据连接时，如果查询配置有误，可能会再次插入表头行。

## 找出重复的表头行

### 在 Excel 中

1. 打开 CSV（为保留格式，请使用 **数据 → 从文本/CSV**，不要双击打开）。
2. 点击数据中的任意单元格。
3. 选择 **数据 → 筛选** 开启筛选。
4. 点击 **Handle** 列（或第一列）的箭头。
5. 在搜索框中准确输入表头名称（例如 `Handle`）。
6. 如果筛选结果中出现了行，这些就是重复的表头行。

### 在 Google 表格中

1. 选中所有数据（**Ctrl+A**）。
2. 选择 **数据 → 创建过滤器**。
3. 点击第一列的箭头。
4. 在过滤器的文本框中输入表头名称（例如 `Handle`）。
5. 所有显示该值的行都是重复表头。

### 用公式标记

在一个空列中，在每一行旁边加入下面的公式来标记重复项：

```
=IF(A2="Handle","DUPLICATE HEADER","")
```

把 `"Handle"` 换成你第一列的实际名称。按 `DUPLICATE HEADER` 筛选即可找到所有重复项。

## 删除重复的表头行

### 方法 1：筛选后删除（Excel / 表格）

1. 筛选第一列，只显示值为表头的行（例如 `Handle`）。
2. 选中所有可见的筛选结果行（点击第一个结果的行号，再按住 Shift 点击最后一个）。
3. 右键 → **删除行**。
4. 取消筛选（数据 → 清除筛选，或 过滤器 → 关闭）。
5. 检查数据是否完整。

### 方法 2：排序、删除、再排回原序（Excel）

排序会把所有重复的表头行集中到一起，但会改变商品的顺序，所以之后一定要排回原来的顺序。Shopify、WooCommerce 和 eBay 的文件都依赖行的顺序。

1. 添加一个辅助列，填入行号（1、2、3……）以记录原始顺序。
2. 按第一列从 A 到 Z 排序。
3. 重复的表头行现在会挨在一起，位于 `Handle` 按字母顺序落在你的值之间的位置（Excel 排序不区分大小写，所以请在以 H 开头的值之间查找）。
4. 选中这一组行并删除。
5. 按辅助列排序，恢复原始顺序。
6. 删除辅助列。

### 方法 3：文本编辑器（大文件）

对于 Excel 处理不了的大文件（约超过 100,000 行），请使用 VS Code 或 Notepad++：

**VS Code：**
1. 打开文件。
2. 按 **Ctrl+H**（查找和替换）。
3. 开启 **正则表达式** 模式（`.*` 图标）。
4. 在查找框中输入：`^Handle,Title,Vendor,Variant Price\r?\n`
   （换成你的实际表头，必要时进行转义）
5. 替换框留空。
6. 点击 **全部替换**。
7. 删除所有重复项后，手动把表头重新加为第一行。

> 使用正则表达式替换时要小心。务必保留原始文件作为备份，替换后检查表头是否恰好只出现一次。

**Notepad++（Windows）：**
1. 打开文件 → **搜索 → 替换**（Ctrl+H）。
2. 选择 **正则表达式** 模式。
3. 使用与上面 VS Code 相同的模式。
4. 全部替换，然后手动加回表头行。

## 删除重复表头之后

文件清理干净后：

1. 确认表头只在第 1 行出现一次。
2. 数一下行数。总数应等于原始行数减去删除的重复表头数。
3. 抽查重复项原来所在位置附近的几行，确认数据完整。
4. 另存为 **CSV UTF-8**（在 Excel 中：**文件 → 另存为 → CSV UTF-8**）。

---

## 下次合并时避免重复表头

手动合并多个 CSV 时：

1. 在 Excel 或表格中打开第一个文件（你的“基础”文件）。
2. 打开每个要追加的文件。
3. 复制数据之前，先 **删除追加文件的表头行**。
4. 只复制数据行。
5. 粘贴到基础文件的末尾。

如果用脚本自动合并 CSV，请始终跳过第一个文件之后每个文件的表头行。`csv.DictReader` 会把每个文件的表头读作列名，因此表头永远不会混入数据：

```python
# Python 示例：假设所有文件的列都相同
import csv

files = ["export_page1.csv", "export_page2.csv"]

with open("combined.csv", "w", newline="", encoding="utf-8") as outfile:
    writer = None
    for filename in files:
        # utf-8-sig 会去掉 BOM，否则 BOM 会改变第一列的名称
        with open(filename, newline="", encoding="utf-8-sig") as infile:
            reader = csv.DictReader(infile)
            if writer is None:
                writer = csv.DictWriter(outfile, fieldnames=reader.fieldnames)
                writer.writeheader()
            for row in reader:
                writer.writerow(row)
```

如果各文件的列不同，请使用合并两个 CSV 文件指南中的脚本，它会保留所有列。
