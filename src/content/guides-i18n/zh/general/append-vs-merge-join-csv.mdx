## 三种操作，三种含义

人们说"组合 CSV 文件"时，通常指的是三种不同操作中的一种。用错了操作，会导致数据丢失或结构错误。

| 操作 | 改变什么 | 行数 | 列数 |
|---|---|---|---|
| **追加** | 增加行 | 增加 | 不变 |
| **合并** | 把两个结构相同的文件合成一个 | 增加 | 不变 |
| **连接** | 从关联文件中添加列 | 不变 | 增加 |

---

## 追加：增加更多行

**作用**：把第二个 CSV 的行添加到第一个 CSV 的末尾。两个文件的列结构必须完全相同。

**适用场景**：
- 组合分页导出的文件（文件 1 = 第 1–500 行，文件 2 = 第 501–1000 行）。
- 在上传前把一批新商品添加到现有的目录文件中。
- 组合以相同格式导出的不同区域团队的文件。

**在 Excel 中正确追加的方法**：

1. 打开基础文件。
2. 打开第二个文件。
3. 在第二个文件中 **删除标题行**（右键点击第 1 行 → 删除）。
4. 选中剩余的全部数据（Ctrl+A，如果选多了就调整一下）。
5. 复制（Ctrl+C）。
6. 切换到基础文件，点击最后一行数据下方的第一个空单元格。
7. 粘贴（Ctrl+V）。
8. 另存为 CSV UTF-8。

**必须避免的严重错误**：跳过第 3 步（删除标题）会在文件中间产生重复的标题行，任何导入平台都会因此出错。

**在 Google 表格中追加的方法**：

步骤相同：删除第二个文件的标题行，只复制数据行，然后粘贴到基础工作表的底部。

## 合并：组合列相同的文件（来自多个来源）

**作用**：本质上和追加相同，但"合并"一词通常用于组合来自不同来源、代表同一类数据的文件（例如两个格式相同的供应商商品清单）。

**适用场景**：
- 把两个不同供应商的商品数据源组合成一个上传文件。
- 合并各部门使用同一平台 CSV 模板导出的文件。

**合并时（相比简单追加）需要额外注意的事项**：
- **检查重复行。** 如果两个文件中有同一个商品，合并后的文件中会出现两次。可以用 Handle（Shopify）、SKU（WooCommerce/Amazon）或 Item ID（eBay）来找出重复项。在 Excel 中：**数据 → 删除重复值**，然后选择键列。
- **统一列名。** 如果供应商 A 把某列叫作 `Barcode`，供应商 B 叫作 `UPC`，那么合并前需要统一为平台要求的列名。
- **统一数值。** 价格可能使用不同的货币，状态的写法也可能不同（Published、TRUE 或 1）。

## 连接：从关联文件中添加列

**作用**：把两个文件并排放置，根据共同的键列（例如 SKU 或 Handle）匹配行，把第二个文件中的列添加到第一个文件中。

**适用场景**：
- 你有一份来自 ERP 的商品清单（Handle、Title、SKU、Price）和一份单独的库存文件（SKU、Quantity、Warehouse Location），想把库存数量添加到每个商品行。
- 你从某个系统导出了不含图片的商品，另有一个按 SKU 对应的图片 URL 文件。
- 你想在导入前把供应商数据（成本价、供应商零件编号）添加到商品目录中。

### 在 Excel 中用 VLOOKUP 连接

假设：
- **文件 A**（基础）：A 列 = Handle，B 列 = Title，C 列 = Price
- **文件 B**（查找）：A 列 = Handle，B 列 = Quantity

你要把文件 B 中的 Quantity 添加到文件 A。

1. 在文件 A 中添加新的列标题：`Quantity`（在 D 列）。
2. 在 D2 中输入：
   ```
   =VLOOKUP(A2, '[FileB.csv]FileB'!$A:$B, 2, FALSE)
   ```
3. 文件 B 必须在 Excel 中打开。Excel 打开 CSV 时会用文件名给工作表命名，所以 `FileB.csv` 中的工作表叫作 `FileB`。如果键匹配，Quantity 就会填入。如果没有匹配，会显示 `#N/A`，表示该 Handle 不在文件 B 中。
4. 把公式向下复制到所有行。
5. 确认无误后，选中 D 列并复制，然后用 **选择性粘贴 → 值** 把公式替换为固定值。
6. 关闭文件 B。
7. 把文件 A 另存为 CSV UTF-8。

### 在 Google 表格中连接

用相同的语法使用 `VLOOKUP`。也可以用 `IMPORTRANGE` 从另一个 Google 表格中取数据，再使用辅助列。

### 用 Python 连接（大文件）

```python
import csv

# 把查找文件加载为以 Handle 为键的字典
lookup = {}
with open("inventory.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        lookup[row["Handle"]] = row["Quantity"]

# 把 Quantity 添加到基础文件
with open("products.csv", encoding="utf-8") as infile, \
     open("products_with_qty.csv", "w", newline="", encoding="utf-8") as outfile:
    reader = csv.DictReader(infile)
    fieldnames = reader.fieldnames + ["Quantity"]
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    writer.writeheader()
    for row in reader:
        row["Quantity"] = lookup.get(row["Handle"], "")
        writer.writerow(row)
```

## 组合 CSV 文件时的常见错误

### 错误 1：追加后出现重复的标题行

**症状**：导入在文件中间失败，报"无法识别的行"之类的错误。
**解决方法**：追加前，务必删除除第一个文件以外所有文件的标题行。

### 错误 2：追加的文件列顺序不同

**症状**：追加后数据出现在错误的列中。
**解决方法**：两个文件不仅列名要相同，列顺序也必须相同。如果文件 B 的列顺序不同，请在追加前把它的列调整为与文件 A 一致。

### 错误 3：用不唯一的键进行连接

**症状**：VLOOKUP 返回错误的数量（它取第一个匹配项，忽略重复项）。
**解决方法**：连接前，确保查找文件中的键列（SKU、Handle）是唯一的。使用 **数据 → 删除重复值**，或用 COUNTIF 检查。

### 错误 4：组合后编码不一致

**症状**：来自某个源文件的行出现乱码。
**解决方法**：组合前，把所有源文件都保存为 UTF-8。用 VS Code 重新编码任何不是 UTF-8 的文件（参见编码指南）。

### 错误 5：追加的各部分之间有空行

**症状**：导入在空行处停止，忽略之后的所有行。
**解决方法**：追加后，浏览组合后的文件，删除各部分之间出现的空行。

## 快速决策指南

```
需要更多行？ → 追加或合并
需要更多列？ → 连接

源文件来自同一系统且列完全相同？ → 追加
来自不同系统但列模板相同？ → 合并（检查重复项）
商品数据在一个文件中，补充数据在另一个文件中？ → 连接
```
