## Amazon 如何校验平面文件

Amazon 平面文件是以制表符或逗号分隔的 CSV 文件，必须遵循按商品分类定义的严格列结构。上传平面文件后，Amazon 会依次进行以下校验：

1. **模板匹配**：检查列标题是否与该文件类型的预期模板一致
2. **必填字段校验**：确认所有必填列都有值
3. **数据类型校验**：检查数字、布尔值和固定选项值
4. **业务规则**：校验 ASIN、SKU、状况代码和价格范围
5. **目录检查**：把商品编码与 Amazon 目录进行匹配

处理完成后，Amazon 会生成一份**处理报告**（在卖家平台的“库存”→“批量上传商品”中查看）。请务必查看处理报告，其中列出了每一个失败的行及具体错误。

---

## 错误：seller_sku 无效或缺失

**原因**：`seller_sku` 为空、超过 40 个字符、包含无效字符，或者与目录中已有的 SKU 重复。

**seller_sku 规则**：
- 最多 40 个字符
- 不能有空格（请用连字符或下划线）
- 字母和数字，以及 `-`、`_`、`.`
- 在整个 Amazon 卖家账户中必须唯一

**解决方法**：确保每一行都有唯一的 SKU。可以用 `=COUNTIF($A:$A, A2)` 这样的公式查找重复项。把超过 40 个字符的 SKU 缩短。

---

## 错误：缺少 item_name / 标题过长

**原因**：`item_name` 为空，或者超出了 Amazon 的标题长度限制（因分类而异，通常为 200–500 个字符）。

**解决方法**：
- 为每个商品行填写 `item_name`
- 在 Excel 中用 `=LEN(B2)` 找出超过分类限制的标题
- 在您使用的模板中确认确切的字符上限

---

## 错误：condition_type 无效

**原因**：`condition_type` 列中的值不在 Amazon 允许的列表中。

**可接受的值**：

| 值 | 说明 |
|---|---|
| `New` | 全新，原厂密封 |
| `UsedLikeNew` | 二手 – 几乎全新 |
| `UsedVeryGood` | 二手 – 非常好 |
| `UsedGood` | 二手 – 良好 |
| `UsedAcceptable` | 二手 – 可接受 |
| `CollectibleLikeNew` | 收藏品 – 几乎全新 |
| `CollectibleVeryGood` | 收藏品 – 非常好 |
| `CollectibleGood` | 收藏品 – 良好 |
| `CollectibleAcceptable` | 收藏品 – 可接受 |
| `Refurbished` | 卖家翻新 |
| `Club` | 会员版（媒体类） |

**解决方法**：把不符合标准的状况值替换为上表中的某个值。`New` 首字母必须大写，`new`（小写）会被拒绝。

---

## 错误：价格无效

**原因**：`price` 列中带有货币符号（`$`）、用逗号作小数点、为零、为负数或为空。

**Amazon 价格规则**：
- 普通小数：`19.99`
- 不带货币符号
- 必须为正数（大于 0）
- 用句点作小数点

**解决方法**：去掉货币符号，并把小数点逗号改为句点。保存前在 Excel 中把价格列设置为“数值”格式。

---

## 错误：fulfillment_center_id / 配送渠道无效

**原因**：配送渠道列中有无法识别的值。

**可接受的值**：

| 值 | 说明 |
|---|---|
| `DEFAULT` | 卖家自配送（FBM） |
| `AMAZON_NA`（或 `AMAZON`） | 亚马逊配送（FBA） |

确切的列名和可接受的值因平面文件模板而略有不同。请查看您使用的模板。

**解决方法**：FBM 使用 `DEFAULT`，FBA 使用 `AMAZON_NA` 或 `AMAZON`。不要使用 `FBA`、`FBM` 或其他简写。

---

## 错误：找不到 product_id / ASIN

**原因**：`product_id`（ASIN、UPC、EAN 或 ISBN）与 Amazon 目录中的任何商品都不匹配，或者 `product_id_type` 与所填编码的类型不符。

**product_id_type 的值**：

| 值 | 编码类型 |
|---|---|
| `1` | ASIN |
| `2` | ISBN |
| `3` | UPC |
| `4` | EAN |

**解决方法**：
- 确认商品编码正确，并且在 Amazon 目录中有效
- 让 `product_id_type` 与 `product_id` 中的编码类型一致
- 对于还没有 ASIN 的新商品，可能需要创建新的商品详情页，而不是向现有商品添加库存

---

## 错误：商品分类的模板不对

**原因**：对需要专用平面文件的分类（例如服装、鞋靴、珠宝）使用了通用的 Inventory Loader 模板。

Amazon 为各分类提供了带有额外必填字段的专用模板。用错模板会导致该分类特有的必填字段全部缺失。

**解决方法**：
- 在卖家平台中进入“库存”→“批量上传商品”→“下载库存文件”
- 选择您的商品分类，获取正确的模板
- 下载该分类的平面文件，并把数据迁移进去

拥有专用模板的常见分类：服装、鞋靴、珠宝、电子产品、图书、音乐、影视、运动户外。

---

## 如何阅读处理报告

上传后，从卖家平台下载处理报告（“库存”→“批量上传商品”→“监控上传状态”→“查看处理报告”）。

报告有三个标签页：
- **Summary**：总行数、成功数和失败数
- **Results**：文件中的每条记录一行，包含状态和错误信息
- **Original**：您最初上传的数据

要查找失败的行，请在 Results 标签页中按 `status` 列筛选。`FAILURE` 行包含 `error-code` 和 `error-message`，准确说明了问题所在。
