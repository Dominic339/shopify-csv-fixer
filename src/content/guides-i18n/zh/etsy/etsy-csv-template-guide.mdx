## Etsy 商品 CSV 是什么（以及不能做什么）

Etsy 允许你把在售商品下载为 CSV：打开 **店铺管理器 → 设置 → 选项 → 下载数据**，选择商品的 CSV 下载。根据 Etsy 的帮助，文件中包含每个商品的：

- 标题
- 描述
- 价格和货币代码
- 数量
- 标签
- 材料
- 图片 URL
- SKU（如果你给商品添加了 SKU）

**Etsy 没有商品 CSV 上传功能。** 编辑这个文件不会改变店铺中的任何内容，Etsy 也没有提供重新导入的方式。卖家用这个导出文件来：

- 在电子表格中检查和整理商品数据
- 保存商品目录的备份
- 把商品迁移到其他平台，例如 Shopify 或 WooCommerce
- 提供给通过 Etsy API 工作的第三方批量刊登应用

要在 Etsy 内批量修改，请使用店铺管理器“商品”页面中的批量编辑功能。

## 导出文件中的列

在文件中，每个字段都有自己的列，列标题如 `TITLE`、`DESCRIPTION`、`PRICE`、`CURRENCY_CODE`、`QUANTITY`、`TAGS`、`MATERIALS` 和 `SKU`。每张照片各占一列（`IMAGE1`、`IMAGE2` 等），存放图片的 URL。

| 列 | 内容 | 格式 |
|---|---|---|
| `TITLE` | 商品标题 | 最多 140 个字符 |
| `DESCRIPTION` | 商品描述 | 纯文本 |
| `PRICE` | 以店铺货币计的价格 | 普通数字，如 `14.99` |
| `CURRENCY_CODE` | 店铺货币 | 三个字母的代码，如 `USD` |
| `QUANTITY` | 可售数量 | 整数，最多 999 |
| `TAGS` | 搜索标签 | 逗号分隔，最多 13 个 |
| `MATERIALS` | 材料 | 逗号分隔，最多 13 个 |
| `IMAGE1`、`IMAGE2`、... | 照片 URL | 完整的 `https://` URL |
| `SKU` | 你的 SKU | 文本 |

如果之后要用工具重新读取文件，请保持列名不变。

## 每个字段必须遵守的限制

这些是 Etsy 商品编辑器执行的限制。超出限制的文件，无论用什么工具都无法重新变成有效的商品：

- **标题**：最多 140 个字符。Etsy 搜索只显示开头部分，所以把最重要的词放在前面。
- **标签**：每个商品最多 13 个，每个标签含空格最多 20 个字符。请使用字母、数字和空格；Etsy 不接受标签中的大多数符号。
- **材料**：每个商品最多 13 个。
- **数量**：每个商品最多 999 的整数。
- **价格**：以店铺货币计的普通数字，不带货币符号。

---

## 价格格式

- 使用普通小数：`14.99`
- 不带货币符号（`$`、`€`、`£`）
- 即使电子表格使用逗号，也要用句点而不是逗号作小数点
- 货币由店铺决定，`CURRENCY_CODE` 只是记录它

---

## 标签

标签放在同一个单元格中，用逗号分隔：

```
handmade,gift for her,leather wallet,birthday gift
```

因为单元格中有逗号，所以在 CSV 中必须用双引号括起来。电子表格保存时会自动处理。需要留意：

- 单元格中的标签超过 13 个
- 有标签超过 20 个字符
- 编辑后残留的连续逗号或逗号前后的空格

---

## 批量刊登应用可能要求的字段

Etsy 的导出并不包含商品的所有设置。通过 Etsy API 创建商品的第三方应用经常要求额外的列，例如商品由谁制作（`who_made`）、何时制作（`when_made`）、是否为手工材料（`is_supply`）、运费模板和店铺分区。允许的值来自 Etsy API，并会随时间变化（例如 `when_made` 的年份区间），所以请严格使用该应用模板中列出的值。

## 在电子表格中编辑后的常见问题

### 价格带符号或逗号

`$14.99` 或 `14,99` 这样的价格不是普通数字。

**解决方法**：用查找和替换删除 `$`、`€` 和 `£`，并把小数点逗号换成句点。

### 标题过长

标题超过 140 个字符。

**解决方法**：在 Excel 中添加一个 `=LEN(A2)` 辅助列，找出超过 140 个字符的标题并缩短。

### 标签太多或太长

某个商品的标签超过 13 个，或者某个标签超过 20 个字符。

**解决方法**：数一数标签（逗号数 + 1），并让每个标签都不超过 20 个字符。

### 图片链接损坏

图片单元格里是 `mug.jpg` 之类的内容，或者链接缺少 `https://`。

**解决方法**：使用以 `https://` 开头的完整图片 URL。
