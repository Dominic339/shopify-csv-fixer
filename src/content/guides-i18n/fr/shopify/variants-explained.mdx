## Comment Shopify représente les variantes dans le CSV

Dans le CSV de produits Shopify, un produit à plusieurs variantes est représenté par **plusieurs lignes partageant le même Handle**. La première ligne est la ligne « parent » : elle contient les données du produit. Chaque ligne suivante avec le même Handle est une ligne de variante.

### Exemple minimal : un t-shirt en deux tailles

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Variant SKU,Image Src
blue-shirt,Blue T-Shirt,Size,Small,19.99,BLUE-SM,https://cdn.example.com/shirt.jpg
blue-shirt,,Size,Medium,21.99,BLUE-MD,
```

À retenir :
- Les deux lignes partagent le Handle `blue-shirt`.
- La deuxième ligne a un Title vide, un Image Src vide et un nouvel Option1 Value.
- Chaque ligne représente une variante achetable (une combinaison de valeurs d'options).

---

## La ligne parent

La première ligne d'un Handle est la ligne parent. Elle définit les champs du produit :

| Colonne | Obligatoire dans la ligne parent | Remarques |
|---|---|---|
| Handle | Oui | Identifiant unique de ce produit ; lettres, chiffres et tirets |
| Title | Oui | Le nom du produit |
| Body HTML | Non | Description du produit ; seulement dans la ligne parent |
| Vendor | Non | Nom de la marque |
| Type | Non | Type de produit (pour les collections) |
| Tags | Non | Tags séparés par des virgules |
| Published | Non | true ou false |
| Option1 Name | Oui (avec des options) | Nom de la première option (par ex. « Size ») |
| Option1 Value | Oui (avec des options) | Valeur de la première variante (par ex. « Small ») |
| Image Src | Non | URL de l'image principale |

**Une ligne parent doit avoir un Title.** Si le Title est vide, Shopify ne la reconnaît pas comme ligne parent et l'import peut donner des résultats incorrects.

---

## Les lignes de variante

Chaque ligne qui suit la première avec le même Handle est une ligne de variante. Les lignes de variante :
- Partagent le même Handle que la ligne parent.
- Ont un Title vide (ou le même Title : Shopify l'ignore en dehors de la ligne parent).
- Ont leur propre Option1 Value (et Option2 Value, Option3 Value le cas échéant).
- Ont leurs propres Variant Price, Variant SKU, Variant Inventory Qty, etc.

### Colonnes propres aux variantes

| Colonne | Remarques |
|---|---|
| Variant Price | Nombre décimal (sans symbole monétaire) ; un prix vide est importé à 0.00 |
| Variant SKU | Facultatif mais vivement conseillé ; gardez-le unique, car Shopify n'empêche pas les doublons |
| Variant Grams | Poids en grammes |
| Variant Inventory Qty | Stock initial |
| Variant Inventory Policy | `deny` ou `continue` (continue = autoriser la survente) |
| Variant Fulfillment Service | En général `manual` |
| Variant Requires Shipping | true ou false |
| Variant Taxable | true ou false |
| Variant Barcode | EAN, UPC ou autre code-barres |

## Plusieurs options (taille ET couleur)

Shopify prend en charge jusqu'à trois options avec les colonnes Option1, Option2 et Option3.

Exemple : t-shirt avec taille et couleur

```
Handle,Title,Option1 Name,Option1 Value,Option2 Name,Option2 Value,Variant Price,Variant SKU
blue-shirt,Blue T-Shirt,Size,Small,Color,Blue,19.99,BLUE-SM-BLU
blue-shirt,,Size,Small,Color,Red,19.99,BLUE-SM-RED
blue-shirt,,Size,Medium,Color,Blue,21.99,BLUE-MD-BLU
blue-shirt,,Size,Medium,Color,Red,21.99,BLUE-MD-RED
```

- Option1 Name et Option2 Name ne doivent figurer que sur la ligne parent (la première de chaque Handle). Les répéter sur les lignes de variante ne pose pas de problème.
- Chaque combinaison d'options a besoin de sa propre ligne.
- Un produit avec 3 tailles et 4 couleurs demande 12 lignes de variante.

## Erreurs courantes

### Erreur 1 : des Handles différents pour le même produit

**Symptôme :** Ce qui devrait être un seul produit avec des variantes apparaît comme plusieurs produits séparés après l'import.

**Solution :** Toutes les lignes d'un même produit doivent avoir exactement le même Handle. Une faute de frappe (`blue-shirt` au lieu de `blue-shirt-`) fait créer un nouveau produit à Shopify.

### Erreur 2 : informations produit sur les lignes de variantes

**Symptôme :** un titre, une description ou un tag saisi sur une ligne de variante n'apparaît pas après l'import.

**Solution :** Shopify lit les champs du produit (Title, Body HTML, Vendor, Tags, etc.) sur la première ligne de chaque Handle. Mettez-les là et laissez-les vides sur les lignes suivantes.

### Erreur 3 : colonne Option1 Name manquante

**Symptôme :** les variantes n'apparaissent pas, ou le produit se retrouve avec une seule variante nommée « Default Title ».

**Solution :** incluez toujours `Option1 Name` dans l'en-tête, avec une valeur au moins sur la ligne parente. Si votre produit n'a pas de vraies options, mettez `Title` dans Option1 Name et `Default Title` dans Option1 Value. Sans aucune colonne d'option, Shopify crée une nouvelle variante par défaut et supprime les variantes existantes.

### Erreur 4 : des valeurs d'option incohérentes d'une ligne à l'autre

**Symptôme :** Shopify crée plus de variantes que prévu, ou des noms d'option apparaissent en double.

**Solution :** Option1 Name doit être exactement le même texte sur toutes les lignes d'un Handle. Si la ligne parent indique `Size`, chaque ligne de variante doit aussi indiquer `Size` (ou rester vide). Mélanger `Size`, `size` et `Sizes` produit des données d'options incohérentes.

### Erreur 5 : Variant Price vide

**Symptôme :** les variantes sont créées avec un prix de 0.00 $.

**Solution :** Shopify ne refuse pas un prix vide : il importe la variante à 0.00. Les prix ne sont pas hérités ; même si toutes les variantes ont le même prix, chaque ligne doit l'indiquer.

### Erreur 6 : ajouter une variante écrase les variantes existantes

**Symptôme :** Après un import partiel (ajout d'une seule nouvelle variante), toutes les autres variantes disparaissent.

**Solution :** quand vous mettez à jour un produit par import CSV, incluez **toutes** ses variantes existantes dans le fichier, pas seulement la nouvelle. Shopify associe les variantes à leurs valeurs d'option, et celles qui manquent dans le fichier peuvent être supprimées quand vous écrasez le produit.

## Conseils pour les grands catalogues

- **Générez les lignes de variante automatiquement.** Pour les produits à nombreuses combinaisons (3 tailles × 4 couleurs × 2 matières = 24 lignes), utilisez une formule de tableur ou un script plutôt que de tout saisir à la main.
- **Utilisez des modèles de SKU cohérents.** Un SKU comme `BASE-TAILLE-COULEUR` (par ex. `SHIRT-SM-BLU`) rend les variantes faciles à identifier et à trier.
- **Testez d'abord avec un seul produit.** Importez un produit (la ligne parent et toutes ses variantes) avant d'envoyer tout le catalogue. Vérifiez la structure des variantes dans l'administration Shopify avant de continuer.
