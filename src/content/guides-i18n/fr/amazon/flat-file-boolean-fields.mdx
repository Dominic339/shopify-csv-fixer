## Les valeurs oui/non dépendent du fichier

Amazon n'utilise pas un seul format oui/non pour tous ses fichiers d'import. Ce qu'une colonne accepte dépend du fichier que vous remplissez :

| Fichier | Exemples de colonnes | Valeurs acceptées |
|---|---|---|
| Modèle de catégorie (téléchargé depuis Seller Central pour votre type de produit) | `batteries_required`, `are_batteries_included` | Ce que l'onglet **Valid Values** du modèle indique pour cette colonne. Pour les champs de piles, c'est généralement `true` / `false` |
| Inventory Loader (fichier d'offres avec `sku`, `product-id`, `add-delete`) | `will-ship-internationally` | `n` ou `1` pour les États-Unis uniquement, `y` ou `2` pour l'international |
| Inventory Loader | `expedited-shipping` | Pas un champ oui/non : une liste d'options d'expédition (voir plus bas) |

Le guide de l'Inventory Loader d'Amazon présente `batteries_required` et `are_batteries_included` avec les options `true` ou `false`, et la Listings API d'Amazon les enregistre aussi en true/false.

**L'erreur la plus courante :** saisir un mot qui ne figure pas dans la liste du modèle, comme `Yes`, `Y` ou `1` dans une colonne dont l'onglet Valid Values indique `true` / `false`, ou reprendre la convention d'un fichier Amazon dans un autre.

## Vérifiez d'abord l'onglet Valid Values

Chaque modèle de catégorie téléchargé depuis Seller Central contient deux onglets qui tranchent la question pour votre fichier :

1. **Data Definitions :** décrit chaque colonne et indique si elle est obligatoire.
2. **Valid Values :** liste les valeurs exactes acceptées par chaque colonne à liste déroulante.

Cherchez le nom de la colonne dans l'onglet Valid Values et copiez les valeurs depuis celui-ci, écrites exactement comme affichées. Les modèles évoluent et varient selon la catégorie et la place de marché : vérifiez donc la version que vous allez envoyer, pas celle enregistrée il y a des mois. Si une colonne attendue ne figure pas dans votre modèle, votre type de produit ne l'utilise pas.

## Colonnes d'expédition de l'Inventory Loader

Si vous mettez à jour des offres avec le fichier Inventory Loader (celui qui contient les colonnes `sku`, `product-id` et `add-delete`), deux colonnes d'expédition ressemblent à des champs oui/non mais suivent leurs propres règles. Le guide de l'Inventory Loader d'Amazon les définit ainsi :

| Nom de colonne | Valeurs attendues | Ce qu'elle contrôle |
|---|---|---|
| `will-ship-internationally` | `n` ou `1` pour les États-Unis uniquement, `y` ou `2` pour l'international | Si vous expédiez l'offre hors des États-Unis |
| `expedited-shipping` | `Next`, `Second`, `Domestic`, `International` et `Plus`, séparés par des virgules, ou `N` pour aucune | Les options de livraison rapide que vous proposez |

`expedited-shipping` n'est donc pas un champ oui/non, et un `y` n'y correspond à aucune option. Écrivez `Next,Second` pour proposer la livraison en un jour et en deux jours, ou laissez la cellule vide si vous n'en proposez aucune.

## Comment les tableurs modifient les valeurs oui/non

### Excel

1. **Cases à cocher et formules :** les cases à cocher et les formules comme `=IF(A2>0, TRUE, FALSE)` produisent les `TRUE` / `FALSE` propres à Excel (affichés VRAI / FAUX dans Excel en français). Cela ne fonctionne que si la liste de votre modèle contient true/false, et jamais dans la colonne `will-ship-internationally` de l'Inventory Loader.
2. **Mots saisis à la main :** un `Yes`, `No` ou `Y` saisi à la main reste tel quel, et le fichier finit par mélanger plusieurs écritures.
3. **Ouverture directe d'un CSV :** quand vous double-cliquez sur un CSV, Excel devine le type des colonnes. Un texte comme `true` peut devenir une valeur logique Excel et être enregistré en `TRUE`.

### Google Sheets

Sheets se comporte de la même façon : les cases à cocher et les formules produisent `TRUE` / `FALSE`, quelle que soit la valeur attendue par la colonne.

## Repérer les valeurs non valides

### Filtrez chaque colonne

1. Ouvrez votre fichier via **Données → À partir d'un fichier texte/CSV** pour qu'Excel ne le reformate pas.
2. Cliquez sur la flèche de filtre d'une colonne oui/non (par exemple `batteries_required`).
3. Comparez les valeurs affichées avec l'onglet Valid Values. Toute autre valeur pose problème, tout comme une cellule vide dans une colonne que Data Definitions marque comme obligatoire.

### Formule dans une colonne d'aide

Ajoutez une colonne à côté du champ et indiquez les valeurs acceptées dans la formule. Pour une colonne true/false :

```
=IF(OR(LOWER(A2)="true", LOWER(A2)="false", A2=""), "OK", "INVALID: "&A2)
```

Pour `will-ship-internationally` dans l'Inventory Loader, vérifiez plutôt `y`, `n`, `1` et `2`. Filtrez les lignes qui affichent `INVALID` pour retrouver toutes les valeurs à corriger.

## Corriger les valeurs non valides en masse

### Rechercher et remplacer dans Excel

1. Appuyez sur **Ctrl+H** (Rechercher et remplacer).
2. Dans **Rechercher**, saisissez la mauvaise valeur, par exemple `Yes`.
3. Dans **Remplacer par**, saisissez la valeur de l'onglet Valid Values, par exemple `true`.
4. Cliquez sur **Options** et cochez **Totalité du contenu de la cellule**, pour ne modifier que les cellules entières.
5. Cliquez sur **Remplacer tout**, puis recommencez pour `No` et toute autre écriture trouvée.

> **Important :** décidez de la signification de chaque valeur avant de remplacer. Un `Yes` dans `batteries_required` et un `Yes` dans une autre colonne peuvent demander des remplacements différents.

### Remplacer les résultats de formules par des valeurs

Si vos colonnes oui/non sont calculées par des formules :

1. Sélectionnez la colonne et copiez-la (**Ctrl+C**).
2. Clic droit → **Collage spécial → Valeurs**.
3. Les formules deviennent du texte simple, que vous pouvez ensuite corriger avec Rechercher et remplacer.

### Google Sheets

1. Sélectionnez la colonne.
2. **Édition → Rechercher et remplacer** (Ctrl+H).
3. Cochez **Respecter la casse** et **Faire correspondre tout le contenu de la cellule**, recherchez la mauvaise valeur et remplacez-la par la valeur acceptée.

## Éviter les problèmes la prochaine fois

### Utilisez les listes déroulantes du modèle

Les modèles de catégorie d'Amazon contiennent des listes déroulantes construites à partir de l'onglet Valid Values. Saisissez vos données directement dans le modèle au lieu d'y coller un CSV, et les listes déroulantes garderont les valeurs dans la liste.

### Ajoutez votre propre liste déroulante

Pour un fichier sans listes déroulantes, sélectionnez les cellules sous l'en-tête, allez dans **Données → Validation des données**, choisissez **Liste** et saisissez les valeurs acceptées, par exemple `true,false` (ou `y,n,1,2` pour `will-ship-internationally`).

### Vérifiez avant chaque envoi

1. Ouvrez le fichier final dans un éditeur de texte (pas dans Excel) et parcourez les colonnes oui/non.
2. Vérifiez que chaque valeur figure dans la liste de cette colonne.
3. Remplissez chaque colonne que Data Definitions marque comme obligatoire.

Si vous envoyez vos fichiers avec l'Inventory Loader, le correcteur StriveFormats vérifie `will-ship-internationally` et `expedited-shipping` pour vous d'après le guide d'Amazon.
