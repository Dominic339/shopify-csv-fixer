## Shopify CSV의 이미지 열

Shopify 상품 CSV에는 이미지 관련 열이 세 개 있습니다.

| 열 | 필수 여부 | 참고 |
|---|---|---|
| Image Src | 선택 | 이미지 파일의 공개 HTTPS URL |
| Image Position | 선택 | 표시 순서를 정하는 정수(1, 2, 3...) |
| Image Alt Text | 선택 | 이미지를 설명하는 텍스트 |

이 열들은 상품이나 변형 데이터와 같은 행에 들어갑니다. 한 행에는 이미지 URL 하나를 넣을 수 있습니다.

---

## 상품당 이미지 한 장

가장 간단한 경우는 상품 하나에 이미지 한 장입니다. **상위 행**(해당 Handle의 첫 행)의 `Image Src` 열에 URL을 넣으세요.

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Image Src,Image Alt Text
blue-shirt,Blue T-Shirt,Size,Small,19.99,https://cdn.example.com/blue-shirt.jpg,Blue t-shirt front view
blue-shirt,,Size,Medium,21.99,,
```

변형 행(같은 Handle의 두 번째 이후 행)의 Image Src 열은 비워 둡니다.

---

## 상품당 여러 이미지

상품에 이미지를 두 장 이상 넣으려면 이미지 데이터만 담은 **같은 Handle의 행을 추가**하세요. 이 행들은 Title과 변형 필드가 비어 있으며, 추가 이미지 URL을 전달하는 용도로만 쓰입니다.

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Image Src,Image Position,Image Alt Text
blue-shirt,Blue T-Shirt,Size,Small,19.99,https://cdn.example.com/blue-shirt-front.jpg,1,Blue t-shirt front view
blue-shirt,,Size,Medium,21.99,,,
blue-shirt,,,,,,https://cdn.example.com/blue-shirt-back.jpg,2,Blue t-shirt back view
blue-shirt,,,,,,https://cdn.example.com/blue-shirt-detail.jpg,3,Blue t-shirt fabric detail
```

핵심 규칙:
- 상품당 최대 **250장**의 이미지를 지원합니다.
- 각 이미지 URL은 같은 Handle을 쓴 별도의 행에 넣습니다.
- 이미지 전용 행은 Variant Price, 옵션 값, Title을 비워 둡니다.
- 한 행을 변형과 추가 이미지 둘 다에 쓰지 마세요. 한 행에는 한 가지 용도만 있어야 합니다.

---

## Image Position

`Image Position`은 상품 갤러리에서 이미지가 표시되는 순서를 정합니다. 1부터 시작하는 정수입니다.

- `1` = 대표 이미지(가장 먼저 표시)
- `2`, `3` 등 = 그 순서대로 표시되는 추가 이미지

Image Position을 생략하면 Shopify는 CSV에 이미지가 나오는 순서대로 위치를 정합니다. 위치를 직접 지정하면 행 순서와 관계없이 지정한 순서가 적용됩니다.

**예시:** 라이프스타일 사진을 먼저, 상품 사진을 다음에 표시하기

```
Handle,Image Src,Image Position,Image Alt Text
blue-shirt,https://cdn.example.com/lifestyle.jpg,1,Model wearing blue shirt
blue-shirt,https://cdn.example.com/product.jpg,2,Blue shirt on white background
```

## 이미지 URL 요구 사항

Shopify는 가져오는 시점에 지정한 URL에서 이미지를 내려받습니다. URL은 다음 요구 사항을 충족해야 합니다.

- **HTTPS여야 합니다.** 일반 HTTP URL은 거부되거나 혼합 콘텐츠 경고가 발생할 수 있습니다.
- **공개적으로 접근할 수 있어야 합니다.** 로그인, Cloudflare 확인, IP 제한이 걸린 URL은 작동하지 않습니다.
- **URL에 공백이 없어야 합니다.** 공백은 `%20`으로 인코딩하거나 URL을 바꿔야 합니다.
- **이미지 파일을 가리켜야 합니다.** Shopify는 JPEG, PNG, GIF, WEBP, SVG를 지원합니다. 서버가 올바른 content-type을 반환하면 URL이 확장자로 끝나지 않아도 되지만, 대부분의 가져오기 과정은 확장자가 있는 URL에서 더 안정적으로 작동합니다.
- **만료되는 매개변수가 없어야 합니다.** 일정 시간 후 만료되는 서명 URL(S3, Cloudinary 등)을 쓴다면 가져오기가 끝날 때까지 유효한지 확인하세요.

## 흔한 이미지 가져오기 실패

### 가져온 뒤 이미지가 보이지 않음

**가능한 원인:**
1. URL이 200이 아닌 HTTP 상태(404, 403, 500)를 반환했습니다. Shopify는 접근할 수 없는 이미지를 알림 없이 건너뜁니다.
2. URL이 HTTPS가 아니라 HTTP였습니다.
3. URL에 공백이 있어 요청이 실패했습니다.

**확인 방법:** URL을 브라우저에 그대로 붙여 넣으세요. 이미지가 열리면 URL은 유효합니다. 로그인 페이지, 403, 404가 보이면 이미지가 공개되어 있지 않은 것입니다.

### 엉뚱한 이미지가 대표 이미지가 됨

**원인:** Image Position을 지정하지 않았고, CSV에서 이미지 순서가 잘못되어 있었습니다.

**해결 방법:** 대표 이미지 URL이 있는 행의 `Image Position`을 명시적으로 `1`로 지정하세요.

### 이미지가 다른 상품에 붙음

**원인:** Handle 오타입니다. 이미지 행의 Handle이 상품 행과 조금 달랐습니다.

**해결 방법:** Handle이 정확히 일치하도록 하세요. 공백 하나만 더 있거나 대소문자가 하나만 달라도 새 상품이 만들어집니다.

### 예전 이미지가 삭제되지 않음

**동작:** 다시 가져올 때 Shopify CSV 가져오기는 상품에 이미지를 **추가**합니다. 기존 이미지는 삭제하지 않습니다. 이미지를 삭제하려면 Shopify 관리자나 API에서 해야 합니다.

### 이미지가 너무 많음

**동작:** Handle 하나에 250개가 넘는 이미지 URL을 지정하면 Shopify는 처음 250개만 가져오고 나머지는 알림 없이 무시합니다.

## 대체 텍스트 모범 사례

대체 텍스트(`Image Alt Text` 열)는 두 가지 역할을 합니다.
1. **접근성:** 화면 낭독기가 시각 장애가 있는 사용자에게 대체 텍스트를 읽어 줍니다.
2. **SEO:** 검색 엔진이 대체 텍스트를 색인하고 이미지 내용을 이해하는 데 사용합니다.

**좋은 대체 텍스트:**
- 이미지에 무엇이 있는지 설명합니다: `"파란색 면 티셔츠, 정면, 흰색 배경"`
- 상품명과 주요 특징을 포함합니다
- 이미지마다 다릅니다(상품의 모든 이미지에 같은 내용을 반복하지 않음)

**피해야 할 것:**
- 키워드 나열: `"파란 셔츠 구매 저렴한 셔츠 면 셔츠"`
- 의미 없는 텍스트: `"image1"`, `"사진"`, `""`(빈칸)
- 상품의 모든 이미지에 같은 대체 텍스트 사용

## 빠른 참고: 이미지 행 패턴

**이미지 한 장, 대체 텍스트 없음:**
```
Handle,Title,...,Image Src
my-product,My Product,...,https://example.com/img1.jpg
```

**순서를 지정한 여러 이미지:**
```
Handle,Title,...,Image Src,Image Position,Image Alt Text
my-product,My Product,...,https://example.com/img1.jpg,1,Front view
my-product,,,...,https://example.com/img2.jpg,2,Side view
my-product,,,...,https://example.com/img3.jpg,3,Detail view
```

**변형 이미지(특정 변형 행에 연결된 이미지):**
변형과 같은 행에 Image Src를 넣으세요. Shopify가 그 이미지를 해당 변형에 연결합니다.
```
Handle,Option1 Value,Variant Price,Image Src
my-product,Blue,19.99,https://example.com/blue.jpg
my-product,Red,19.99,https://example.com/red.jpg
```
