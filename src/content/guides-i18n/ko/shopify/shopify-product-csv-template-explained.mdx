## 템플릿 개요

Shopify 공식 상품 CSV 템플릿의 열은 **상품 수준**(상품마다 한 번, 첫 행인 상위 행에 입력)과 **변형 수준**(해당 상품의 모든 행에 입력) 두 종류입니다. 변형이 여러 개인 상품은 같은 Handle을 공유하는 여러 행을 차지합니다.

최신 템플릿은 Shopify 관리자에서 내려받으세요: 제품 → 가져오기 → 샘플 CSV 다운로드. 최신 템플릿은 새 열 이름(`URL handle`, `Description`, `Price`, `Product image URL`, `Published on online store` 등)을 씁니다. 이 가이드에서 쓰는 예전 이름도 Shopify가 계속 받아들입니다.

---

## 식별 열

### Handle(최신 템플릿에서는 `URL handle`)

Handle은 URL에 쓸 수 있는 상품의 고유 식별자입니다. 다음 조건을 지켜야 합니다.
- 스토어의 모든 상품 중에서 고유해야 합니다
- 영문 소문자, 숫자, 하이픈만 사용해야 합니다
- 처음 가져온 뒤에는 바꾸지 않아야 합니다(Handle을 바꾸면 새 상품 URL이 생깁니다)

**예:** `blue-leather-wallet`

같은 상품의 모든 행은 같은 Handle을 써야 합니다. Shopify는 이를 이용해 변형 행을 묶습니다.

### Title(상위 행 필수)

스토어에 표시되는 상품명입니다. 상품의 첫 행에 입력하고 변형 행에서는 비워 두세요.

**예:** `Blue Leather Wallet`

### Body (HTML)

상품 설명입니다. HTML을 넣을 수 있습니다. 설명에 쉼표나 꺾쇠괄호가 있으면 값 전체를 큰따옴표로 감싸세요. 설명 안의 줄바꿈도 따옴표로 감싼 값 안에 있어야 합니다.

### Vendor

브랜드나 공급업체 이름입니다. 일반 텍스트입니다.

### Type

직접 정하는 상품 유형(정리용)입니다. Shopify 상품 카테고리가 아니라 필터링에 쓰는 자유 텍스트입니다.

### Tags

쉼표로 구분한 태그 목록입니다. 태그에 쉼표가 들어 있으면 Tags 셀 값 전체를 따옴표로 감싸야 합니다.

**예:** `"summer, sale, leather"`

## 게시 관련 열

### Published(참/거짓)

상품을 온라인 스토어에 게시할지 여부입니다. `true` 또는 `false`를 사용하며, 빈 셀은 `true`로 처리됩니다.

- `true`: 상품이 온라인 스토어에 게시됩니다
- `false`: 상품이 온라인 스토어에 표시되지 않습니다(관리자 화면에는 남아 있으며, 초안 상태는 Status 열에서 따로 설정합니다)

### Status

상품을 판매할 수 있는지 여부: `active`(기본값), `draft`, `archived`.

## 옵션 열

이 열들은 변형의 축(사이즈, 색상, 소재 등)을 정의합니다.

### Option1 Name / Option1 Value

`Option1 Name`은 축의 이름(예: `Size`, `Color`)이고, `Option1 Value`는 각 행의 구체적인 값(예: `Small`, `Medium`, `Blue`)입니다.

규칙:
- `Option1 Name`은 같은 상품의 모든 행에서 같아야 합니다
- `Option1 Value`는 변형 행마다 달라집니다
- 옵션이 하나뿐이면 Option1만 쓰고, 두 번째나 세 번째 옵션이 없다면 Option2, Option3 열은 넣지 마세요

### Option2 Name / Option2 Value(선택)

두 번째 축(예: 색상)입니다. 상품에 축이 두 개일 때만 필요합니다.

### Option3 Name / Option3 Value(선택)

세 번째 축입니다. Shopify는 상품당 최대 3개의 옵션을 지원합니다.

## 변형 열

이 열들은 상위 행과 변형 행을 포함한 모든 행에 적용됩니다.

### Variant SKU

해당 변형의 고유 식별자입니다. 선택 사항이지만 재고를 관리한다면 SKU는 고유해야 합니다. SKU 기반 재고 관리를 하지 않으면 비워 두세요.

### Variant Price(최신 템플릿에서는 `Price`)

이 변형의 판매 가격입니다. 통화 기호나 천 단위 구분 기호 없는 일반 소수로 씁니다. 비어 있는 가격은 0.00으로 가져옵니다.

**예:** `19.99`

### Variant Compare At Price

취소선으로 표시되는 "정가"입니다. 할인 가격이 없으면 비워 두세요.

### Variant Inventory Qty

재고 수량을 정수로 씁니다. 위치가 하나인 스토어에만 적용되며, 위치가 여러 곳인 스토어는 Shopify 재고 CSV로 재고를 업데이트합니다.

### Variant Inventory Policy

재고가 0이 되었을 때의 동작입니다. 허용 값: `deny`(구매 막기) 또는 `continue`(재고가 없어도 구매 허용).

### Variant Fulfillment Service

변형의 배송 처리 방식입니다. 일반 처리는 `manual`, 외부 서비스라면 해당 서비스의 API 이름을 씁니다.

### Variant Requires Shipping(참/거짓)

배송이 필요한 실물 상품은 `true`, 디지털 상품은 `false`입니다.

### Variant Taxable(참/거짓)

과세 대상이면 `true`, 면세면 `false`입니다.

### Variant Barcode

UPC, EAN, ISBN 바코드입니다. 스프레드시트가 앞자리 0을 지우거나 숫자를 1.23E+11로 바꾸지 않도록 열 서식을 텍스트로 지정하세요.

### Variant Grams / Variant Weight Unit

`Variant Grams`(최신 템플릿에서는 `Weight value (grams)`)는 그램 단위 무게로, 단위 없이 정수로 씁니다. 5.125kg은 `5125`입니다. `Variant Weight Unit`(`Weight unit for display`)은 고객에게 보이는 단위만 정합니다: `g`, `kg`, `lb`, `oz`.

## 이미지 열

### Image Src

상품 이미지의 URL입니다. 비밀번호 보호가 없는 공개 `https://` URL이어야 합니다.

- 상위 행: 상품의 대표 이미지
- 변형 행: 해당 변형의 옵션 조합에 맞는 이미지(예: 파란색 견본)

### Image Position

이미지의 표시 순서입니다. 1부터 시작하는 정수이며 대표 이미지는 1이어야 합니다.

### Image Alt Text

이미지의 대체 텍스트로, 접근성과 SEO에 쓰입니다.

---

## SEO 열

### SEO Title

페이지 제목 태그입니다(브라우저 탭과 검색 결과에 표시). 비워 두면 상품의 Title이 쓰입니다. 70자 미만을 권장합니다.

### SEO Description

상품 페이지의 메타 설명입니다. Shopify는 320자까지 허용하며, 비어 있으면 상품 설명을 씁니다.

---

## 기프트 카드 열

### Gift Card(참/거짓)

이 상품이 기프트 카드일 때만 `true`입니다. 대부분의 상품은 `false`이거나 비어 있어야 합니다. Shopify는 CSV 가져오기로 기프트 카드를 만들 수 없으므로 새 기프트 카드는 관리자에서 만드세요.

---

## 단일 상품과 변형 상품

**단일 상품(변형 1개):** 상품당 한 행입니다. 필수 열을 모두 채우세요. 옵션 열은 선택 사항입니다.

**변형 상품:** 상품당 여러 행이며 모두 같은 Handle을 씁니다. 첫 행이 상위 행(Title, Image Src, Body HTML 등 포함)이고, 이후 행은 변형 행입니다(Title은 비어 있으며, Handle 묶음을 통해 상품 수준 데이터를 이어받습니다).
