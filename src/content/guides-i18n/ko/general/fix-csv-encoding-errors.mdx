## CSV 인코딩 오류란?

인코딩 오류는 CSV 파일의 바이트를 잘못된 문자 집합으로 읽을 때 생깁니다. 가장 흔한 증상은 **글자 깨짐**입니다. 상품명, 설명 등의 필드에서 아포스트로피, 악센트가 있는 문자, 한글, 통화 기호 대신 `â€™`, `Ã©`, `Â£`, `í•œ` 같은 이상한 문자열이 보입니다.

Shopify와 WooCommerce는 **UTF-8**을 기대하며, 다른 모든 플랫폼에서도 UTF-8이 안전한 선택입니다. 파일이 다른 인코딩(CP949/EUC-KR, Latin-1, Windows-1252 등)으로 저장되어 있으면 가져오기 도구가 파일을 거부하거나 문자를 조용히 망가뜨립니다.

### 흔한 증상

- 아포스트로피와 따옴표가 여러 글자로 된 의미 없는 문자열로 보임
- `é`, `ü`, `ñ` 같은 글자가 `Ã©`, `Ã¼`, `Ã±`로, 한글은 알아볼 수 없는 기호와 글자로 보임
- 가져오기가 "invalid character"나 "encoding error" 같은 메시지와 함께 실패함
- 첫 열 머리글 앞에 이상한 문자가 붙어 있음(BOM)

## 파일의 인코딩 확인하기

고치기 전에 파일이 지금 어떤 인코딩인지 확인하세요.

**VS Code:** 파일을 열면 오른쪽 아래 상태 표시줄에 인코딩이 보입니다. `UTF-8 with BOM`, `Korean (EUC-KR)`, `Windows 1252`, `ISO 8859-1` 등이 표시되면 변환해야 합니다.

**Python:**

```python
# pip install chardet
import chardet

with open("products.csv", "rb") as f:
    result = chardet.detect(f.read(10_000))
print(result)
# 예: {'encoding': 'Windows-1252', 'confidence': 0.73}
```

**명령줄(Linux/macOS):**

```bash
file -i products.csv    # macOS에서는: file -I products.csv
# products.csv: text/plain; charset=iso-8859-1
```

## UTF-8 BOM 제거하기

**BOM**(바이트 순서 표시)은 파일 맨 앞에 있는 숨겨진 3바이트(`EF BB BF`)입니다. Windows의 Excel에서 "다른 이름으로 저장 > CSV UTF-8(쉼표로 분리)"을 쓰면 추가됩니다. Shopify와 WooCommerce는 이를 처리하지만, 일부 가져오기 도구와 스크립트는 이 추가 바이트를 첫 번째 열 머리글의 일부로 읽습니다. 그러면 열 이름이 `Handle`이 아니라 `﻿Handle`이 되어 도구가 인식하지 못합니다.

**VS Code에서 고치기:**
1. 파일을 엽니다
2. 오른쪽 아래 상태 표시줄의 인코딩 표시를 클릭합니다
3. "Save with Encoding"을 고릅니다
4. **UTF-8**(BOM 없음)을 선택합니다

**Excel에서 고치기:**
Excel에는 BOM 없이 UTF-8로 저장하는 옵션이 없습니다. BOM을 피하려고 일반 "CSV(쉼표로 분리)"를 쓰지 마세요. 시스템의 예전 인코딩(한국어 Windows에서는 CP949)으로 저장되어 다른 플랫폼에서 한글이 깨집니다. "CSV UTF-8"로 저장하고, 도구가 필요로 할 때만 VS Code에서 BOM을 제거하세요.

**Python으로 고치기:**

```python
# utf-8-sig는 읽을 때 BOM을 제거하고, 쓰기는 BOM 없는 일반 utf-8로 합니다
with open("input.csv", encoding="utf-8-sig") as f:
    content = f.read()
with open("output.csv", "w", encoding="utf-8") as f:
    f.write(content)
```

## ANSI, Latin-1, Windows-1252를 UTF-8로 바꾸기

이런 예전 인코딩은 한 지역의 문자만 다룹니다. Windows-1252와 Latin-1에는 한글이 없고, CP949에는 많은 기호와 다른 언어의 문자가 없습니다. 게다가 도구가 파일을 UTF-8로 읽으면 이런 문자는 모두 깨집니다.

**VS Code에서:**
1. 상태 표시줄의 인코딩 표시를 클릭합니다
2. "Reopen with Encoding"을 고르고 파일의 **현재** 인코딩(예: `Korean (EUC-KR)`)을 선택합니다. 글자가 제대로 보이는지 확인하세요
3. 표시를 다시 클릭하고 "Save with Encoding"을 고른 뒤 **UTF-8**을 선택합니다

**Python에서:**

```python
# 위에서 확인한 인코딩을 쓰세요(한국어 Excel의 CSV는 대개 cp949)
with open("input.csv", encoding="windows-1252") as f:
    content = f.read()
with open("output.csv", "w", encoding="utf-8") as f:
    f.write(content)
```

**LibreOffice Calc에서:**
파일을 열 때 LibreOffice가 인코딩을 묻습니다. 올바른 원본 인코딩을 고르세요. 저장할 때는 대화 상자에서 "유니코드(UTF-8)"를 고르세요.

## 이미 데이터에 들어간 깨진 글자(mojibake) 고치기

깨진 글자가 이미 셀 값에 들어가 있다면(잘못 읽은 채로 다시 저장해서 파일에 기록된 경우) 변환만으로는 고쳐지지 않습니다. 깨짐을 되돌려야 합니다.

**흔한 mojibake 패턴:**

| 보이는 글자 | 원래 글자 | 원인 |
|---|---|---|
| `â€™` | `’`(둥근 아포스트로피) | UTF-8을 Windows-1252로 읽음 |
| `â€”` | `—`(대시) | UTF-8을 Windows-1252로 읽음 |
| `Ã©` | `é` | UTF-8을 Windows-1252 또는 Latin-1로 읽음 |
| `Â£` | `£` | UTF-8을 Windows-1252 또는 Latin-1로 읽음 |

**Python으로 고치기(ftfy 라이브러리):**

```python
# pip install ftfy
import ftfy

with open("input.csv", encoding="utf-8") as f:
    content = f.read()

fixed = ftfy.fix_text(content)

with open("output.csv", "w", encoding="utf-8") as f:
    f.write(fixed)
```

**알려진 패턴을 직접 고치기:**
VS Code나 정규식을 지원하는 텍스트 편집기에서 찾기 및 바꾸기를 써서 깨진 문자열을 올바른 글자로 바꾸세요.

## 인코딩 문제 막기

- **Google 스프레드시트에서는** 항상 파일 > 다운로드 > CSV로 내보내세요. 깨끗한 UTF-8이 만들어집니다
- **Windows의 Excel에서는** 예전 인코딩을 쓰는 일반 "CSV(쉼표로 분리)"가 아니라 "CSV UTF-8(쉼표로 분리)"로 저장하세요
- **저장한 뒤** VS Code에서 파일을 확인하세요. 상태 표시줄에서 인코딩을 확인할 수 있습니다
- **UTF-8 CSV를** 예전 Excel에서 열어 다시 저장할 때는 반드시 저장할 때 UTF-8을 명시적으로 고르세요
- **스크립트로 내보낼 때는** Python `csv` 모듈이나 `encoding="utf-8"`을 지정한 pandas를 쓰세요
