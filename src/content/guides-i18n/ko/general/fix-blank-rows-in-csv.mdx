## 빈 행이 가져오기 문제를 일으키는 이유

CSV의 빈 행은 모든 필드가 비어 있는(또는 값 없이 쉼표만 있는) 행입니다. 많은 가져오기 도구는 완전히 빈 행을 그냥 건너뛰지만, 플랫폼에 따라 빈 행이 다음과 같은 일을 일으킬 수 있습니다.

- **빈 상품 레코드를 만듦**(Title도 Price도 비어 있음). 필수 필드 검증에서 실패합니다
- **가져오기를 멈춤**. 빈 행에서 멈추고 그 뒤는 모두 조용히 무시합니다
- **검증 오류를 냄**. 빈 행에 빠진 필수 필드마다 오류가 납니다

빈 행이 가장 자주 생기는 곳:

- **파일 끝**(스프레드시트가 자동으로 하나 추가하는 경우가 많음)
- **상품 사이**(행을 지웠지만 빈 줄이 남음)
- **구역 사이**(보기 좋게 간격을 두고 시트를 정리한 경우)
- **셀 내용을 지운 뒤**: Delete 키는 행의 셀만 비우고 빈 행은 그대로 남깁니다

## 빈 행 찾기

### 텍스트 편집기에서

VS Code나 메모장으로 파일을 열면 빈 행이 바로 보입니다. 쉼표만 있거나 완전히 빈 줄입니다.

```
Handle,Title,Price
blue-shirt,Blue T-Shirt,19.99
                          ← 빈 행(쉼표만 있거나 아무것도 없음)
red-shirt,Red T-Shirt,21.99
```

### Excel에서

`Ctrl+End`를 누르면 사용 범위의 마지막 셀로 이동합니다. 마지막 행이 데이터보다 아래(빈 행)라면 Excel이 빈 행을 사용 범위에 포함한 것입니다.

모든 빈 행을 찾으려면 마지막 열 뒤에 보조 열을 추가하고 2행에 `=COUNTA(A2:Z2)`를 입력한 다음(범위를 모든 열로 넓히세요) 아래로 채우세요. `0`으로 표시된 행이 완전히 빈 행입니다.

`Title` 같은 한 열에서만 빈칸을 찾지 마세요. Shopify 파일에서는 옵션 행이 `Title`을 일부러 비워 두며, 이는 빈 행이 아닙니다.

## Excel에서 빈 행 삭제하기

**방법 1: 끝의 빈 행 삭제하기**

1. `Ctrl+End`를 눌러 Excel이 데이터가 끝난다고 보는 위치를 확인합니다
2. 마지막 데이터 행보다 아래라면 데이터 아래의 여분 행을 선택합니다
3. 마우스 오른쪽 클릭 → 삭제
4. 다시 `Ctrl+End`를 눌러 사용 범위가 이제 올바른지 확인합니다

**방법 2: 보조 열로 모든 빈 행 삭제하기**

1. 위에서 설명한 `=COUNTA(A2:Z2)` 보조 열을 추가합니다
2. 필터를 켜고(데이터 → 필터) 보조 열이 `0`인 행만 표시합니다
3. 그 행들을 선택하고 마우스 오른쪽 클릭 → 행 삭제
4. 필터를 해제하고 보조 열을 삭제합니다

한 열에 이동 옵션 → 빈 셀을 쓰지 마세요. 그 열이 우연히 비어 있는 모든 행이 삭제되며, 정상적인 옵션 행도 포함됩니다.

## Google 스프레드시트에서 빈 행 삭제하기

같은 보조 열과 필터를 씁니다.

1. `=COUNTA(A2:Z2)` 보조 열을 추가하고 아래로 채웁니다
2. 필터를 추가합니다(데이터 → 필터 만들기)
3. 보조 열의 필터에서 `0`만 표시합니다
4. 보이는 행을 선택해 삭제합니다(마우스 오른쪽 클릭 → 선택한 행 삭제)
5. 필터를 끄고 보조 열을 삭제합니다

정렬해도 빈 행이 아래로 모이지만, 행 순서가 중요하지 않은 파일에서만 정렬하세요. Shopify 상품, WooCommerce 변형, eBay 옵션 상품은 행 순서가 유지되어야 합니다.

## Python으로 빈 행 삭제하기

큰 파일이라면 Python이 가장 빠릅니다.

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f_in, \
     open("output.csv", "w", newline="", encoding="utf-8") as f_out:
    reader = csv.reader(f_in)
    writer = csv.writer(f_out)
    for row in reader:
        # 공백이 아닌 값이 있는 필드가 하나라도 있으면 행을 유지
        if any(cell.strip() for cell in row):
            writer.writerow(row)
```

이 코드는 공백만 있는 행(비어 보이지만 공백이나 탭이 들어 있는 행)도 처리합니다.

---

## 공백만 있는 행

어떤 행은 스프레드시트에서 비어 보이지만 실제로는 하나 이상의 셀에 공백이나 탭 문자가 들어 있습니다. 단순한 "행이 비어 있나?" 확인으로는 찾을 수 없습니다.

**Python으로 찾기:**

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for i, row in enumerate(reader, 1):
        if not any(cell.strip() for cell in row):
            print(f"Blank or whitespace-only row at line {i}")
```

앞 섹션의 방법(`cell.strip()` 사용)은 이런 행도 자동으로 지웁니다.

## 앞으로의 내보내기에서 빈 행 막기

- **Excel:** CSV로 저장하기 전에 `Ctrl+End`를 눌러 데이터가 있는 마지막 행이 실제로 마지막 사용 행인지 확인하세요. 그 아래 행은 지우세요.
- **Google 스프레드시트:** CSV 다운로드에는 비어 있지 않은 마지막 셀까지의 모든 행이 들어가므로 데이터를 빈틈없이 유지하세요.
- **행을 지울 때:** Excel에서는 행 번호를 마우스 오른쪽 클릭 → 삭제를 쓰세요(셀 내용에서 Delete만 누르면 빈 행이 남습니다).
- **필터를 쓴 뒤:** Excel의 CSV 내보내기에는 필터로 숨긴 행도 들어갑니다. 내보내기 전에 필터를 해제하고 시트에 실제로 무엇이 있는지 확인하세요.
