## 세 가지 작업, 세 가지 의미

"CSV 파일을 합친다"고 하면 대개 서로 다른 세 가지 작업 중 하나를 뜻합니다. 잘못된 작업을 고르면 데이터가 사라지거나 구조가 깨집니다.

| 작업 | 바뀌는 것 | 행 수 | 열 수 |
|---|---|---|---|
| **추가** | 행이 늘어남 | 늘어남 | 같음 |
| **병합** | 구조가 같은 두 파일을 하나로 합침 | 늘어남 | 같음 |
| **조인** | 관련 파일의 열을 더함 | 같음 | 늘어남 |

---

## 추가: 행 늘리기

**하는 일:** 두 번째 CSV의 행을 첫 번째 CSV 끝에 붙입니다. 두 파일의 열 구성이 완전히 같아야 합니다.

**쓰는 경우:**
- 페이지로 나뉜 내보내기를 합칠 때(파일 1 = 1–500행, 파일 2 = 501–1000행).
- 업로드 전에 기존 카탈로그 파일에 새 상품 묶음을 더할 때.
- 같은 형식으로 내보내는 여러 지역 팀의 파일을 합칠 때.

**Excel에서 올바르게 추가하는 방법:**

1. 기준 파일을 엽니다.
2. 두 번째 파일을 엽니다.
3. 두 번째 파일에서 **머리글 행을 삭제**합니다(1행을 마우스 오른쪽 클릭 → 삭제).
4. 남은 데이터를 모두 선택합니다(Ctrl+A, 너무 많이 선택되면 조정).
5. 복사합니다(Ctrl+C).
6. 기준 파일로 돌아가 마지막 데이터 행 아래의 첫 빈 셀을 클릭합니다.
7. 붙여 넣습니다(Ctrl+V).
8. CSV UTF-8로 저장합니다.

**반드시 피해야 할 실수:** 3단계(머리글 삭제)를 건너뛰면 파일 중간에 머리글 행이 중복되어 어떤 가져오기 플랫폼에서도 실패합니다.

**Google 스프레드시트에서 추가하는 방법:**

방법은 같습니다. 두 번째 파일의 머리글 행을 삭제하고, 데이터 행만 복사해 기준 시트 맨 아래에 붙여 넣습니다.

## 병합: 열이 같은 파일 합치기(여러 소스에서)

**하는 일:** 본질적으로 추가와 같지만, "병합"은 서로 다른 소스에서 온, 같은 종류의 데이터를 담은 파일을 합칠 때 흔히 쓰는 말입니다(예: 같은 형식으로 된 두 공급업체의 상품 목록).

**쓰는 경우:**
- 서로 다른 두 공급업체의 상품 피드를 업로드 파일 하나로 합칠 때.
- 같은 플랫폼 CSV 템플릿을 쓰는 부서별 내보내기를 합칠 때.

**병합할 때 추가로 확인할 점(단순 추가와 비교):**
- **중복 행을 확인하세요.** 두 파일에 같은 상품이 있으면 병합된 파일에는 두 번 들어갑니다. Handle(Shopify), SKU(WooCommerce/Amazon), Item ID(eBay)로 중복을 찾으세요. Excel에서는 **데이터 → 중복된 항목 제거**를 누르고 키 열을 고릅니다.
- **열 이름을 통일하세요.** 공급업체 A는 `Barcode`, 공급업체 B는 `UPC`라고 부른다면 병합 전에 플랫폼이 기대하는 열 이름으로 맞춰야 합니다.
- **값을 통일하세요.** 가격의 통화가 다르거나 상태 표기 방식이 다를 수 있습니다(Published, TRUE, 1 등).

## 조인: 관련 파일의 열 더하기

**하는 일:** 두 파일을 나란히 놓고 공통 키 열(SKU나 Handle 등)로 행을 맞춰, 두 번째 파일의 열을 첫 번째 파일에 더합니다.

**쓰는 경우:**
- ERP의 상품 목록(Handle, Title, SKU, Price)과 별도의 재고 파일(SKU, Quantity, Warehouse Location)이 있고, 각 상품 행에 재고 수량을 더하고 싶을 때.
- 한 시스템에서 이미지 없이 상품을 내보내고, SKU로 연결된 이미지 URL 파일이 따로 있을 때.
- 가져오기 전에 공급업체 데이터(원가, 공급업체 품번)를 상품 카탈로그에 더하고 싶을 때.

### Excel의 VLOOKUP으로 조인하기

가정:
- **파일 A**(기준): A열=Handle, B열=Title, C열=Price
- **파일 B**(조회): A열=Handle, B열=Quantity

파일 B의 Quantity를 파일 A에 더하려고 합니다.

1. 파일 A에 새 열 머리글 `Quantity`를 추가합니다(D열).
2. D2에 다음을 입력합니다.
   ```
   =VLOOKUP(A2, '[FileB.csv]FileB'!$A:$B, 2, FALSE)
   ```
3. 파일 B가 Excel에서 열려 있어야 합니다. Excel은 CSV를 열 때 시트 이름을 파일 이름으로 정하므로 `FileB.csv`의 시트 이름은 `FileB`입니다. 키가 일치하면 Quantity가 채워집니다. 일치하지 않으면 `#N/A`가 나타나며, 그 Handle이 파일 B에 없다는 뜻입니다.
4. 수식을 모든 행에 아래로 복사합니다.
5. 결과가 맞으면 D열을 선택해 복사하고 **선택하여 붙여넣기 → 값**으로 수식을 고정 값으로 바꿉니다.
6. 파일 B를 닫습니다.
7. 파일 A를 CSV UTF-8로 저장합니다.

### Google 스프레드시트에서 조인하기

같은 문법으로 `VLOOKUP`을 사용합니다. 또는 `IMPORTRANGE`로 다른 Google 스프레드시트에서 데이터를 가져온 뒤 보조 열을 쓰는 방법도 있습니다.

### Python으로 조인하기(큰 파일)

```python
import csv

# 조회 파일을 Handle을 키로 하는 딕셔너리로 불러오기
lookup = {}
with open("inventory.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        lookup[row["Handle"]] = row["Quantity"]

# 기준 파일에 Quantity 더하기
with open("products.csv", encoding="utf-8") as infile, \
     open("products_with_qty.csv", "w", newline="", encoding="utf-8") as outfile:
    reader = csv.DictReader(infile)
    fieldnames = reader.fieldnames + ["Quantity"]
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    writer.writeheader()
    for row in reader:
        row["Quantity"] = lookup.get(row["Handle"], "")
        writer.writerow(row)
```

## CSV 파일을 합칠 때 흔한 실수

### 실수 1: 추가한 뒤 머리글 행이 중복됨

**증상:** 파일 중간에서 "인식할 수 없는 행" 같은 오류로 가져오기가 실패합니다.
**해결 방법:** 추가하기 전에 첫 번째 파일을 제외한 모든 파일의 머리글 행을 반드시 삭제하세요.

### 실수 2: 추가한 파일의 열 순서가 다름

**증상:** 추가한 뒤 데이터가 엉뚱한 열에 들어가 있습니다.
**해결 방법:** 두 파일은 열 이름뿐 아니라 열 순서도 같아야 합니다. 파일 B의 열 순서가 다르면 추가하기 전에 파일 A에 맞춰 다시 정렬하세요.

### 실수 3: 고유하지 않은 키로 조인함

**증상:** VLOOKUP이 잘못된 수량을 돌려줍니다(처음 일치한 값을 쓰고 중복은 무시합니다).
**해결 방법:** 조인하기 전에 조회 파일에서 키 열(SKU, Handle)이 고유한지 확인하세요. **데이터 → 중복된 항목 제거**를 쓰거나 COUNTIF로 확인하세요.

### 실수 4: 합친 뒤 인코딩이 맞지 않음

**증상:** 원본 파일 중 하나에서 온 행의 글자가 깨집니다.
**해결 방법:** 합치기 전에 모든 원본 파일을 UTF-8로 저장하세요. UTF-8이 아닌 파일은 VS Code로 다시 인코딩하세요(인코딩 가이드 참고).

### 실수 5: 추가한 부분 사이에 빈 행이 있음

**증상:** 가져오기가 빈 행에서 멈추고 그 뒤의 행을 모두 무시합니다.
**해결 방법:** 추가한 뒤 합친 파일을 훑어보고 부분 사이에 생긴 빈 행을 삭제하세요.

## 빠른 선택 가이드

```
행이 더 필요한가요? → 추가 또는 병합
열이 더 필요한가요? → 조인

같은 시스템에서 나온, 열이 똑같은 파일인가요? → 추가
다른 시스템에서 나왔지만 열 템플릿이 같은 파일인가요? → 병합(중복 확인)
상품 데이터는 한 파일에, 보강 데이터는 다른 파일에 있나요? → 조인
```
