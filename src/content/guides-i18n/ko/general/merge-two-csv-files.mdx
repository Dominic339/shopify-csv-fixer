## CSV 파일을 합쳐야 할 때는?

두 CSV 파일을 하나로 합치는 것은 쇼핑몰 가져오기 전에 흔히 하는 작업입니다. 다음과 같은 경우에 필요합니다.

- 두 공급업체의 상품을 한 번의 카탈로그 업로드로 모을 때
- 지난달 상품 내보내기와 새로 추가한 상품을 합칠 때
- 큰 가져오기를 작은 묶음으로 나눈 뒤 다시 합칠 때
- 여러 소스의 옵션 행을 하나의 상품 CSV로 모을 때

이 가이드는 Excel Power Query, Google 스프레드시트, 명령줄, Python이라는 네 가지 믿을 만한 방법을 다룹니다. 모든 방법은 첫 번째 파일의 머리글 행을 유지하고 두 번째 파일에서는 데이터 행만 추가합니다.

---

## 시작하기 전에: 머리글 맞추기

두 파일은 같은 열 머리글을 같은 순서로 가져야 합니다. 열이 다르면 합칠 때 데이터가 엉뚱한 필드로 밀려 가져오기가 망가집니다.

합치기 전 빠른 체크리스트:

- [ ] 두 파일을 열어 첫 행(머리글)을 나란히 비교함
- [ ] 열 이름이 정확히 일치함(일부 플랫폼은 대소문자를 구분함)
- [ ] 두 파일의 열 순서가 같음
- [ ] 어느 파일에도 요약 행이나 바닥글 행이 없음
- [ ] 두 파일 모두 UTF-8로 저장함

머리글 순서가 다르면 합치기 전에 한 파일의 열 순서를 바꾸세요. Python의 DictWriter 방법(아래 방법 4)은 열 순서 차이를 자동으로 처리합니다.

## 방법 1: Excel Power Query(Windows, 추천)

Excel의 Power Query는 수식이나 매크로 없이 여러 CSV를 이어 붙입니다. 파일 사이의 인코딩과 줄바꿈 차이를 자동으로 처리하며 머리글 행을 반복하지 않습니다.

### 단계

1. Excel에서 빈 통합 문서를 엽니다.
2. **데이터** 탭에서 **데이터 가져오기**, **파일에서**, **텍스트/CSV에서**를 차례로 클릭합니다.
3. **첫 번째 CSV 파일**을 고르고 **가져오기**를 클릭합니다. 미리 보기가 나오면 **데이터 변환**을 클릭합니다(로드가 아님).
4. Power Query 편집기에서 **홈** > **새 원본** > **파일** > **텍스트/CSV**로 가서 **두 번째 CSV 파일**을 고르고 **확인**을 클릭합니다. 이제 두 파일이 왼쪽 패널에 쿼리로 나타납니다.
5. 첫 번째 쿼리를 선택한 다음 **홈** > **쿼리 추가** > **새 쿼리로 쿼리 추가**로 갑니다.
6. 대화 상자에서 **2개의 테이블**을 고르고 목록에서 두 번째 쿼리를 선택합니다.
7. 왼쪽 패널에 합쳐진 새 쿼리가 나타납니다. **닫기 및 로드**를 클릭해 새 시트에 씁니다.
8. 합친 시트가 활성화된 상태에서 **파일** > **다른 이름으로 저장**으로 가서 파일 형식으로 **CSV UTF-8(쉼표로 분리)을** 고릅니다. Excel은 활성 시트만 저장합니다. 일반 "CSV(쉼표로 분리)"는 예전 인코딩(한국어 Windows에서는 CP949)을 써서 다른 플랫폼에서 한글이 깨질 수 있습니다.

### Power Query를 쓰는 이유

- 파일마다 인코딩을 감지하고, 짐작이 틀리면 미리 보기에서 바꿀 수 있습니다.
- 머리글 행을 파일마다가 아니라 한 번만 넣습니다.
- 두 파일 사이에 빈 행을 넣지 않습니다.
- 큰 파일도 다룰 수 있지만 Excel 시트 하나에는 최대 1,048,576행까지만 들어갑니다. 그보다 많다면 명령줄이나 Python을 쓰세요.

## 방법 2: Google 스프레드시트(브라우저에서, 작은 파일)

Excel이 없다면 Google 스프레드시트가 빠른 선택입니다. 합계 약 5만 행 미만의 파일에 잘 맞습니다.

### 단계

1. Google 드라이브를 열고 첫 번째 CSV를 업로드합니다. 빈 곳을 마우스 오른쪽 클릭해 **파일 업로드**를 고르고 CSV를 선택한 다음, 업로드한 파일을 마우스 오른쪽 클릭해 **연결 앱 > Google 스프레드시트**를 고릅니다.
2. 마지막 데이터 행의 번호를 적어 둡니다(예: 데이터 499행과 머리글 1행이 있다면 500행).
3. 두 번째 CSV도 같은 방법으로 새 브라우저 탭에서 엽니다.
4. 두 번째 시트에서 행 번호 **2**(머리글 아래 첫 데이터 행)를 클릭합니다. **Ctrl+Shift+End**를 눌러 데이터가 있는 마지막 행과 열까지 선택을 넓힙니다.
5. **Ctrl+C**로 복사합니다. 첫 번째 탭으로 돌아가 데이터 아래 첫 빈 행을 클릭합니다.
6. **Ctrl+V**로 데이터 행(머리글 제외)을 붙여 넣습니다.
7. **파일** > **다운로드** > **쉼표로 구분된 값(.csv)으로** 갑니다.

### 주의할 점

- Google 스프레드시트는 BOM 없는 UTF-8로 내보내므로 합친 파일을 그대로 업로드할 수 있습니다.
- 아주 큰 파일(10만 행 이상)은 스프레드시트를 느리게 하거나 멈추게 할 수 있습니다. 이럴 때는 명령줄이나 Python을 쓰세요.
- 붙여 넣은 행이 열과 맞는지 확인하세요. 한 열만 밀려도 합친 결과 전체가 망가집니다.

## 방법 3: 명령줄(가장 빠름, 파일 크기 무관)

터미널을 쓸 수 있다면 명령줄은 파일 크기와 상관없이 1초도 걸리지 않습니다. macOS와 Linux에서는 아무것도 설치하지 않아도 됩니다.

### macOS 또는 Linux

```bash
# file1.csv와 file2.csv를 merged.csv로 합치기
# tail -n +2는 두 번째 파일의 머리글 행을 건너뜀
cat file1.csv <(tail -n +2 file2.csv) > merged.csv
```

`file1.csv`가 줄바꿈으로 끝나지 않으면 마지막 행과 `file2.csv`의 첫 행이 같은 줄에 붙습니다. 결과에서 이어지는 부분을 확인하세요.

### Windows(명령 프롬프트)

```bat
:: 먼저 첫 번째 파일을 복사
copy file1.csv merged.csv

:: 두 번째 파일에서 머리글을 뺀 모든 행을 추가
more +1 file2.csv >> merged.csv
```

참고: Windows의 `more +1` 명령은 첫 줄을 건너뜁니다. 하지만 탭을 공백으로 바꾸고, ASCII가 아닌 문자(한글 포함)를 망가뜨릴 수 있으며, 아주 큰 파일에서는 멈춥니다. 결과를 확인하거나 Windows에서는 Python(방법 4)을 쓰세요.

### 결과 확인하기

명령줄로 합친 뒤에는 결과를 텍스트 편집기로 열어 다음을 확인하세요.

- 머리글 행이 정확히 한 번(맨 위에) 있음
- 두 파일의 데이터 사이에 빈 줄이 없음
- file1의 마지막 행과 file2의 첫 데이터 행이 이어진 줄에 있음
- 끝에 불필요한 줄바꿈이 없음(대부분의 가져오기 도구는 괜찮지만 없는 편이 깔끔함)

## 방법 4: Python(모든 운영 체제, 열이 달라도 됨)

Python의 `csv.DictWriter`는 가장 믿을 만한 합치기 방법입니다. 열 순서가 달라도, 한 파일에만 있는 열이 있어도, 파일이 커도 처리합니다. 프로그래머가 아니어도 됩니다. Python을 설치하고 아래 스크립트를 실행하세요.

### 스크립트

```python
import csv

files_to_merge = ["file1.csv", "file2.csv"]
output_file = "merged.csv"

# 모든 열 이름을 처음 나타난 순서대로 모으기
fieldnames = []
for fname in files_to_merge:
    with open(fname, newline="", encoding="utf-8-sig") as f:
        for h in csv.DictReader(f).fieldnames or []:
            if h not in fieldnames:
                fieldnames.append(h)

with open(output_file, "w", newline="", encoding="utf-8") as out:
    # restval=""는 그 열이 없는 파일에서 온 행의 해당 열을 비워 둠
    writer = csv.DictWriter(out, fieldnames=fieldnames, restval="")
    writer.writeheader()
    for fname in files_to_merge:
        # utf-8-sig는 BOM이 있으면 제거함
        with open(fname, newline="", encoding="utf-8-sig") as f:
            for row in csv.DictReader(f):
                writer.writerow(row)

print(f"Done: merged {len(files_to_merge)} files into {output_file}")
```

이 파일을 CSV 파일들과 같은 폴더에 `merge.py`로 저장하세요. 그 폴더에서 터미널이나 명령 프롬프트를 열고 다음을 실행합니다.

```
python merge.py
```

### Python을 쓰는 이유

- Windows, Mac, Linux에서 작동합니다.
- BOM을 자동으로 제거합니다(utf-8-sig). UTF-8이 아닌 파일은 먼저 변환하세요(아래 인코딩 섹션 참고).
- DictWriter는 위치가 아니라 열 이름으로 연결하므로 열 순서가 달라도 됩니다. 한 파일에 없는 열은 비워 두고, 한 파일에만 있는 열도 유지합니다.
- 모든 것을 메모리에 올리지 않고 한 행씩 처리하므로 아주 큰 파일에서도 작동합니다.

## 합치지 말아야 할 때

합치기는 구조가 같은 파일의 행을 위아래로 쌓기 위한 방법입니다. 다음과 같은 경우에는 합치지 마세요.

- **파일 구조가 다를 때.** file1에 30개 열, file2에 다른 25개 열이 있다면 그냥 합칠 경우 데이터가 어긋난 파일이 됩니다. 모든 열을 유지하고 빈칸으로 남기는 Python DictWriter 방법(방법 4)을 쓰거나 먼저 구조를 맞추세요.
- **키로 연결하고 싶을 때(SQL 같은 JOIN).** 합치기는 행을 쌓을 뿐 공통 SKU, Handle, ID로 두 파일의 행을 짝지어 주지 않습니다. 키로 연결하려면 Python의 `csv.DictReader`와 딕셔너리를 쓰거나 pandas 같은 도구를 쓰세요.
- **한 파일에 합계, 요약, 피벗 테이블이 있을 때.** 합치기 전에 원래 데이터 행만 내보내세요. 요약 행, SUM 수식, 평균 행은 합친 뒤 상품 데이터로 나타납니다.
- **파일이 서로 다른 내보내기 템플릿에서 나왔을 때.** Shopify 상품 내보내기와 Shopify 재고 내보내기는 열이 달라서 행을 덧붙여 합칠 수 없습니다.

## 합치기 전에 머리글 불일치 고치기

두 파일의 열은 같지만 머리글 이름이 다르다면(예: `Title`과 `Product Title`, `Price`와 `Variant Price`) 합치기 전에 이름을 통일하세요.

### Excel이나 Google 스프레드시트에서 직접 고치기

1. 두 파일을 나란히 엽니다.
2. 각 파일의 1행(머리글)을 비교합니다.
3. 한 파일의 비표준 머리글 이름을 다른 파일에 맞춰 바꿉니다. 셀을 직접 편집하세요(Excel에서는 F2 키).
4. 합치기 전에 두 파일을 모두 CSV로 저장합니다.

### Python으로 자동으로 고치기

```python
import csv

# file2의 비표준 이름을 file1에서 쓰는 표준 이름에 연결
RENAME = {
    "Product Title": "Title",
    "Price": "Variant Price",
    "SKU": "Variant SKU",
}

with open("file2.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    # 머리글 이름 바꾸기
    fieldnames = [RENAME.get(h, h) for h in (reader.fieldnames or [])]
    rows = list(reader)

with open("file2_normalized.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    for row in rows:
        writer.writerow({RENAME.get(k, k): v for k, v in row.items()})
```

## 열 순서 맞추기

열 이름은 같은데 순서만 다르다면 Python DictWriter 방법(방법 4)이 이름으로 연결하므로 자동으로 처리합니다. Excel이나 스프레드시트에서는 직접 순서를 바꾸세요.

**Excel에서:**
1. 한 파일의 1행 위에 빈 행을 삽입합니다.
2. 대상 파일에서 원하는 순서대로 열에 번호를 매깁니다(1, 2, 3...).
3. 그 번호 행으로 열을 정렬합니다(데이터 > 정렬 > 옵션 > 왼쪽에서 오른쪽, 1행 기준).
4. 보조 번호 행을 지웁니다.

**Google 스프레드시트에서:**
1. 맨 위에 빈 행을 삽입합니다.
2. 각 열이 있어야 할 위치 번호를 입력합니다.
3. 보조 시트에서 `=CHOOSECOLS(Sheet1!A:Z, 3, 1, 2)`(원하는 순서대로 열 번호 입력)를 쓰거나, 열을 직접 잘라 올바른 순서로 붙여 넣습니다.
4. 다운로드 > CSV.

## 합친 파일에서 중복된 머리글 행 지우기

합친 파일 중간에 실수로 머리글 행이 중복되어 들어갔다면(같은 도구의 내보내기를 여러 번 합칠 때 흔함) Python으로 지우세요.

```python
import csv

with open("merged.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.reader(f)
    rows = list(reader)

if not rows:
    raise ValueError("File is empty")

header = rows[0]
# 머리글과 같은 행은 빼고 유지(첫 머리글은 남김)
clean = [header] + [r for r in rows[1:] if r != header]

with open("merged_clean.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(clean)

print(f"Removed {len(rows) - len(clean)} duplicate header row(s).")
```

## 파일 사이의 인코딩과 구분 기호 차이

한 파일은 UTF-8이고 다른 파일은 CP949나 Windows-1252(ANSI)라면, 합친 파일에서는 ANSI 파일에 있던 한글, 악센트가 있는 문자, 둥근 따옴표, 통화 기호가 모두 깨집니다.

**합치기 전에 ANSI 파일을 UTF-8로 변환하세요.**

macOS 또는 Linux에서(한국어 Excel의 CSV는 대개 `cp949`):
```bash
iconv -f windows-1252 -t utf-8 file2_ansi.csv > file2_utf8.csv
```

Python으로:
```python
with open("file2_ansi.csv", encoding="windows-1252") as f:
    content = f.read()
with open("file2_utf8.csv", "w", encoding="utf-8") as f:
    f.write(content)
```

두 파일의 인코딩은 같지만 구분 기호가 다르다면(쉼표와 세미콜론) 합치기 전에 한 파일의 구분 기호를 바꾸세요. CSV 기초 가이드의 구분 기호 섹션을 참고하세요.

## 합친 파일 문제 해결

| 문제 | 원인 | 해결 방법 |
|---|---|---|
| 합친 파일 중간에 빈 행이 하나 더 있음 | 두 번째 파일 끝에 줄바꿈이나 요약 행이 있었음 | 빈 행을 지우거나, Python에서 `writer.writerow(row)` 앞에 `if any(row.values()):`를 추가 |
| 중간에 머리글 행이 중복됨 | 두 번째 파일의 머리글을 건너뛰지 않음 | `tail -n +2`(명령줄)나 머리글을 자동으로 건너뛰는 Power Query 쿼리 추가를 사용 |
| 데이터가 엉뚱한 열에 있음 | 파일마다 열 순서가 다름 | 먼저 한 파일의 열 순서를 바꾸거나 Python DictWriter 방법을 사용 |
| 합친 파일의 글자가 깨짐 | 파일의 인코딩이 서로 다름 | 먼저 두 파일을 모두 UTF-8로 변환. Mac/Linux에서는 iconv 사용: `iconv -f windows-1252 -t utf-8 file2.csv > file2_utf8.csv` |
| 업로드 후 첫 열이 인식되지 않음 | 합친 파일에 플랫폼이 잘못 읽는 BOM이 있음 | VS Code로 열어 BOM 없는 UTF-8로 다시 저장 |
