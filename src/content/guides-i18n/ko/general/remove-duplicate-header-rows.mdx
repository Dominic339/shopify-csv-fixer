## 중복 헤더 행이란?

중복 헤더 행은 CSV의 첫 행(열 이름)이 데이터 영역 어딘가에 다시 나타나는 경우입니다. 예:

```
Handle,Title,Vendor,Variant Price
blue-shirt,Blue T-Shirt,Acme,19.99
Handle,Title,Vendor,Variant Price   ← 반복된 헤더 행
red-shirt,Red T-Shirt,Acme,21.99
```

가져오기 도구가 데이터 행에서 `Handle`을 만나면 그 행을 상품으로 읽을 수 없습니다. 대부분의 플랫폼은 그 행을 조용히 건너뛰거나 형식 오류를 냅니다. 실패한 행으로 세는 곳도 있습니다.

---

## 중복 헤더가 생기는 이유

### 여러 내보내기 파일을 합친 경우

가장 흔한 원인은 두 CSV를 Excel이나 Google Sheets에서 복사해 붙여 넣어 합치는 것입니다. 두 번째 파일의 헤더 행이 합친 파일 중간에 들어갑니다.

### 페이지 단위 내보내기

데이터를 페이지 단위(예: 파일당 500행)로 내보내는 플랫폼이 있습니다. 모든 페이지를 내려받아 이어 붙이면 각 파일의 헤더 행도 함께 붙습니다.

### 예약된 보고 시스템

매일 CSV에 행을 덧붙이는 자동 시스템은 덧붙이는 블록마다 맨 앞에 헤더를 반복하기도 합니다.

### Excel의 '모두 새로 고침' 또는 Power Query 내보내기

Excel에서 데이터 연결을 새로 고치면 쿼리 설정이 잘못된 경우 헤더 행이 다시 삽입될 수 있습니다.

---

## 중복 헤더 행 찾기

### Excel에서

1. CSV를 엽니다(서식을 지키려면 더블클릭 말고 **데이터 → 텍스트/CSV에서** 사용).
2. 데이터 안의 아무 셀이나 클릭합니다.
3. **데이터 → 필터**로 필터를 켭니다.
4. **Handle** 열(또는 첫 번째 열)의 화살표를 클릭합니다.
5. 검색 상자에 헤더 이름을 정확히 입력합니다(예: `Handle`).
6. 필터 결과에 행이 나타나면 그것이 중복 헤더 행입니다.

### Google Sheets에서

1. 모든 데이터를 선택합니다(**Ctrl+A**).
2. **데이터 → 필터 만들기**로 갑니다.
3. 첫 번째 열의 화살표를 클릭합니다.
4. 필터 텍스트 상자에 헤더 이름을 입력합니다(예: `Handle`).
5. 그 값을 보여 주는 행은 모두 중복 헤더입니다.

### 수식으로 표시하기

빈 열에서 각 행 옆에 다음 수식을 넣어 중복을 표시합니다.

```
=IF(A2="Handle","DUPLICATE HEADER","")
```

`"Handle"`은 실제 첫 번째 열 이름으로 바꾸세요. `DUPLICATE HEADER`로 필터하면 모든 경우를 찾을 수 있습니다.

## 중복 헤더 행 삭제하기

### 방법 1: 필터 후 삭제(Excel / Sheets)

1. 첫 번째 열을 필터해 헤더 값(예: `Handle`)이 있는 행만 표시합니다.
2. 보이는 필터 결과 행을 모두 선택합니다(첫 결과의 행 번호를 클릭하고 마지막 결과를 Shift+클릭).
3. 마우스 오른쪽 클릭 → **행 삭제**.
4. 필터를 해제합니다(데이터 → 필터 지우기, 또는 필터 → 끄기).
5. 데이터가 온전한지 확인합니다.

### 방법 2: 정렬, 삭제, 원래 순서로 되돌리기(Excel)

정렬하면 중복 헤더 행이 모두 한곳에 모이지만 상품 순서가 바뀌므로 반드시 나중에 원래 순서로 되돌리세요. Shopify, WooCommerce, eBay 파일은 행 순서에 의존합니다.

1. 원래 순서를 기록하도록 행 번호(1, 2, 3...)를 넣은 도우미 열을 추가합니다.
2. 첫 번째 열을 기준으로 A에서 Z로 정렬합니다.
3. 중복 헤더 행은 이제 `Handle`이 값들 사이에서 알파벳순으로 들어가는 자리에 모여 있습니다(Excel 정렬은 대소문자를 구분하지 않으므로 H로 시작하는 값들 사이를 찾아보세요).
4. 그 행 묶음을 선택해 삭제합니다.
5. 도우미 열을 기준으로 정렬해 원래 순서를 되돌립니다.
6. 도우미 열을 삭제합니다.

### 방법 3: 텍스트 편집기(큰 파일)

Excel로 다루기엔 너무 큰 파일(약 100,000행 초과)은 VS Code나 Notepad++를 사용합니다.

**VS Code:**
1. 파일을 엽니다.
2. **Ctrl+H**(찾기 및 바꾸기)를 누릅니다.
3. **정규식** 모드(`.*` 아이콘)를 켭니다.
4. 찾기에 다음을 입력합니다: `^Handle,Title,Vendor,Variant Price\r?\n`
   (실제 헤더로 바꾸고, 필요하면 이스케이프합니다)
5. 바꾸기는 비워 둡니다.
6. **모두 바꾸기**를 클릭합니다.
7. 중복을 모두 지운 뒤 헤더를 직접 첫 줄로 다시 추가합니다.

> 정규식 바꾸기는 조심해서 사용하세요. 원본 파일은 항상 백업으로 보관하고, 바꾼 뒤 헤더가 정확히 한 번만 나오는지 확인하세요.

**Notepad++(Windows):**
1. 파일 열기 → **검색 → 바꾸기**(Ctrl+H).
2. **정규 표현식** 모드를 선택합니다.
3. 위 VS Code와 같은 패턴을 사용합니다.
4. 모두 바꾼 다음 헤더 행을 직접 다시 추가합니다.

## 중복 헤더를 삭제한 뒤

파일이 깨끗해지면:

1. 헤더가 1행에 정확히 한 번만 있는지 확인합니다.
2. 행 수를 셉니다. 원래 행 수에서 삭제한 중복 헤더 수를 뺀 값과 같아야 합니다.
3. 중복이 있던 자리 근처의 행 몇 개를 표본으로 확인해 데이터가 온전한지 확인합니다.
4. **CSV UTF-8**로 저장합니다(Excel: **파일 → 다른 이름으로 저장 → CSV UTF-8**).

## 다음에 합칠 때 중복 헤더 막기

여러 CSV를 직접 합칠 때:

1. 첫 번째 파일('기준' 파일)을 Excel이나 Sheets에서 엽니다.
2. 추가할 각 파일을 엽니다.
3. 데이터를 복사하기 전에 추가 파일의 **헤더 행을 삭제**합니다.
4. 데이터 행만 복사합니다.
5. 기준 파일의 맨 아래에 붙여 넣습니다.

스크립트로 CSV 합치기를 자동화한다면 첫 번째 파일 이후 모든 파일의 헤더 행을 항상 건너뛰세요. `csv.DictReader`는 각 파일의 헤더를 열 이름으로 읽으므로 헤더가 데이터에 섞이지 않습니다.

```python
# Python 예시: 모든 파일의 열이 같다고 가정합니다
import csv

files = ["export_page1.csv", "export_page2.csv"]

with open("combined.csv", "w", newline="", encoding="utf-8") as outfile:
    writer = None
    for filename in files:
        # utf-8-sig는 BOM을 제거합니다. 그대로 두면 첫 번째 열 이름이 바뀝니다
        with open(filename, newline="", encoding="utf-8-sig") as infile:
            reader = csv.DictReader(infile)
            if writer is None:
                writer = csv.DictWriter(outfile, fieldnames=reader.fieldnames)
                writer.writeheader()
            for row in reader:
                writer.writerow(row)
```

파일마다 열이 다르다면 두 CSV 파일 합치기 가이드에 있는 스크립트를 사용하세요. 그 스크립트는 모든 열을 유지합니다.
