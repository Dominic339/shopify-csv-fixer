## Amazon이 플랫 파일을 검증하는 방식

Amazon 플랫 파일은 상품 카테고리별로 정해진 엄격한 열 구성을 따르며, Amazon Inventory Loader 가이드는 업로드 전에 파일을 탭으로 구분된 텍스트(.txt)로 저장하라고 안내합니다. 플랫 파일을 업로드하면 Amazon은 여러 단계로 검증합니다:

1. **템플릿 확인**: 열 머리글이 해당 파일 유형의 템플릿과 일치하는지 확인합니다
2. **필수 필드 검증**: 모든 필수 열에 값이 있는지 확인합니다
3. **데이터 유형 검증**: 숫자, 참/거짓 값, 정해진 선택지 값을 확인합니다
4. **비즈니스 규칙**: ASIN, SKU, 상태 코드, 가격 범위를 확인합니다
5. **카탈로그 확인**: 상품 ID를 Amazon 카탈로그와 맞춰 봅니다

처리가 끝나면 Amazon이 **처리 보고서**를 만듭니다(Seller Central의 카탈로그 → 업로드를 통한 상품 추가). 항상 확인하세요. 실패한 모든 행과 구체적인 오류가 나와 있습니다.

---

## 오류: seller_sku가 잘못되었거나 없음

**원인:** `seller_sku`가 비어 있거나, 40자를 넘거나, 쓸 수 없는 문자가 있거나, 카탈로그에 이미 있는 SKU와 겹칩니다.

**seller_sku 규칙:**
- 최대 40자
- Amazon 가이드는 영숫자 문자열이라고 설명하지만, Amazon의 예시 SKU `dt-black`에도 하이픈이 들어 있습니다
- 일부 도구가 제대로 처리하지 못하는 공백과 기타 기호는 피하세요
- Amazon 판매자 계정 전체에서 고유해야 함

**해결 방법:** 모든 행에 고유한 SKU를 넣으세요. `=COUNTIF($A:$A, A2)` 같은 수식으로 중복을 찾을 수 있습니다. 40자가 넘는 SKU는 줄이세요.

---

## 오류: item_name이 없음 / 상품명이 너무 김

**원인:** `item_name`이 비어 있거나 Amazon의 상품명 길이 제한을 넘습니다(카테고리마다 다르지만 보통 200~500자).

**해결 방법:**
- 모든 상품 행에 `item_name`을 채우세요
- Excel에서 `=LEN(B2)`로 카테고리 제한을 넘는 상품명을 찾으세요
- 정확한 글자 수 제한은 사용하는 템플릿에서 확인하세요

---

## 오류: condition_type이 잘못됨

**원인:** `condition_type` 열에 Amazon이 허용하는 목록에 없는 값이 있습니다.

**허용 값:**

| 값 | 설명 |
|---|---|
| `New` | 새 상품, 미개봉 |
| `UsedLikeNew` | 중고(새것 같음) |
| `UsedVeryGood` | 중고(매우 좋음) |
| `UsedGood` | 중고(좋음) |
| `UsedAcceptable` | 중고(사용 가능) |
| `CollectibleLikeNew` | 수집품(새것 같음) |
| `CollectibleVeryGood` | 수집품(매우 좋음) |
| `CollectibleGood` | 수집품(좋음) |
| `CollectibleAcceptable` | 수집품(사용 가능) |
| `Refurbished` | 판매자 리퍼비시 |
| `Club` | 클럽(미디어 카테고리) |

**해결 방법:** 표준이 아닌 상태 값을 위 목록의 값으로 바꾸세요. Inventory Loader에서는 `item-condition`에 숫자를 씁니다: 새 상품은 `11`, 중고(새것 같음, 매우 좋음, 좋음, 양호)는 `1`~`4`, 수집품은 같은 순서로 `5`~`8`입니다. Amazon 가이드는 `9`를 사용하지 않는 값으로 표시합니다.

---

## 오류: 가격이 잘못됨

**원인:** `price` 열에 통화 기호(`$`)가 있거나, 소수점으로 쉼표를 썼거나, 0, 음수 또는 빈 값입니다.

**Amazon 가격 규칙:**
- 일반 소수: `19.99`
- 통화 기호 없음
- 양수여야 함(0보다 큼)
- 소수점은 마침표
- 천 단위 구분 기호 없이: `1,250.00`이 아니라 `1250.00`

**해결 방법:** 통화 기호를 없애고 소수점 쉼표를 마침표로 바꾸세요. 저장하기 전에 Excel에서 가격 열의 서식을 "숫자"로 지정하세요.

---

## 오류: fulfillment_center_id / 주문 처리 채널이 잘못됨

**원인:** 주문 처리 채널 열에 인식할 수 없는 값이 있습니다.

**허용 값:**

| 값 | 설명 |
|---|---|
| `DEFAULT` | 판매자 직접 배송(FBM) |
| `AMAZON_NA` | Amazon 배송(FBA, 미국) |

정확한 열 이름과 허용 값은 플랫 파일 템플릿에 따라 조금씩 다릅니다. 사용하는 템플릿을 확인하세요.

**해결 방법:** FBM에는 `DEFAULT`, 미국 FBA에는 `AMAZON_NA`를 사용하세요. `FBA`, `FBM` 같은 약어는 쓰지 마세요. FBA 행은 `quantity`를 비워 두세요. Amazon 가이드에 따르면 수량을 넣으면 해당 SKU가 판매자 배송으로 바뀝니다.

---

## 오류: product_id / ASIN을 찾을 수 없음

**원인:** `product_id`(ASIN, UPC, EAN 또는 ISBN)가 Amazon 카탈로그의 어떤 상품과도 일치하지 않거나, `product_id_type`이 입력한 ID 유형과 맞지 않습니다.

**product_id_type 값:**

| 값 | ID 유형 |
|---|---|
| `1` | ASIN |
| `2` | ISBN |
| `3` | UPC |
| `4` | EAN |

**해결 방법:**
- 상품 ID가 올바르고 Amazon 카탈로그에서 활성 상태인지 확인하세요
- `product_id_type`을 `product_id`에 넣은 ID 유형에 맞추세요
- 아직 ASIN이 없는 새 상품은 기존 리스팅에 재고를 추가하는 대신 새 리스팅을 만들어야 할 수 있습니다

---

## 오류: 상품 카테고리에 맞지 않는 템플릿

**원인:** 아직 Amazon 카탈로그에 없는 상품에 Inventory Loader를 사용했습니다. Inventory Loader는 이미 있는 상품의 오퍼를 만들거나 업데이트할 뿐이며, 새 상품에는 카테고리별 재고 파일(예: 의류, 신발, 주얼리)이 필요합니다.

Amazon에는 추가 필수 필드가 있는 카테고리별 템플릿이 있습니다. 다른 템플릿을 쓰면 카테고리 전용 필수 필드가 모두 빠집니다.

**해결 방법:**
- Seller Central에서 재고 → 업로드를 통해 상품 추가 → 재고 파일 다운로드로 이동하세요
- 상품 카테고리를 선택해 올바른 템플릿을 받으세요
- 카테고리 전용 플랫 파일을 내려받고 데이터를 옮기세요

전용 템플릿이 있는 주요 카테고리: 의류, 신발, 주얼리, 전자 제품, 도서, 음악, 비디오, 스포츠 및 아웃도어.

---

## 처리 보고서 읽는 법

업로드 후 Seller Central에서 처리 보고서를 여세요(카탈로그 → 업로드를 통한 상품 추가 → 업로드 상태 모니터링). Seller Central 메뉴는 위치가 바뀌기도 하니, 이 경로가 보이지 않으면 Seller Central에서 "업로드를 통한 상품 추가"를 검색하세요.

보고서는 처리된 레코드 수와 성공한 레코드 수를 보여 주는 요약으로 시작합니다.

그 아래에는 문제마다 한 줄씩 파일의 행 번호(`original-record-number`), `sku`, `error-code`, `error-type`(Error 또는 Warning), `error-message`가 나옵니다. Error는 해당 행을 막고, Warning은 통과시키지만 확인할 점을 알려 줍니다.
