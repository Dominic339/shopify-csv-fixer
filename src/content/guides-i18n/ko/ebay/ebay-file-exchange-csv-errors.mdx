## eBay가 대량 업로드를 확인하는 방식

eBay 리스팅 대량 업로드는 이제 **Seller Hub → 보고서 → 업로드**에서 합니다. File Exchange 형식의 CSV 템플릿도 여기서 내려받습니다. 파일을 올리면 eBay는 다음을 확인합니다.

1. **파일 구성**: 맨 위의 INFO 줄과 그 아래의 헤더 행
2. **Action 열**: 각 리스팅 행을 어떻게 처리할지
3. **데이터 형식**: 가격은 숫자, 수량은 정수, URL은 완전한 웹 주소
4. **비즈니스 규칙**: 유효한 카테고리 ID, 해당 카테고리에서 허용되는 상태 ID, 유효한 판매 기간
5. **내용 규칙**: 제목 길이와 리스팅 정책

처리가 끝나면 업로드 페이지에 결과 파일이 생깁니다. 성공한 행, 실패한 행과 그 이유를 보여 줍니다. eBay는 일부 행만 가져오고 나머지를 거부하는 경우가 많으니 항상 확인하세요.

---

## 오류: 템플릿을 인식하지 못함(INFO 줄)

eBay의 최신 템플릿은 열 제목 위에 다음과 같은 줄로 시작합니다.

```
#INFO,Version=1.0.0,Template=fx_category_template_EBAY_US
```

업로드할 때 eBay에는 이 첫 번째 INFO 줄이 필요합니다. `#INFO`나 `INFO`로 시작하는 다른 줄(템플릿 안내문)은 남겨 두거나 지워도 됩니다.

**해결 방법:**
- 메모처럼 보여도 템플릿의 첫 줄은 지우지 마세요.
- Mac에서 Excel을 쓴다면 첫 줄의 `#INFO` 앞에 아무것도 없는지 확인하세요. Excel이 그 자리에 보이지 않는 문자를 넣을 수 있고, 그러면 eBay가 파일을 거부합니다. 텍스트 편집기로 CSV를 열면 볼 수 있습니다.

StriveFormats는 INFO 줄 아래의 헤더 행을 읽고, 내려받을 때 불필요한 문자를 없앤 INFO 줄을 다시 맨 위에 넣습니다.

## 오류: Action이 없거나 잘못됨

모든 리스팅 행에는 Action이 필요합니다. 예외는 변형 행(`Relationship` = `Variation`)으로, 부모 리스팅 아래에 두고 Action은 비워 둡니다.

허용되는 값:

| 값 | 의미 |
|---|---|
| `Add` | 새 리스팅 만들기 |
| `VerifyAdd` | 새 리스팅을 게시하지 않고 확인하고 수수료 보기 |
| `Revise` | 판매 중인 리스팅의 필드 바꾸기 |
| `Relist` | 종료된 리스팅 다시 올리기 |
| `End` | 판매 중인 리스팅 종료하기(`EndCode`와 함께) |
| `Status` | 판매된 상품의 상태 바꾸기(예: 발송됨으로 표시) |
| `AddToItemDescription` | 판매 중인 리스팅 설명 끝에 글 추가하기 |
| `Draft` | 리스팅을 임시 저장함에 저장하기(임시 저장 템플릿 전용) |

**해결 방법:** 모든 리스팅 행에 위의 값 중 하나를 정확히 같은 표기로 쓰세요. eBay는 정확히 비교하므로 `verifyadd`는 `VerifyAdd`와 다릅니다.

## 오류: 잘못된 카테고리

**원인:** `Category`(또는 `Category ID`) 값이 유효한 숫자 eBay 카테고리 ID가 아니거나, 카테고리가 폐지되었습니다.

eBay 카테고리 ID는 숫자입니다(예: eBay 미국의 남성 티셔츠는 `15687`). eBay가 카테고리를 개편할 때 가끔 바뀝니다.

**해결 방법:**
- eBay 카테고리 트리에서 올바른 카테고리 ID를 찾으세요
- 예전 템플릿의 카테고리 ID는 아직 유효한지 확인하지 않고 그대로 쓰지 마세요
- 추가 상품 정보가 필요한 카테고리도 있으니 카테고리에 필요한 항목을 확인하세요

ID를 찾는 방법은 [eBay CategoryID: 무엇이고 어떻게 설정하나](/guides/ebay/categoryid-and-file-exchange)를 참고하세요.

---

## 오류: 제목이 너무 김

**원인:** `Title` 값이 eBay 리스팅 제목 한도인 80자를 넘습니다.

**해결 방법:**

Excel에 보조 열을 추가하세요: `=LEN(B2)`(B2를 제목 열의 셀로 바꾸세요). 길이가 80을 넘는 행을 필터링해 그 제목을 줄이세요.

Python의 경우:

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for i, row in enumerate(reader, 2):
        title_len = len(row.get("Title", ""))
        if title_len > 80:
            print(f"Row {i}: Title is {title_len} chars (max 80): {row['Title'][:60]}...")
```

## 오류: 잘못된 상태 ID

**원인:** `ConditionID` 값이 유효한 eBay 상태 ID가 아니거나, 상품의 카테고리에서 허용되지 않습니다.

eBay 상태 표에 있는 주요 상태 ID:

| ID | 상태 | 참고 |
|---|---|---|
| `1000` | New | Brand New, New with tags, New with box로도 표시 |
| `1500` | New other | 태그나 상자 없는 새 상품, 개봉 상품 |
| `1750` | New with defects | |
| `2000` | Certified Refurbished | 일부 카테고리에서 승인된 판매자만 |
| `2500` | Seller refurbished | 일부 카테고리에서는 아래의 리퍼비시 등급으로 대체 |
| `2010` / `2020` / `2030` | Excellent / Very Good / Good - Refurbished | 일부 카테고리에서 승인된 판매자만 |
| `2750` | Like New | |
| `3000` | Used | Pre-owned로도 표시 |
| `4000` | Very Good | |
| `5000` | Good | |
| `6000` | Acceptable | |
| `7000` | For parts or not working | 의미가 있는 카테고리에서만 |

쓸 수 있는 ID는 카테고리마다 다르고, 구매자에게 보이는 이름도 카테고리에 따라 다릅니다.

**해결 방법:** 상태 이름을 숫자 ID로 바꾸세요. StriveFormats가 eBay 상태 이름("Used", "Open box" 등)을 ID로 자동 변환합니다.

## 오류: 잘못된 StartPrice

**원인:** `StartPrice`에 통화 기호(`$9.99`)가 있거나, 소수점으로 쉼표를 썼거나(`9,99`), 음수이거나 비어 있습니다.

**해결 방법:**
- 찾기 및 바꾸기로 통화 기호를 지우세요
- 소수점 쉼표를 마침표로 바꾸세요
- 모든 가격이 양의 소수인지 확인하세요
- 저장하기 전에 Excel에서 열 서식을 숫자로 지정하세요

---

## 오류: 잘못된 Duration

**원인:** `Duration`에 해당 리스팅 형식에서 eBay가 받지 않는 값이 있습니다.

**허용되는 값:**

| 형식 | Duration |
|---|---|
| `FixedPrice` | `GTC`(Good 'Til Cancelled). 고정가 리스팅은 더 이상 일수를 지정하지 않습니다 |
| `Auction` | `Days_1`, `Days_3`, `Days_5`, `Days_7`, `Days_10` |

**해결 방법:** 고정가 리스팅에는 `GTC`를, 경매에는 `Days_` 값 중 하나를 쓰세요.

---

## 오류: 이미지 URL에 접근할 수 없음

**원인:** `PicURL`에 eBay가 내려받을 수 없는 URL이 있습니다. 이미지가 로그인 뒤에 있거나, 내 컴퓨터에 있거나, 리디렉션 뒤에 있습니다.

eBay Seller Hub Reports는 `PicURL`에 리스팅당 최대 **24개 이미지**를 세로 막대 `|`로 구분해 받습니다. URL 하나는 최대 2048자이며, URL 안의 공백은 `%20`으로 써야 합니다.

**해결 방법:**
- 각 URL을 브라우저의 비공개 창에서 열어 보세요. 로그인 없이 이미지가 바로 보여야 합니다
- 완전한 `https://` URL을 쓰세요
- 공백을 `%20`으로 바꾸세요(StriveFormats가 대신 해 줍니다)
- URL 단축기와 리디렉션 서비스는 피하세요

## 오류: 상품 번호나 UPC가 1.23457E+11로 보임

**원인:** Excel이 긴 숫자(`ItemID`나 `P:UPC`의 바코드)를 지수 표기로 바꿨습니다. 앞 몇 자리 뒤의 숫자가 사라져 eBay가 리스팅을 찾거나 상품을 매칭할 수 없습니다.

**해결 방법:** 기록에서 전체 번호를 다시 입력하세요. eBay 도움말은 저장하기 전에 상품 번호 열을 소수 자릿수 0인 숫자 서식으로 지정하라고 권합니다. 텍스트 서식도 됩니다. StriveFormats가 이런 셀을 모두 표시합니다.

---

## 오류: 잘못된 수량

**원인:** `Quantity`가 비어 있거나, 소수(예: `1.5`)이거나, 음수입니다.

**해결 방법:** 정수를 쓰세요. 새 리스팅의 수량은 1 이상이어야 합니다. 변형이 있는 리스팅은 각 변형의 수량을 부모 행이 아니라 각자의 행에 넣으세요.

---

## 전부 올리기 전에 시험하기

1. INFO 줄과 헤더 행을 유지한 채 2~3개 행을 새 파일에 복사하세요.
2. 그 행들의 Action을 `VerifyAdd`로 바꾸고 업로드하세요. eBay가 행을 확인하고 아무것도 게시하지 않은 채 수수료를 보여 줍니다.
3. 결과 파일이 알려 준 문제를 고친 뒤, 전체 파일의 Action을 다시 `Add`로 바꾸세요.
