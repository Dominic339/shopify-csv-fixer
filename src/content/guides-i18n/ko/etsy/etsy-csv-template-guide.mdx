## Etsy 상품 CSV란(그리고 할 수 없는 것)

Etsy에서는 판매 중인 상품을 CSV로 내려받을 수 있습니다. **샵 매니저 → 설정 → 옵션 → 데이터 다운로드**를 열고 상품 CSV 다운로드를 고르세요. Etsy 도움말에 따르면 파일에는 상품별로 다음 정보가 들어 있습니다.

- 제목
- 설명
- 가격과 통화 코드
- 수량
- 태그
- 소재
- 이미지 URL
- SKU(상품에 SKU를 추가한 경우)

**Etsy에는 상품 CSV 업로드가 없습니다.** 파일을 편집해도 샵에는 아무것도 바뀌지 않으며, Etsy는 파일을 다시 가져오는 방법을 제공하지 않습니다. 판매자들은 이 내보내기를 다음 용도로 씁니다.

- 스프레드시트에서 상품 데이터를 점검하고 정리하기
- 카탈로그 백업 보관하기
- Shopify나 WooCommerce 같은 다른 플랫폼으로 상품 옮기기
- Etsy API로 작동하는 외부 대량 등록 앱에 데이터 넘기기

Etsy 안에서 한꺼번에 바꾸려면 샵 매니저 상품 페이지의 일괄 편집 기능을 쓰세요.

---

## 내보내기의 열

파일에서는 필드마다 열이 따로 있고, 제목은 `TITLE`, `DESCRIPTION`, `PRICE`, `CURRENCY_CODE`, `QUANTITY`, `TAGS`, `MATERIALS`, `SKU` 같은 형태입니다. 사진은 한 장씩 별도 열(`IMAGE1`, `IMAGE2` 등)에 이미지 URL로 들어갑니다.

| 열 | 내용 | 형식 |
|---|---|---|
| `TITLE` | 상품 제목 | 최대 140자 |
| `DESCRIPTION` | 상품 설명 | 일반 텍스트 |
| `PRICE` | 샵 통화 기준 가격 | `14.99` 같은 일반 숫자 |
| `CURRENCY_CODE` | 샵 통화 | `USD` 같은 세 글자 코드 |
| `QUANTITY` | 판매 가능 수량 | 999 이하의 정수 |
| `TAGS` | 검색 태그 | 쉼표로 구분, 최대 13개 |
| `MATERIALS` | 소재 | 쉼표로 구분, 최대 13개 |
| `IMAGE1`, `IMAGE2`, ... | 사진 URL | 완전한 `https://` URL |
| `SKU` | 내 SKU | 텍스트 |

도구가 파일을 다시 읽을 예정이라면 열 이름을 그대로 두세요.

---

## 각 필드가 지켜야 할 한도

다음은 Etsy 상품 편집기가 적용하는 한도입니다. 한도를 넘는 파일은 어떤 도구를 써도 다시 유효한 상품으로 만들 수 없습니다.

- **제목:** 최대 140자. Etsy 검색에는 앞부분만 보이므로 중요한 단어를 앞에 두세요.
- **태그:** 상품당 최대 13개, 태그 하나는 공백 포함 최대 20자. 문자, 숫자, 공백을 쓰세요. Etsy는 태그에 쓰인 기호 대부분을 받지 않습니다.
- **소재:** 상품당 최대 13개.
- **수량:** 상품당 999 이하의 정수.
- **가격:** 샵 통화 기준의 일반 숫자, 통화 기호 없이.

---

## 가격 형식

- 일반 소수를 쓰세요: `14.99`
- 통화 기호(`$`, `€`, `£`)는 빼세요
- 스프레드시트가 쉼표를 쓰더라도 소수점에는 쉼표가 아닌 마침표를 쓰세요
- 통화는 샵에서 정해지며, `CURRENCY_CODE`는 그것을 기록할 뿐입니다

---

## 태그

태그는 한 셀에 쉼표로 구분해 들어갑니다.

```
handmade,gift for her,leather wallet,birthday gift
```

셀에 쉼표가 있으므로 CSV에서는 큰따옴표로 감싸야 합니다. 저장할 때 스프레드시트가 알아서 처리합니다. 주의할 점:

- 셀에 태그가 13개를 넘음
- 20자가 넘는 태그가 있음
- 편집 후 남은 이중 쉼표나 쉼표 앞뒤의 공백

---

## 대량 등록 앱이 요구할 수 있는 필드

Etsy 내보내기에는 상품 설정이 모두 들어 있지 않습니다. Etsy API로 상품을 만드는 외부 앱은 만든 사람(`who_made`), 만든 시기(`when_made`), 공예 재료인지 여부(`is_supply`), 배송 프로필, 샵 섹션 같은 추가 열을 요구하는 경우가 많습니다. 허용되는 값은 Etsy API에서 오며 시간이 지나면 바뀌므로(예: `when_made`의 연도 범위), 해당 앱의 템플릿에 있는 값을 그대로 쓰세요.

---

## 스프레드시트에서 편집한 뒤 흔한 문제

### 기호나 쉼표가 들어간 가격

`$14.99`나 `14,99` 같은 가격은 일반 숫자가 아닙니다.

**해결 방법:** 찾기 및 바꾸기로 `$`, `€`, `£`를 지우고 소수점 쉼표를 마침표로 바꾸세요.

### 제목이 너무 김

제목이 140자를 넘습니다.

**해결 방법:** Excel에 `=LEN(A2)` 보조 열을 추가해 140자가 넘는 제목을 찾고 줄이세요.

### 태그가 너무 많거나 너무 김

상품의 태그가 13개를 넘거나 20자가 넘는 태그가 있습니다.

**해결 방법:** 태그 수를 세고(쉼표 수 + 1) 각 태그를 20자 이내로 유지하세요.

### 깨진 이미지 링크

이미지 셀에 `mug.jpg` 같은 값이나 `https://`가 없는 링크가 있습니다.

**해결 방법:** `https://`로 시작하는 완전한 이미지 URL을 쓰세요.
