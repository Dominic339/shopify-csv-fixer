## CSV에서 WooCommerce 속성이 작동하는 방식

WooCommerce 상품 속성은 상품이 어떤 기준으로 달라지는지 정합니다. 보통 사이즈, 색상, 소재입니다. CSV 가져오기에서 속성은 번호가 매겨진 열 묶음으로 표현됩니다. 열 4개가 한 묶음으로 속성 하나를 나타냅니다.

열 이름 패턴은 다음과 같습니다.
- `Attribute 1 name`
- `Attribute 1 value(s)`
- `Attribute 1 visible`
- `Attribute 1 global`

두 번째 속성은 `Attribute 2 name`, `Attribute 2 value(s)`처럼 같은 패턴을 반복합니다.

WordPress를 한국어로 쓰고 있다면 내보내기 파일의 열 이름이 한국어로 나옵니다. 가져오기 도구는 한국어 이름과 영어 이름을 모두 인식합니다. 이 가이드에서는 영어 열 이름을 사용합니다.

---

## 열 참고표

| 열 | 형식 | 설명 |
|---|---|---|
| `Attribute N name` | 텍스트 | 속성 이름(예: `Color`, `Size`) |
| `Attribute N value(s)` | 텍스트, 쉼표로 구분 | 이 행의 값(예: `Blue` 또는 `Blue, Red`) |
| `Attribute N visible` | `1` 또는 `0` | `1` = 상품 페이지에 표시, `0` = 숨김 |
| `Attribute N global` | `1` 또는 `0` | `1` = 전역 분류 속성, `0` = 로컬 속성 |

---

## 속성 값이 여러 개인 단순 상품

여러 색상이 있지만 별도 변형으로 나누지 않는 단순 상품은 `Attribute 1 value(s)` 열에 모든 값을 쉼표로 구분해 넣으세요. 그러면 셀에 쉼표가 있으므로 큰따옴표로 감쌉니다(스프레드시트가 저장할 때 자동으로 처리합니다):

```
Name,Type,SKU,Regular price,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global
Blue Scarf,simple,SCARF-001,14.99,Color,"Blue, Navy, Teal",1,1
```

이렇게 하면 상품 페이지에 세 가지 색상 값을 모두 보여 주는 Color 속성이 있는 상품 하나가 만들어집니다.

---

## 변형이 있는 가변 상품

가변 상품에서는 속성이 다르게 작동합니다. 상위 행에는 가능한 모든 속성 값을 나열합니다. 각 변형 행에는 해당 변형의 값 하나만 넣습니다.

**상위 행(Type: variable):**

```
Name,Type,SKU,Regular price,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global
T-Shirt,variable,TSHIRT,20.00,Size,"S, M, L, XL",1,1
```

**변형 행(Type: variation):**

```
Name,Type,SKU,Regular price,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global
,variation,TSHIRT-S,18.00,Size,S,1,1
,variation,TSHIRT-M,18.00,Size,M,1,1
,variation,TSHIRT-L,20.00,Size,L,1,1
,variation,TSHIRT-XL,20.00,Size,XL,1,1
```

변형 행의 `Name` 열은 비어 있습니다. WooCommerce가 속성 값으로 변형 이름을 만듭니다.

---

## 속성 두 개(사이즈 + 색상)

속성 기준이 두 개인 상품의 경우:

**상위 행:**

```
Name,Type,SKU,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global,Attribute 2 name,Attribute 2 value(s),Attribute 2 visible,Attribute 2 global
Running Shoe,variable,SHOE,Size,"7, 8, 9, 10",1,1,Color,"Black, White",1,1
```

**변형 행:**

```
,variation,SHOE-7-BLK,Size,7,1,1,Color,Black,1,1
,variation,SHOE-7-WHT,Size,7,1,1,Color,White,1,1
,variation,SHOE-8-BLK,Size,8,1,1,Color,Black,1,1
```

각 변형 행은 속성마다 값을 정확히 하나만 지정합니다. 목록이 아닙니다. 여러 개가 있으면 WooCommerce는 첫 번째 값을 씁니다.

## 전역 속성과 로컬 속성

### 전역 속성(`Attribute N global: 1`)

전역 속성은 WooCommerce의 속성 분류(WordPress 관리자의 상품 → 속성)에서 정의합니다. 다음과 같은 경우 전역 속성을 쓰세요.
- 여러 상품이 같은 속성 값(같은 색상, 같은 사이즈)을 공유할 때
- 쇼핑 페이지에서 속성으로 상품을 필터링하고 싶을 때
- WooCommerce의 계층형 탐색(레이어드 내비게이션) 위젯을 쓸 때

`global: 1`로 가져오면 속성 값이 아직 없을 경우 WooCommerce가 새로 만듭니다. WooCommerce가 기존 분류와 연결하려면 속성 이름이 정확히 일치해야 합니다(대소문자 구분).

### 로컬 속성(`Attribute N global: 0`)

로컬 속성은 한 상품에만 해당합니다. 다른 상품에는 적용되지 않는 그 상품만의 사양에 쓰세요(예: 특정 상품의 `Material: 100% cashmere`).

로컬 속성도 변형에는 쓸 수 있지만, 계층형 탐색 필터에는 쓸 수 없습니다.

## 흔한 속성 가져오기 오류

### 속성 열을 인식하지 못함

**원인:** 열 이름이 패턴을 정확히 따르지 않습니다. 공백이나 번호가 틀렸거나 이름을 줄여 썼습니다.

틀림: `Attribute1 name`, `attribute 1 name`, `Attr 1 name`
맞음: `Attribute 1 name`

**해결 방법:** `Attribute`와 번호 사이에 공백을 넣은 정확한 열 이름을 쓰세요.

### 변형 속성이 상위 상품과 맞지 않음

**원인:** 변형 행의 속성 이름이 상위 행의 속성 이름과 다르거나, 변형에 상위 상품의 값 목록에 없는 값이 들어 있습니다.

**해결 방법:** 속성 이름은 상위 행과 변형 행에서 똑같아야 합니다. 변형 값은 상위 행에 나열한 값 중 하나여야 합니다.

### 세로 막대로 구분된 값

**원인:** WooCommerce 관리 화면에 보이는 대로 값 사이에 `|`를 썼습니다(`Blue | Red`). CSV 가져오기는 쉼표로 값을 나누므로 `Blue | Red`는 "Blue | Red"라는 값 하나가 됩니다.

**해결 방법:** 값은 쉼표로 구분하세요: `Blue, Red`. 값 안에 쉼표를 넣으려면 `\,`로 쓰세요. StriveFormats가 세로 막대로 구분된 값을 쉼표로 바꿔 줍니다.
