## Come Shopify rappresenta le varianti nel CSV

Nel CSV dei prodotti Shopify, un prodotto con più varianti è rappresentato da **più righe con lo stesso Handle**. La prima riga è la riga "principale": contiene i dati del prodotto. Ogni riga successiva con lo stesso Handle è una riga di variante.

### Esempio minimo: t-shirt in due taglie

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Variant SKU,Image Src
blue-shirt,Blue T-Shirt,Size,Small,19.99,BLUE-SM,https://cdn.example.com/shirt.jpg
blue-shirt,,Size,Medium,21.99,BLUE-MD,
```

Da notare:
- Entrambe le righe hanno l'Handle `blue-shirt`.
- La seconda riga ha Title vuoto, Image Src vuoto e un nuovo Option1 Value.
- Ogni riga rappresenta una variante acquistabile (una combinazione di valori delle opzioni).

---

## La riga principale

La prima riga di ogni Handle è la riga principale. Imposta i campi del prodotto:

| Colonna | Obbligatoria nella principale | Note |
|---|---|---|
| Handle | Sì | Identificativo univoco del prodotto; minuscole e solo trattini |
| Title | Sì | Il nome del prodotto |
| Body HTML | No | Descrizione del prodotto; serve solo nella riga principale |
| Vendor | No | Nome del marchio |
| Type | No | Tipo di prodotto (per le collezioni) |
| Tags | No | Tag separati da virgole |
| Published | No | true o false |
| Option1 Name | Sì (con le opzioni) | Nome della prima opzione (ad es. "Size") |
| Option1 Value | Sì (con le opzioni) | Valore della prima variante (ad es. "Small") |
| Image Src | No | URL dell'immagine principale |

**La riga principale deve avere un Title.** Se il Title è vuoto, Shopify non la riconosce come riga principale e l'importazione può dare risultati errati.

---

## Righe di variante

Ogni riga dopo la prima con lo stesso Handle è una riga di variante. Le righe di variante:
- Hanno lo stesso Handle della riga principale.
- Hanno il Title vuoto (o lo stesso Title: Shopify lo ignora fuori dalla riga principale).
- Hanno il proprio Option1 Value (e Option2 Value, Option3 Value se presenti).
- Hanno i propri Variant Price, Variant SKU, Variant Inventory Qty, ecc.

### Colonne specifiche delle varianti

| Colonna | Note |
|---|---|
| Variant Price | Obbligatoria per ogni variante; numero decimale (senza simbolo di valuta) |
| Variant SKU | Facoltativa ma fortemente consigliata; deve essere univoca in tutto il negozio |
| Variant Grams | Peso in grammi |
| Variant Inventory Qty | Giacenza iniziale |
| Variant Inventory Policy | `deny` o `continue` (continue = consenti la vendita senza giacenza) |
| Variant Fulfillment Service | Di solito `manual` |
| Variant Requires Shipping | true o false |
| Variant Taxable | true o false |
| Variant Barcode | EAN, UPC o altro codice a barre |

## Più opzioni (taglia E colore)

Shopify supporta fino a tre opzioni tramite le colonne Option1, Option2 e Option3.

Esempio: t-shirt con taglia e colore

```
Handle,Title,Option1 Name,Option1 Value,Option2 Name,Option2 Value,Variant Price,Variant SKU
blue-shirt,Blue T-Shirt,Size,Small,Color,Blue,19.99,BLUE-SM-BLU
blue-shirt,,Size,Small,Color,Red,19.99,BLUE-SM-RED
blue-shirt,,Size,Medium,Color,Blue,21.99,BLUE-MD-BLU
blue-shirt,,Size,Medium,Color,Red,21.99,BLUE-MD-RED
```

- Option1 Name e Option2 Name devono comparire solo nella riga principale (la prima di ogni Handle). Ripeterli nelle righe di variante non crea problemi.
- Ogni combinazione di opzioni ha bisogno di una propria riga.
- Un prodotto con 3 taglie e 4 colori richiede 12 righe di variante.

## Errori comuni

### Errore 1: Handle diversi per lo stesso prodotto

**Sintomo:** Quello che dovrebbe essere un prodotto con varianti compare come più prodotti separati dopo l'importazione.

**Soluzione:** Tutte le righe di un prodotto devono avere esattamente lo stesso Handle. Un errore di battitura (`blue-shirt` invece di `blue-shirt-`) fa creare a Shopify un nuovo prodotto.

### Errore 2: Title in ogni riga

**Sintomo:** L'importazione riesce, ma Shopify crea prodotti duplicati o tratta le righe di variante come prodotti a sé.

**Soluzione:** Solo la prima riga di ogni Handle deve avere un Title. Lascia vuoto il Title in tutte le righe di variante.

### Errore 3: manca la colonna Option1 Name

**Sintomo:** Errore di importazione "Option1 Name is required" oppure tutte le varianti compaiono come un'unica opzione chiamata "Default Title".

**Soluzione:** Includi sempre `Option1 Name` nell'intestazione, con un valore almeno nella riga principale. Se il prodotto non ha vere opzioni, imposta Option1 Name su `Title` e Option1 Value su `Default Title`.

### Errore 4: valori delle opzioni non coerenti tra le righe

**Sintomo:** Shopify crea più varianti del previsto o i nomi delle opzioni compaiono doppi.

**Soluzione:** Option1 Name deve essere esattamente lo stesso testo in tutte le righe di un Handle. Se la riga principale dice `Size`, anche ogni riga di variante deve dire `Size` (o restare vuota). Mescolare `Size`, `size` e `Sizes` crea dati delle opzioni incoerenti.

### Errore 5: Variant Price vuoto

**Sintomo:** L'importazione fallisce con "Variant Price is required" oppure le varianti vengono create con prezzo 0.00.

**Soluzione:** Variant Price è obbligatorio in ogni riga. Non viene ereditato: anche se tutte le varianti hanno lo stesso prezzo, ogni riga deve indicarlo.

### Errore 6: aggiungere una variante sovrascrive quelle esistenti

**Sintomo:** Dopo un'importazione parziale (aggiungendo una sola nuova variante), tutte le altre varianti spariscono.

**Soluzione:** Quando aggiorni un prodotto con un'importazione CSV, devi includere nel file **tutte** le varianti esistenti, non solo quella nuova. L'importazione di Shopify sostituisce l'intero insieme di varianti di un Handle. Le varianti omesse vengono eliminate.

## Consigli per i cataloghi grandi

- **Genera le righe di variante in automatico.** Per prodotti con molte combinazioni (3 taglie × 4 colori × 2 materiali = 24 righe), usa una formula del foglio di calcolo o uno script invece di inserirle a mano.
- **Usa schemi di SKU coerenti.** Uno SKU come `BASE-TAGLIA-COLORE` (ad es. `SHIRT-SM-BLU`) rende le varianti facili da riconoscere e ordinare.
- **Fai prima una prova con un prodotto.** Importa un singolo prodotto (riga principale e tutte le varianti) prima di caricare l'intero catalogo. Controlla la struttura delle varianti nel pannello di Shopify prima di procedere.
