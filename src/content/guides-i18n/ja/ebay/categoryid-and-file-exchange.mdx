## CategoryID とは

eBay の一括出品 CSV にある `Category` 列（File Exchange テンプレートのバージョンによっては `CategoryID`）は、商品が属する eBay カテゴリを表す**数値の識別子**です。eBay で出品中の商品にはすべてカテゴリが必要で、eBay はこの ID を使って次のことを決めます。

- カテゴリを閲覧したときに出品がどこに表示されるか。
- 出品にどの商品詳細（必須項目）が適用されるか。
- 購入者のどの検索で商品が表示されるか。

CategoryID が空や誤りだと、File Exchange のアップロードが丸ごと失敗したり、商品詳細が不完全な出品ができたりします。よくある原因の 1 つです。

---

## CategoryID とカテゴリのパス

CSV に必要なのは人が読むカテゴリのパスではなく、**数字**（CategoryID）です。例：

| カテゴリのパス | CategoryID |
|---|---|
| Clothing, Shoes & Accessories > Men > Men's Clothing > Shirts > T-Shirts | 15687 |
| Cameras & Photo > Digital Cameras | 31388 |
| Health & Beauty > Vitamins & Dietary Supplements | 180959 |

CSV にパスの文字列は使えません。数値の ID でなければなりません。

---

## 商品詳細にとって CategoryID が重要な理由

eBay の商品詳細（ブランド、サイズ、色、素材など）はカテゴリによって決まります。カテゴリを間違えると、次のようになります。
- 正しいカテゴリの必須の商品詳細が求められず、確認もされない。
- 必須の商品詳細が欠けていると、検索結果で出品の表示順位が下がることがある。
- あなたのカテゴリで商品詳細で絞り込む購入者に、出品が見つからない。

広い親カテゴリではなく、商品を正確に表す最も具体的なカテゴリ（最下層のカテゴリ）を必ず選びましょう。

---

## 正しい CategoryID の見つけ方

### 方法 1：eBay のカテゴリ候補（Seller Hub）

1. Seller Hub で、商品の 1 つについて手動で下書きの出品を作成します。
2. 「カテゴリ」の手順で、検索ボックスに商品の種類を入力します。
3. eBay がキーワードに基づいてカテゴリを提案します。
4. 最も具体的に当てはまるカテゴリを選びます。
5. カテゴリ名を控え、下のいずれかの方法で ID を調べます。

### 方法 2：eBay のカテゴリ ID 一覧

Seller Hub Reports のヘルプには、一括アップロード用のカテゴリ名と ID の一覧へのリンクがあります。

1. **Seller Hub → レポート → アップロード** を開き、アップロード用テンプレートのヘルプを開きます。
2. カテゴリ名と ID の一覧を開き、商品の種類を探します。
3. 開発者は eBay の API（Taxonomy API など）からカテゴリツリー全体を取得することもできます。

### 方法 3：既存の出品の URL を見る

同じカテゴリに自分の出品や競合の出品がある場合：

1. eBay でカテゴリのページを開きます（出品の上にあるパンくずリストのカテゴリ名をクリック）。
2. カテゴリのページの URL は `https://www.ebay.com/b/Levis-Mens-Jeans/11483/bn_700176` のような形です。
3. カテゴリ名の後の数字（`11483`、メンズジーンズ）がカテゴリ ID です。

### 方法 4：カテゴリ別テンプレートをダウンロードする

**Seller Hub → レポート → アップロード** では、特定のカテゴリ用の出品テンプレートをダウンロードできます。そこで選んだカテゴリ ID を、そのままファイルに使います。

## File Exchange の CSV での CategoryID

eBay の出品テンプレートでは列名は `*Category`（アスタリスクは必須列の印）、下書きテンプレートでは `Category ID` です。

```
*Action(SiteID=US|Country=US|Currency=USD|Version=1193),*Title,*Category,*StartPrice,...
Add,Men's Blue Cotton T-Shirt,15687,19.99,...
Add,Men's Slim Fit Jeans,11483,45.00,...
```

**ルール**：
- 値は、有効な eBay の最下層カテゴリに対応する正の整数である必要があります。
- 親カテゴリや中間のカテゴリは、通常は受け付けられません。最も具体的なカテゴリを使います。
- カテゴリは出品先の eBay サイトで有効なものでなければなりません（アメリカのカテゴリはイギリス、ドイツ、オーストラリアなどと異なります）。

## CategoryID をまとめて入力する

商品の大半がいくつかのカテゴリに収まる大きなカタログの場合：

### Excel：IF や VLOOKUP でカテゴリを割り当てる

商品の種類のコードが入った補助列がある場合：

```
=IF(B2="T-Shirts", 15687, IF(B2="Jeans", 11483, ""))
```

または参照表（商品の種類 → CategoryID）を作って VLOOKUP を使います。

```
=VLOOKUP(B2, CategoryTable!$A:$B, 2, FALSE)
```

### Excel：同じカテゴリのグループを下方向にコピーする

1. 商品リストを商品の種類で並べ替えます。
2. 各グループの最初の商品に CategoryID を入力します。
3. そのセルからグループの最後の商品までを選択します。
4. **Ctrl+D** で下方向にコピーします。

### フィルターを使う

1. 商品の種類の列でカタログを絞り込みます。
2. CategoryID 列の表示されているセルをすべて選択します。
3. CategoryID を入力し、**Ctrl+Enter** で選択したセルすべてに一度に入力します。

## アップロード前に CategoryID を確認する

CategoryID を間違えると、出品が違うカテゴリに作られます。よくある失敗で、気づきにくいものです。

1. **抜き取り確認**：CSV から CategoryID を 5 つ選び、eBay で調べて想定どおりのカテゴリのパスになっているか確認します。
2. **商品の種類の対応表と照合**：商品の種類 → CategoryID の簡単な表を作っておき、新しい種類を追加するときに見直します。
3. **テストアップロード**：まず 1〜3 行のテストファイルをアップロードします。作られた出品を見て、正しいカテゴリに入っているか確認します。
4. **eBay の結果ファイルを確認**：アップロードのたびに、Seller Hub Reports のアップロードのページに結果ファイルが用意されます。無効なカテゴリ ID に関する行エラーがないか確認します。

---

## よくあるエラー

| エラーメッセージ | 考えられる原因 |
|---|---|
| "Category is required" | CategoryID 列が空欄 |
| "Invalid category" | ID が有効な eBay の最下層カテゴリではない |
| "Category not allowed for this listing type" | 固定価格かオークションかによるカテゴリの制限 |
| アップロード後の商品詳細のエラー | カテゴリが違うため、商品詳細が商品に合っていない |
