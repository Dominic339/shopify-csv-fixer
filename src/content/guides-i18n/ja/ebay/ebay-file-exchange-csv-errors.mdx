## eBay は一括アップロードをどう確認するか

eBay の出品の一括アップロードは現在、**Seller Hub → レポート → アップロード** から行います。File Exchange 形式の CSV テンプレートもここからダウンロードできます。ファイルをアップロードすると、eBay は次の点を確認します。

1. **ファイルの構成**：先頭の INFO 行と、その下のヘッダー行
2. **Action 列**：各出品行をどう処理するか
3. **データ型**：価格は数値、数量は整数、URL は完全なウェブアドレス
4. **ビジネスルール**：有効なカテゴリ ID、そのカテゴリで使える状態 ID、有効な出品期間
5. **内容のルール**：タイトルの長さと出品ポリシー

処理が終わると、アップロードのページに結果ファイルが用意されます。成功した行、失敗した行とその理由がわかります。eBay は一部の行だけを取り込み、残りを拒否することがよくあるので、必ず確認してください。

## エラー：テンプレートが認識されない（INFO 行）

eBay の現在のテンプレートは、列見出しの上にこのような行で始まります。

```
#INFO,Version=1.0.0,Template=fx_category_template_EBAY_US
```

アップロードには最初の INFO 行が必要です。`#INFO` や `INFO` で始まるそれ以外の行（テンプレート内の説明）は、残しても削除しても構いません。

**対処法**：
- メモのように見えても、テンプレートの 1 行目は削除しないでください。
- Mac の Excel を使っている場合は、1 行目の `#INFO` の前に何も入っていないか確認してください。Excel がそこに見えない文字を追加することがあり、その場合 eBay はファイルを拒否します。テキストエディタで CSV を開くと確認できます。

StriveFormats は INFO 行の下にあるヘッダー行を読み取り、ダウンロード時には余計な文字を取り除いたうえで INFO 行を先頭に戻します。

## エラー：Action が空、または無効

出品の行にはすべて Action が必要です。例外はバリエーション行（`Relationship` = `Variation`）で、親の出品の下に置き、Action は空欄にします。

使える値：

| 値 | 意味 |
|---|---|
| `Add` | 新しい出品を作成する |
| `VerifyAdd` | 新しい出品を公開せずに確認し、手数料を表示する |
| `Revise` | 出品中の項目を変更する |
| `Relist` | 終了した出品を再出品する |
| `End` | 出品中の商品を終了する（`EndCode` を付ける） |
| `Status` | 販売済み商品のステータスを変更する（発送済みにするなど） |
| `AddToItemDescription` | 出品中の商品説明の末尾に文章を追加する |
| `Draft` | 出品を下書きに保存する（下書きテンプレートのみ） |

**対処法**：出品の行には上の値のいずれかを、この通りの表記で入れてください。eBay は完全一致で比較するため、`verifyadd` と `VerifyAdd` は別物です。

## エラー：カテゴリが無効

**原因**：`Category`（または `Category ID`）の値が eBay の有効な数値のカテゴリ ID ではない、またはそのカテゴリが廃止されている。

eBay のカテゴリ ID は数字です（たとえば eBay アメリカのメンズ T シャツは `15687`）。eBay がカテゴリを再編すると、ときどき変わります。

**対処法**：
- eBay のカテゴリツリーで正しいカテゴリ ID を調べる
- 古いテンプレートのカテゴリ ID は、まだ有効か確かめずに流用しない
- 追加の商品詳細が必要なカテゴリもあるので、そのカテゴリに何が必要か確認する

ID の調べ方は [eBay CategoryID：意味と設定方法](/guides/ebay/categoryid-and-file-exchange) を参照してください。

## エラー：タイトルが長すぎる

**原因**：`Title` の値が、eBay の出品タイトルの上限である 80 文字を超えている。

**対処法**：

Excel で補助列を追加します：`=LEN(B2)`（B2 はタイトル列のセルに置き換えます）。長さが 80 を超える行で絞り込み、そのタイトルを短くします。

Python の場合：

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for i, row in enumerate(reader, 2):
        title_len = len(row.get("Title", ""))
        if title_len > 80:
            print(f"Row {i}: Title is {title_len} chars (max 80): {row['Title'][:60]}...")
```

## エラー：状態 ID が無効

**原因**：`ConditionID` の値が eBay の有効な状態 ID ではない、またはその商品のカテゴリで使えない。

eBay の状態一覧にある主な状態 ID：

| ID | 状態 | 補足 |
|---|---|---|
| `1000` | New | Brand New、New with tags、New with box と表示されることもある |
| `1500` | New other | タグや箱のない新品、開封済み |
| `1750` | New with defects | |
| `2000` | Certified Refurbished | 一部のカテゴリで承認を受けたセラーのみ |
| `2500` | Seller refurbished | 一部のカテゴリでは下の整備済みグレードに置き換え |
| `2010` / `2020` / `2030` | Excellent / Very Good / Good - Refurbished | 一部のカテゴリで承認を受けたセラーのみ |
| `2750` | Like New | |
| `3000` | Used | Pre-owned と表示されることもある |
| `4000` | Very Good | |
| `5000` | Good | |
| `6000` | Acceptable | |
| `7000` | For parts or not working | 意味のあるカテゴリでのみ |

使える ID はカテゴリによって異なり、購入者に表示される名前もカテゴリごとに変わります。

**対処法**：状態の名前を数値の ID に置き換えます。StriveFormats は eBay の状態名（「Used」や「Open box」など）を自動で ID に変換します。

## エラー：StartPrice が無効

**原因**：`StartPrice` に通貨記号（`$9.99`）が入っている、小数点にカンマを使っている（`9,99`）、負の値、または空欄。

**対処法**：
- 検索と置換で通貨記号を削除する
- 小数点のカンマをピリオドに置き換える
- すべての価格が正の小数になっているか確認する
- 保存前に Excel で列の書式を数値にする

---

## エラー：Duration が無効

**原因**：`Duration` に、その出品形式で eBay が受け付けない値が入っている。

**使える値**：

| 形式 | Duration |
|---|---|
| `FixedPrice` | `GTC`（Good 'Til Cancelled）。固定価格の出品には、もう日数を指定できません |
| `Auction` | `Days_1`、`Days_3`、`Days_5`、`Days_7`、`Days_10` |

**対処法**：固定価格の出品には `GTC`、オークションには `Days_` の値のいずれかを使います。

---

## エラー：画像 URL にアクセスできない

**原因**：`PicURL` に、eBay がダウンロードできない URL が入っている。画像がログインの先にある、自分のパソコンにある、またはリダイレクトの先にある。

eBay の Seller Hub Reports では、`PicURL` に 1 出品あたり最大 **24 枚**の画像を縦棒 `|` で区切って入れられます。各 URL は最大 2048 文字で、URL 内のスペースは `%20` と書く必要があります。

**対処法**：
- 各 URL をブラウザのプライベートウィンドウで開き、ログインなしで画像が直接表示されることを確認する
- 完全な `https://` の URL を使う
- スペースを `%20` に置き換える（StriveFormats が自動で行います）
- 短縮 URL やリダイレクトサービスは使わない

---

## エラー：商品番号や UPC が 1.23457E+11 と表示される

**原因**：Excel が長い数値（`ItemID` や `P:UPC` のバーコード）を指数表記に変えてしまった。先頭の数桁より後の数字が失われ、eBay は出品を見つけられず、商品も照合できません。

**対処法**：手元の記録から正しい番号を入力し直します。eBay のヘルプでは、保存前に商品番号の列を小数点以下 0 桁の数値にするよう勧めています。文字列の書式でも構いません。StriveFormats はこれが起きたセルをすべて指摘します。

---

## エラー：数量が無効

**原因**：`Quantity` が空欄、小数（`1.5` など）、または負の値。

**対処法**：整数を使います。新しい出品の数量は 1 以上にしてください。バリエーションのある出品では、各バリエーションの数量を親の行ではなく、それぞれの行に入れます。

---

## すべてをアップロードする前に試す

1. INFO 行とヘッダー行を残したまま、2〜3 行を新しいファイルにコピーします。
2. その行の Action を `VerifyAdd` にしてアップロードします。eBay は行を確認し、何も出品せずに手数料を表示します。
3. 結果ファイルの指摘を直してから、ファイル全体の Action を `Add` に戻します。
