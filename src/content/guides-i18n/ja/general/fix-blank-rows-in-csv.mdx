## 空白行がインポートの問題になる理由

CSV の空白行とは、すべての項目が空の行（または値のないカンマだけの行）のことです。多くのインポート機能は完全な空白行を単に飛ばしますが、プラットフォームによっては次のようなことが起こります。

- **空の商品レコードができる**（Title も Price も空）。必須項目の検証で失敗します
- **インポートが止まる**。空白行で処理が止まり、それ以降はすべて黙って無視されます
- **検証エラーが出る**。空白行に欠けている必須項目ごとにエラーになります

空白行ができやすい場所：

- **ファイルの末尾**（スプレッドシートが自動で 1 行加えることがよくあります）
- **商品と商品の間**（行を削除したつもりで空の行が残った）
- **セクションの間**（見た目のために間を空けてシートを整理した場合）
- **セルの内容を消したあと**：Delete キーは行のセルを空にするだけで、空の行はそのまま残ります

## 空白行を見つける

### テキストエディタで

ファイルを VS Code やメモ帳で開くと、空白行はすぐにわかります。カンマだけの行か、まったく空の行です。

```
Handle,Title,Price
blue-shirt,Blue T-Shirt,19.99
                          ← 空白行（カンマだけ、または何もない）
red-shirt,Red T-Shirt,21.99
```

### Excel で

`Ctrl+End` を押すと、使用範囲の最後のセルに移動します。最後の行がデータより下（空の行）なら、Excel は空白行を使用範囲に含めています。

すべての空白行を見つけるには、最後の列の後ろに補助列を追加し、2 行目に `=COUNTA(A2:Z2)` と入力して（範囲はすべての列を含むように広げます）下までコピーします。`0` と表示された行は完全な空白行です。

`Title` のような 1 つの列だけで空欄を探してはいけません。Shopify のファイルでは、バリエーションの行は `Title` を意図的に空にしていて、空白行ではありません。

## Excel で空白行を削除する

**方法 1：末尾の空白行を削除する**

1. `Ctrl+End` を押して、Excel がデータの終わりと見なしている位置を確認します
2. 最後のデータ行より下なら、データの下にある余分な行を選択します
3. 右クリック → 削除
4. もう一度 `Ctrl+End` を押して、使用範囲が正しくなったことを確認します

**方法 2：補助列を使ってすべての空白行を削除する**

1. 上で説明した `=COUNTA(A2:Z2)` の補助列を追加します
2. フィルターをオンにして（データ → フィルター）、補助列が `0` の行だけを表示します
3. その行を選択して、右クリック → 行の削除
4. フィルターを解除し、補助列を削除します

1 つの列に対して「ジャンプ → セル選択 → 空白セル」を使うのは避けてください。その列がたまたま空の行がすべて削除され、正しいバリエーションの行まで消えてしまいます。

## Google スプレッドシートで空白行を削除する

同じ補助列とフィルターを使います。

1. `=COUNTA(A2:Z2)` の補助列を追加して下までコピーします
2. フィルターを追加します（データ → フィルタを作成）
3. 補助列のフィルターで `0` だけを表示します
4. 表示された行を選択して削除します（右クリック → 選択した行を削除）
5. フィルターをオフにし、補助列を削除します

並べ替えでも空白行は下に集まりますが、行の順番が関係ないファイルでだけ使ってください。Shopify の商品、WooCommerce のバリエーション、eBay のバリエーション出品は、行の順番が保たれていることが前提です。

## Python で空白行を削除する

大きなファイルでは Python がいちばん速い方法です。

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f_in, \
     open("output.csv", "w", newline="", encoding="utf-8") as f_out:
    reader = csv.reader(f_in)
    writer = csv.writer(f_out)
    for row in reader:
        # 空白以外の値を持つ項目が 1 つでもあれば、その行を残す
        if any(cell.strip() for cell in row):
            writer.writerow(row)
```

これでスペースだけの行（空に見えるが、スペースやタブが入っている行）も取り除けます。

## スペースだけの行

スプレッドシートでは空に見えても、実際には 1 つ以上のセルにスペースやタブが入っている行があります。単純な「行が空か」の確認では見つかりません。

**Python で見つける**：

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for i, row in enumerate(reader, 1):
        if not any(cell.strip() for cell in row):
            print(f"Blank or whitespace-only row at line {i}")
```

前のセクションの方法（`cell.strip()` を使うもの）なら、これらも自動で取り除けます。

## 今後の書き出しで空白行を防ぐ

- **Excel**：CSV で保存する前に `Ctrl+End` を押し、データのある最後の行が本当に使用範囲の最後の行か確認します。その下の行は削除します。
- **Google スプレッドシート**：CSV のダウンロードには、最後の空でないセルまでのすべての行が含まれるので、データを詰めておきます。
- **行を削除するとき**：Excel では行番号を右クリック → 削除を使います（セルの内容に Delete キーを押すだけだと、空の行が残ります）。
- **フィルターをかけたあと**：Excel の CSV 書き出しには、フィルターで非表示になった行も含まれます。書き出す前にフィルターを解除し、シートに実際に何があるか確認します。
