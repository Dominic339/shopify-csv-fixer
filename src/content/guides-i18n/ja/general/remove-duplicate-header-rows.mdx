## 重複したヘッダー行とは？

重複したヘッダー行とは、CSV の 1 行目（列名）がデータ部分のどこかにもう一度現れる状態です。例：

```
Handle,Title,Vendor,Variant Price
blue-shirt,Blue T-Shirt,Acme,19.99
Handle,Title,Vendor,Variant Price   ← 繰り返されたヘッダー行
red-shirt,Red T-Shirt,Acme,21.99
```

インポートツールはデータ行に `Handle` を見つけると、その行を商品として読み込めません。多くのプラットフォームはその行を黙ってスキップするか、形式エラーを出します。失敗した行として数えるものもあります。

---

## ヘッダーが重複する理由

### 複数のエクスポートファイルを結合した

最も多い原因は、2 つの CSV を Excel や Google スプレッドシートでコピー＆ペーストして結合することです。2 つ目のファイルのヘッダー行が、結合したファイルの途中に入り込みます。

### ページ分割されたエクスポート

データをページ単位（たとえば 1 ファイル 500 行）でエクスポートするプラットフォームがあります。すべてのページをダウンロードしてつなげると、各ファイルのヘッダー行も一緒に追加されます。

### 定期的なレポートシステム

毎日 CSV に行を追記する自動システムは、追記するブロックごとに先頭でヘッダーを繰り返すことがあります。

### Excel の「すべて更新」や Power Query のエクスポート

Excel でデータ接続を更新すると、クエリの設定が誤っている場合にヘッダー行が再び挿入されることがあります。

## 重複したヘッダー行を見つける

### Excel の場合

1. CSV を開きます（書式を保つため、ダブルクリックではなく **データ → テキストまたは CSV から** を使います）。
2. データ内の任意のセルをクリックします。
3. **データ → フィルター** でフィルタを有効にします。
4. **Handle** 列（または先頭の列）の矢印をクリックします。
5. 検索ボックスにヘッダー名をそのまま入力します（例：`Handle`）。
6. フィルタ結果に行が表示されたら、それが重複したヘッダー行です。

### Google スプレッドシートの場合

1. すべてのデータを選択します（**Ctrl+A**）。
2. **データ → フィルタを作成** を選びます。
3. 先頭の列の矢印をクリックします。
4. フィルタのテキストボックスにヘッダー名を入力します（例：`Handle`）。
5. その値が表示されている行はすべて重複したヘッダーです。

### 数式で印を付ける

空いている列で、各行の横に次の数式を入れて重複に印を付けます。

```
=IF(A2="Handle","DUPLICATE HEADER","")
```

`"Handle"` は実際の先頭列の名前に置き換えてください。`DUPLICATE HEADER` でフィルタすると、すべての該当行が見つかります。

## 重複したヘッダー行を削除する

### 方法 1：フィルタして削除する（Excel / スプレッドシート）

1. 先頭の列をフィルタし、ヘッダーの値（例：`Handle`）を持つ行だけを表示します。
2. 表示されているフィルタ後の行をすべて選択します（最初の結果の行番号をクリックし、最後の行番号を Shift＋クリック）。
3. 右クリック → **行の削除**。
4. フィルタを解除します（データ → フィルターのクリア、またはフィルタ → オフ）。
5. データが欠けていないか確認します。

### 方法 2：並べ替えて削除し、元の順に戻す（Excel）

並べ替えると重複したヘッダー行がすべて 1 か所に集まりますが、商品の順序が変わるため、必ず後で元の順に戻してください。Shopify、WooCommerce、eBay のファイルは行の順序に依存します。

1. 元の順序を記録するため、行番号（1、2、3…）を入れた補助列を追加します。
2. 先頭の列で A から Z へ並べ替えます。
3. 重複したヘッダー行は、`Handle` がアルファベット順で値の間に入る位置にまとまって並びます（Excel の並べ替えは大文字と小文字を区別しないので、H で始まる値の間を探してください）。
4. その行のまとまりを選択して削除します。
5. 補助列で並べ替えて元の順序に戻します。
6. 補助列を削除します。

### 方法 3：テキストエディタ（大きなファイル）

Excel では大きすぎるファイル（およそ 100,000 行超）には、VS Code か Notepad++ を使います。

**VS Code：**
1. ファイルを開きます。
2. **Ctrl+H**（検索と置換）を押します。
3. **正規表現** モード（`.*` アイコン）を有効にします。
4. 検索欄に次を入力します：`^Handle,Title,Vendor,Variant Price\r?\n`
   （実際のヘッダーに置き換え、必要に応じてエスケープします）
5. 置換欄は空のままにします。
6. **すべて置換** をクリックします。
7. 重複をすべて削除したら、ヘッダーを手作業で 1 行目に戻します。

> 正規表現による置換には注意してください。元のファイルは必ずバックアップとして残し、置換後にヘッダーがちょうど 1 回だけ現れることを確認します。

**Notepad++（Windows）：**
1. ファイルを開く → **検索 → 置換**（Ctrl+H）。
2. **正規表現** モードを選びます。
3. 上の VS Code と同じパターンを使います。
4. すべて置換してから、ヘッダー行を手作業で戻します。

## 重複したヘッダーを削除した後

ファイルがきれいになったら：

1. ヘッダーが 1 行目にちょうど 1 回だけあることを確認します。
2. 行数を数えます。元の行数から削除した重複ヘッダーの数を引いた数になっているはずです。
3. 重複があった位置の近くの行をいくつか抜き取りで確認し、データが欠けていないことを確かめます。
4. **CSV UTF-8** として保存します（Excel では **ファイル → 名前を付けて保存 → CSV UTF-8**）。

## 次回の結合でヘッダーの重複を防ぐ

複数の CSV を手作業で結合するとき：

1. 最初のファイル（「ベース」ファイル）を Excel またはスプレッドシートで開きます。
2. 追加する各ファイルを開きます。
3. データをコピーする前に、追加ファイルの **ヘッダー行を削除** します。
4. データ行だけをコピーします。
5. ベースファイルの末尾に貼り付けます。

スクリプトで CSV の結合を自動化する場合は、2 つ目以降のファイルのヘッダー行を必ず読み飛ばします。`csv.DictReader` は各ファイルのヘッダーを列名として読み込むので、ヘッダーがデータに混ざることはありません。

```python
# Python の例：すべてのファイルが同じ列を持つことを前提としています
import csv

files = ["export_page1.csv", "export_page2.csv"]

with open("combined.csv", "w", newline="", encoding="utf-8") as outfile:
    writer = None
    for filename in files:
        # utf-8-sig は BOM を取り除きます。残すと先頭列の名前が変わってしまいます
        with open(filename, newline="", encoding="utf-8-sig") as infile:
            reader = csv.DictReader(infile)
            if writer is None:
                writer = csv.DictWriter(outfile, fieldnames=reader.fieldnames)
                writer.writeheader()
            for row in reader:
                writer.writerow(row)
```

ファイルごとに列が異なる場合は、2 つの CSV ファイルを結合するガイドにあるスクリプトを使ってください。そちらはすべての列を残します。
