## 3 つの操作、3 つの意味

「CSV ファイルを組み合わせる」と言うとき、たいていは次の 3 つの操作のどれかを指しています。違う操作を選ぶと、データが失われたり構造が崩れたりします。

| 操作 | 変わるもの | 行数 | 列数 |
|---|---|---|---|
| **追加** | 行が増える | 増える | 同じ |
| **マージ** | 同じ構造の 2 つのファイルを 1 つにする | 増える | 同じ |
| **結合** | 関連するファイルから列を加える | 同じ | 増える |

---

## 追加：行を増やす

**何をするか**：2 つ目の CSV の行を、1 つ目の末尾に加えます。両方のファイルの列構成が完全に同じである必要があります。

**使う場面**：
- ページ分割されたエクスポートをまとめるとき（ファイル 1 = 1〜500 行、ファイル 2 = 501〜1000 行）。
- アップロード前に、既存のカタログファイルへ新しい商品をまとめて加えるとき。
- 同じ形式でエクスポートしている地域チームのファイルをまとめるとき。

**Excel で正しく追加する手順**：

1. ベースのファイルを開きます。
2. 2 つ目のファイルを開きます。
3. 2 つ目のファイルで **見出し行を削除** します（1 行目を右クリック → 削除）。
4. 残りのデータをすべて選択します（Ctrl+A。選択範囲が広すぎる場合は調整します）。
5. コピーします（Ctrl+C）。
6. ベースのファイルに切り替え、最後のデータ行の下にある最初の空のセルをクリックします。
7. 貼り付けます（Ctrl+V）。
8. CSV UTF-8 で保存します。

**避けるべき重大な間違い**：手順 3（見出しの削除）を飛ばすと、ファイルの途中に見出し行が重複し、どのインポート先でも失敗します。

**Google スプレッドシートで追加する手順**：

手順は同じです。2 つ目のファイルの見出し行を削除し、データ行だけをコピーして、ベースのシートの末尾に貼り付けます。

## マージ：同じ列を持つファイルをまとめる（複数のソースから）

**何をするか**：基本的には追加と同じですが、「マージ」は異なるソースから来た、同じ種類のデータを表すファイルをまとめるときによく使われる言葉です（たとえば、同じ形式の 2 社の仕入れ先の商品リスト）。

**使う場面**：
- 2 社の仕入れ先の商品フィードを、1 つのアップロード用ファイルにまとめるとき。
- 同じプラットフォームの CSV テンプレートを使う部署ごとのエクスポートをまとめるとき。

**マージで追加で気をつけること（単純な追加との違い）**：
- **重複行を確認する。** 両方のファイルに同じ商品があると、マージ後のファイルには 2 回入ります。重複は Handle（Shopify）、SKU（WooCommerce/Amazon）、Item ID（eBay）で見つけます。Excel では **データ → 重複の削除** を選び、キーの列を指定します。
- **列名をそろえる。** 仕入れ先 A が `Barcode`、仕入れ先 B が `UPC` という列名を使っているなら、マージの前にプラットフォームが求める列名に統一する必要があります。
- **値をそろえる。** 価格の通貨が違ったり、ステータスの書き方が違ったり（Published、TRUE、1 など）することがあります。

## 結合：関連するファイルから列を加える

**何をするか**：2 つのファイルを横に並べ、共通のキー列（SKU や Handle など）で行を対応させて、2 つ目のファイルの列を 1 つ目に加えます。

**使う場面**：
- ERP の商品リスト（Handle、Title、SKU、Price）と、別の在庫ファイル（SKU、Quantity、Warehouse Location）があり、各商品行に在庫数を加えたいとき。
- あるシステムから画像なしで商品をエクスポートしていて、SKU で対応づけた画像 URL のファイルが別にあるとき。
- インポートの前に、仕入れ先のデータ（仕入れ価格、仕入れ先の品番）を商品カタログに加えたいとき。

### Excel の VLOOKUP で結合する

前提：
- **ファイル A**（ベース）：A 列 = Handle、B 列 = Title、C 列 = Price
- **ファイル B**（参照先）：A 列 = Handle、B 列 = Quantity

ファイル B の Quantity をファイル A に加えます。

1. ファイル A に新しい列見出し `Quantity` を追加します（D 列）。
2. D2 に次のように入力します。
   ```
   =VLOOKUP(A2, '[FileB.csv]FileB'!$A:$B, 2, FALSE)
   ```
3. ファイル B は Excel で開いておく必要があります。Excel は CSV を開くとシートにファイル名を付けるので、`FileB.csv` のシート名は `FileB` です。キーが一致すれば Quantity が入ります。一致しない場合は `#N/A` が表示され、その Handle がファイル B にないことを意味します。
4. 数式をすべての行に下へコピーします。
5. 結果に問題がなければ D 列を選択してコピーし、**形式を選択して貼り付け → 値** で数式を固定の値に置き換えます。
6. ファイル B を閉じます。
7. ファイル A を CSV UTF-8 で保存します。

### Google スプレッドシートで結合する

同じ書き方で `VLOOKUP` を使います。または `IMPORTRANGE` で別の Google スプレッドシートからデータを取り込み、補助列を使う方法もあります。

### Python で結合する（大きなファイル）

```python
import csv

# 参照先のファイルを Handle をキーにした辞書に読み込む
lookup = {}
with open("inventory.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        lookup[row["Handle"]] = row["Quantity"]

# ベースのファイルに Quantity を加える
with open("products.csv", encoding="utf-8") as infile, \
     open("products_with_qty.csv", "w", newline="", encoding="utf-8") as outfile:
    reader = csv.DictReader(infile)
    fieldnames = reader.fieldnames + ["Quantity"]
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    writer.writeheader()
    for row in reader:
        row["Quantity"] = lookup.get(row["Handle"], "")
        writer.writerow(row)
```

## CSV ファイルを組み合わせるときによくある間違い

### 間違い 1：追加したあとに見出し行が重複する

**症状**：ファイルの途中で「認識できない行」といったエラーになり、インポートが失敗します。
**対処法**：追加する前に、最初のファイル以外の見出し行を必ず削除します。

### 間違い 2：追加したファイルで列の順番が違う

**症状**：追加したあと、データが違う列に入っています。
**対処法**：両方のファイルで、列名だけでなく列の順番も同じでなければなりません。ファイル B の列の順番が違う場合は、追加する前にファイル A に合わせて並べ替えます。

### 間違い 3：一意でないキーで結合する

**症状**：VLOOKUP が間違った在庫数を返します（最初に一致したものを使い、重複は無視されます）。
**対処法**：結合する前に、参照先のファイルでキー列（SKU、Handle）が一意であることを確認します。**データ → 重複の削除** を使うか、COUNTIF で確認します。

### 間違い 4：組み合わせたあとに文字コードがずれる

**症状**：元のファイルの 1 つから来た行で文字化けが起きます。
**対処法**：組み合わせる前に、すべての元ファイルを UTF-8 で保存します。UTF-8 でないファイルは VS Code で再エンコードします（文字コードのガイドを参照）。

### 間違い 5：追加した部分の間に空行がある

**症状**：インポートが空行で止まり、それ以降の行がすべて無視されます。
**対処法**：追加したあとに組み合わせたファイルを確認し、部分の間にある空行を削除します。

## すぐに選べる早見表

```
行を増やしたい？ → 追加またはマージ
列を増やしたい？ → 結合

同じシステムから出た、列がまったく同じファイル？ → 追加
別のシステムから出た、列のテンプレートが同じファイル？ → マージ（重複を確認）
商品データが 1 つのファイルに、補足データが別のファイルにある？ → 結合
```
