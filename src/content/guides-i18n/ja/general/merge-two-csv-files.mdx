## CSV ファイルを結合する必要があるのはどんなとき？

2 つの CSV ファイルを 1 つにまとめるのは、EC へのインポート前によくある作業です。次のような場面で必要になります。

- 2 社の仕入れ先の商品を、1 回のカタログのアップロードにまとめる
- 先月の商品エクスポートと新しく追加した商品を合わせる
- 大きなインポートを小さく分けたあと、もう一度まとめる
- 別々のソースにあるバリエーションの行を、1 つの商品 CSV にまとめる

このガイドでは、Excel の Power Query、Google スプレッドシート、コマンドライン、Python の 4 つの確実な方法を紹介します。どの方法も、1 つ目のファイルの見出し行を残し、2 つ目のファイルからはデータ行だけを追加します。

---

## 始める前に：見出しをそろえる

2 つのファイルには、同じ列の見出しが同じ順番で並んでいる必要があります。列が違うと、結合したときにデータが違う項目にずれ、インポートが壊れます。

結合前の簡単なチェックリスト：

- [ ] 両方のファイルを開き、1 行目（見出し）を並べて比べる
- [ ] 列名が完全に一致している（大文字・小文字を区別するプラットフォームもある）
- [ ] 両方のファイルで列の順番が同じ
- [ ] どちらのファイルにも集計行やフッター行がない
- [ ] 両方のファイルを UTF-8 で保存している

見出しの順番が違う場合は、結合する前に片方のファイルの列を並べ替えます。Python の DictWriter を使う方法（下の方法 4）なら、列の順番の違いを自動で処理できます。

## 方法 1：Excel の Power Query（Windows、おすすめ）

Excel の Power Query は、数式やマクロを使わずに複数の CSV を縦につなげます。ファイル間の文字コードや改行コードの違いを自動で処理し、見出し行を繰り返すこともありません。

### 手順

1. Excel で空のブックを開きます。
2. **データ** タブで **データの取得**、**ファイルから**、**テキストまたは CSV から** の順にクリックします。
3. **1 つ目の CSV ファイル** を選んで **インポート** をクリックします。プレビューが表示されたら、**データの変換** をクリックします（読み込みではありません）。
4. Power Query エディターで **ホーム** > **新しいソース** > **ファイル** > **テキスト/CSV** を選び、**2 つ目の CSV ファイル** を選んで **OK** をクリックします。これで両方のファイルが左側のパネルにクエリとして表示されます。
5. 1 つ目のクエリを選び、**ホーム** > **クエリの追加** > **クエリを新規クエリとして追加** を選びます。
6. ダイアログで **2 つのテーブル** を選び、一覧から 2 つ目のクエリを選びます。
7. 左側のパネルに、結合した新しいクエリが表示されます。**閉じて読み込む** をクリックして、新しいシートに書き出します。
8. 結合したシートをアクティブにした状態で **ファイル** > **名前を付けて保存** を選び、ファイルの種類に **CSV UTF-8 (コンマ区切り)** を選びます。Excel はアクティブなシートだけを保存します。普通の「CSV (コンマ区切り)」は古い文字コード（日本語版では Shift_JIS）を使うので、ほかのプラットフォームで文字化けすることがあります。

### Power Query を使う理由

- ファイルごとに文字コードを判定し、判定が違っていればプレビューで直せます。
- 見出し行は、ファイルごとではなく 1 回だけ追加されます。
- 2 つのファイルの間に余分な空行が入りません。
- 大きなファイルも扱えます。ただし、Excel のシートは 1 枚あたり 1,048,576 行までです。それ以上の行数は、コマンドラインか Python を使います。

## 方法 2：Google スプレッドシート（ブラウザで、小さめのファイル）

Excel がない場合、Google スプレッドシートが手軽です。合計でおよそ 5 万行未満のファイルに向いています。

### 手順

1. Google ドライブを開き、1 つ目の CSV をアップロードします。空いている場所を右クリックして **ファイルのアップロード** を選び、CSV を選んだら、アップロードしたファイルを右クリックして **アプリで開く > Google スプレッドシート** を選びます。
2. 最後のデータ行の行番号を控えます（たとえば、データ行が 499 行で見出し行が 1 行なら 500 行目）。
3. 2 つ目の CSV も同じ方法で、ブラウザの新しいタブで開きます。
4. 2 つ目のシートで行番号 **2**（見出しの下の最初のデータ行）をクリックします。**Ctrl+Shift+End** を押して、データのある最後の行と列まで選択を広げます。
5. **Ctrl+C** でコピーします。1 つ目のタブに切り替え、データの下にある最初の空の行をクリックします。
6. **Ctrl+V** でデータ行（見出しなし）を貼り付けます。
7. **ファイル** > **ダウンロード** > **カンマ区切り形式 (.csv)** を選びます。

### 注意点

- Google スプレッドシートは BOM なしの UTF-8 で書き出すので、結合したファイルはそのままアップロードできます。
- とても大きなファイル（10 万行以上）では、スプレッドシートが遅くなったり固まったりすることがあります。その場合はコマンドラインか Python を使います。
- 貼り付けた行が列とそろっているか確認します。1 列ずれるだけで、結合全体が壊れます。

## 方法 3：コマンドライン（最速、どんなサイズでも）

ターミナルが使えるなら、コマンドラインはファイルの大きさに関係なく 1 秒もかかりません。macOS と Linux では何もインストールする必要がありません。

### macOS または Linux

```bash
# file1.csv と file2.csv を merged.csv にまとめる
# tail -n +2 で 2 つ目のファイルの見出し行を飛ばす
cat file1.csv <(tail -n +2 file2.csv) > merged.csv
```

`file1.csv` の最後が改行で終わっていないと、その最後の行と `file2.csv` の最初の行が同じ行につながってしまいます。結果のつなぎ目を確認してください。

### Windows（コマンドプロンプト）

```bat
:: まず 1 つ目のファイルをコピーする
copy file1.csv merged.csv

:: 2 つ目のファイルの見出し以外のすべての行を追加する
more +1 file2.csv >> merged.csv
```

注意：Windows の `more +1` コマンドは最初の行を飛ばします。ただし、タブをスペースに変えたり、ASCII 以外の文字（日本語を含む）を壊したり、とても大きなファイルで止まったりするので、結果を確認するか、Windows では Python（方法 4）を使ってください。

### 結果を確認する

コマンドラインで結合したら、結果をテキストエディタで開いて次を確認します。

- 見出し行が 1 回だけ（いちばん上に）ある
- 2 つのファイルのデータの間に空行がない
- file1 の最後の行と file2 の最初のデータ行が、続いた行になっている
- 末尾に余分な改行がない（ほとんどのインポート機能は気にしませんが、ないほうがきれいです）

## 方法 4：Python（どの OS でも、列が違っても大丈夫）

Python の `csv.DictWriter` は、最も確実な結合方法です。列の順番の違い、片方のファイルにしかない列、大きなファイルにも対応できます。プログラミングの経験は不要で、Python をインストールして下のスクリプトを実行するだけです。

### スクリプト

```python
import csv

files_to_merge = ["file1.csv", "file2.csv"]
output_file = "merged.csv"

# すべての列名を、最初に現れた順に集める
fieldnames = []
for fname in files_to_merge:
    with open(fname, newline="", encoding="utf-8-sig") as f:
        for h in csv.DictReader(f).fieldnames or []:
            if h not in fieldnames:
                fieldnames.append(h)

with open(output_file, "w", newline="", encoding="utf-8") as out:
    # restval="" で、その列がないファイルの行は空のままにする
    writer = csv.DictWriter(out, fieldnames=fieldnames, restval="")
    writer.writeheader()
    for fname in files_to_merge:
        # utf-8-sig で、BOM があれば取り除く
        with open(fname, newline="", encoding="utf-8-sig") as f:
            for row in csv.DictReader(f):
                writer.writerow(row)

print(f"Done: merged {len(files_to_merge)} files into {output_file}")
```

このファイルを、CSV ファイルと同じフォルダに `merge.py` という名前で保存します。そのフォルダでターミナルかコマンドプロンプトを開き、次を実行します。

```
python merge.py
```

### Python を使う理由

- Windows、Mac、Linux で動きます。
- BOM を自動で取り除きます（utf-8-sig）。UTF-8 でないファイルは、先に変換しておきます（下の文字コードのセクションを参照）。
- DictWriter は位置ではなく列名で対応付けるので、列の順番が違っても大丈夫です。片方のファイルにない列は空になり、片方にしかない列も残ります。
- すべてをメモリに読み込まず 1 行ずつ処理するので、とても大きなファイルでも動きます。

## 結合すべきでない場面

結合は、同じ構造のファイルの行を縦に積み重ねるための方法です。次のような場合は結合しません。

- **ファイルの構造が違う。** file1 に 30 列、file2 に別の 25 列がある場合、そのまま結合するとデータがずれたファイルになります。すべての列を残して空欄にする Python の DictWriter の方法（方法 4）を使うか、先に構造をそろえます。
- **キーで突き合わせたい（SQL のような JOIN）。** 結合は行を積み重ねるだけで、共通の SKU、Handle、ID で 2 つのファイルの行を対応付けることはしません。キーで突き合わせるには、Python の `csv.DictReader` と辞書を使うか、pandas のようなツールを使います。
- **片方のファイルに合計、集計、ピボットテーブルがある。** 結合する前に、元のデータ行だけを書き出します。集計行、SUM の数式、平均の行は、結合すると商品データとして扱われてしまいます。
- **ファイルが違うエクスポートテンプレートから来ている。** Shopify の商品エクスポートと在庫エクスポートは列が違うため、行を追加して結合することはできません。

## 結合の前に見出しの不一致を直す

2 つのファイルの列は同じでも見出しの名前が違う場合（たとえば `Title` と `Product Title`、`Price` と `Variant Price`）は、結合の前に名前をそろえます。

### Excel や Google スプレッドシートで手で直す

1. 2 つのファイルを並べて開きます。
2. それぞれのファイルの 1 行目（見出し）を比べます。
3. 片方のファイルの標準でない見出しを、もう片方に合わせて名前を変えます。セルを直接編集します（Excel では F2 キー）。
4. 結合に進む前に、両方のファイルを CSV で保存します。

### Python で自動で直す

```python
import csv

# file2 の標準でない名前を、file1 で使っている標準の名前に対応付ける
RENAME = {
    "Product Title": "Title",
    "Price": "Variant Price",
    "SKU": "Variant SKU",
}

with open("file2.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    # 見出しの名前を変える
    fieldnames = [RENAME.get(h, h) for h in (reader.fieldnames or [])]
    rows = list(reader)

with open("file2_normalized.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    for row in rows:
        writer.writerow({RENAME.get(k, k): v for k, v in row.items()})
```

## 列の順番をそろえる

列名は同じで順番だけが違う場合、Python の DictWriter の方法（方法 4）は名前で対応付けるので自動で処理します。Excel やスプレッドシートでは、手で並べ替えます。

**Excel の場合**：
1. 片方のファイルで、1 行目の上に空の行を挿入します。
2. 結合先のファイルで並べたい順に、列に番号を振ります（1、2、3...）。
3. その番号の行で列を並べ替えます（データ > 並べ替え > オプション > 列単位、1 行目で並べ替え）。
4. 補助の番号行を削除します。

**Google スプレッドシートの場合**：
1. いちばん上に空の行を挿入します。
2. それぞれの列を置きたい位置の番号を入力します。
3. 補助のシートで `=CHOOSECOLS(Sheet1!A:Z, 3, 1, 2)`（並べたい順に列番号を書く）を使うか、列を正しい順番に手で切り取って貼り付けます。
4. ダウンロード > CSV。

## 結合したファイルから重複した見出し行を取り除く

結合したファイルの途中に、うっかり見出し行が重複して入ってしまった場合（同じツールのエクスポートを何回か結合したときによく起こります）は、Python で取り除きます。

```python
import csv

with open("merged.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.reader(f)
    rows = list(reader)

if not rows:
    raise ValueError("File is empty")

header = rows[0]
# 見出しと同じ行を取り除く（最初の見出しは残す）
clean = [header] + [r for r in rows[1:] if r != header]

with open("merged_clean.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(clean)

print(f"Removed {len(rows) - len(clean)} duplicate header row(s).")
```

## ファイル間の文字コードや区切り文字の違い

片方のファイルが UTF-8 で、もう片方が Shift_JIS や Windows-1252（ANSI）の場合、結合したファイルでは、ANSI のファイルにあった日本語、アクセント付きの文字、曲がった引用符、通貨記号がすべて文字化けします。

**結合する前に、ANSI のファイルを UTF-8 に変換します。**

macOS または Linux の場合（日本語版 Excel の CSV は多くの場合 `cp932`）：
```bash
iconv -f windows-1252 -t utf-8 file2_ansi.csv > file2_utf8.csv
```

Python の場合：
```python
with open("file2_ansi.csv", encoding="windows-1252") as f:
    content = f.read()
with open("file2_utf8.csv", "w", encoding="utf-8") as f:
    f.write(content)
```

文字コードは同じでも区切り文字が違う場合（カンマとセミコロン）は、結合する前に片方の区切り文字を変換します。CSV の基礎ガイドの区切り文字のセクションを参照してください。

## 結合したファイルのトラブルシューティング

| 問題 | 原因 | 直し方 |
|---|---|---|
| 結合したファイルの途中に余分な空行がある | 2 つ目のファイルの末尾に改行や集計行があった | 空行を削除するか、Python で `writer.writerow(row)` の前に `if any(row.values()):` を加える |
| 途中に見出し行が重複している | 2 つ目のファイルの見出しを飛ばし忘れた | `tail -n +2`（コマンドライン）か、見出しを自動で飛ばす Power Query のクエリの追加を使う |
| データが違う列にずれている | ファイル間で列の順番が違う | 先に片方のファイルの列を並べ替えるか、Python の DictWriter の方法を使う |
| 結合したファイルが文字化けしている | ファイルの文字コードが違う | 先に両方のファイルを UTF-8 に変換する。Mac/Linux なら iconv を使う：`iconv -f windows-1252 -t utf-8 file2.csv > file2_utf8.csv` |
| アップロード後に 1 列目が認識されない | 結合したファイルに、プラットフォームが読み違える BOM がある | VS Code で開き、BOM なしの UTF-8 で保存し直す |

---

## してはいけないこと

- **大きなファイルや複雑なファイルで、手作業のコピー＆ペーストに頼らない。** 行を飛ばしたり、1 列ずれて貼り付けたり、見出しをうっかり繰り返したりしやすくなります。方法 2 は結果を確認すれば小さなファイルには使えますが、それ以外は Power Query、コマンドライン、Python を使います。
- **両方のファイルを Excel でダブルクリックして開き、行を切り取って貼り付けない。** その開き方では、Excel が日付、長い数値、先頭のゼロの書式を変え、気づかないうちにデータを壊します。
- **列の数が違うファイルを、見出しを直さずに結合しない。** 結果はデータがずれたファイルになります。

## 結合後のチェックリスト

結合したファイルをインポートする前に、次を確認します。

- [ ] 見出し行が 1 回だけある（1 行目にあり、途中で繰り返されていない）
- [ ] 行数が正しい：（file1 の行数 − 見出し 1 行）＋（file2 の行数 − 見出し 1 行）＝データ行の合計
- [ ] 2 つのファイルのデータの間に余分な空行がない
- [ ] 重複してはいけない SKU や Handle が重複していない（CSV 修正ツールで確認）
- [ ] 両方の元ファイルの列がすべてそろっている（構造の違うファイルを DictWriter で結合した場合）
- [ ] ファイルを UTF-8 で保存している
- [ ] 拡張子が .csv で、中身がカンマ区切りのプレーンテキストである

## 結合したら：インポートの前に検証する

結合したら、インポートする前に、まとめたファイルを CSV 修正ツールで確認します。結合によって、どちらの元ファイルにもなかった問題が生じることがあります。

- 途中に余分な見出し行がある（修正ツールが構造の問題として検出します）
- SKU や Handle の重複（重複チェックで検出します）
- 文字コードの不一致（修正ツールの文字コード分析で検出します）

結合した CSV を修正ツールにアップロードし、プラットフォームに送る前にファイル全体を検証させましょう。
