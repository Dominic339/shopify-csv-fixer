## Etsy の出品 CSV とは（できないこと）

Etsy では、出品中の商品を CSV でダウンロードできます。**ショップマネージャー → 設定 → オプション → データのダウンロード** を開き、出品の CSV ダウンロードを選びます。Etsy のヘルプによると、ファイルには各出品の次の情報が入っています。

- タイトル
- 説明
- 価格と通貨コード
- 数量
- タグ
- 素材
- 画像 URL
- SKU（出品に SKU を追加している場合）

**Etsy には出品の CSV アップロードがありません。** ファイルを編集してもショップには何も反映されず、Etsy にはファイルを取り込み直す方法もありません。セラーはこのエクスポートを次のように使います。

- スプレッドシートで出品データを確認し、整理する
- カタログのバックアップを残す
- Shopify や WooCommerce など別のプラットフォームに出品を移す
- Etsy の API を使う他社製の一括出品アプリにデータを渡す

Etsy 上でまとめて変更するには、ショップマネージャーの出品ページにある一括編集の機能を使ってください。

## エクスポートの列

ファイルでは項目ごとに列が分かれていて、見出しは `TITLE`、`DESCRIPTION`、`PRICE`、`CURRENCY_CODE`、`QUANTITY`、`TAGS`、`MATERIALS`、`SKU` などです。写真は 1 枚ずつ別の列（`IMAGE1`、`IMAGE2` など）になり、画像の URL が入ります。

| 列 | 内容 | 書式 |
|---|---|---|
| `TITLE` | 出品タイトル | 140 文字まで |
| `DESCRIPTION` | 出品の説明 | プレーンテキスト |
| `PRICE` | ショップの通貨での価格 | `14.99` のような普通の数値 |
| `CURRENCY_CODE` | ショップの通貨 | `USD` のような 3 文字のコード |
| `QUANTITY` | 在庫数 | 999 までの整数 |
| `TAGS` | 検索タグ | カンマ区切り、13 個まで |
| `MATERIALS` | 素材 | カンマ区切り、13 個まで |
| `IMAGE1`、`IMAGE2`、... | 写真の URL | 完全な `https://` の URL |
| `SKU` | 自分の SKU | テキスト |

ツールでファイルを読み込み直す場合は、列名を変えないでください。

---

## 各項目が守るべき上限

これらは Etsy の出品エディタが適用する上限です。上限を超えたファイルは、どのツールを使っても有効な出品に戻せません。

- **タイトル**：140 文字まで。Etsy の検索では先頭しか表示されないので、大事な言葉を前に置きます。
- **タグ**：1 出品につき 13 個まで、1 個あたりスペース込みで 20 文字まで。文字、数字、スペースを使ってください。Etsy はタグ内のほとんどの記号を受け付けません。
- **素材**：1 出品につき 13 個まで。
- **数量**：1 出品につき 999 までの整数。
- **価格**：ショップの通貨での普通の数値。通貨記号は付けません。

---

## 価格の書き方

- 普通の小数を使います：`14.99`
- 通貨記号（`$`、`€`、`£`）は付けません
- スプレッドシートがカンマを使う設定でも、小数点にはカンマではなくピリオドを使います
- 通貨はショップで決まり、`CURRENCY_CODE` はそれを記録するだけです

---

## タグ

タグは 1 つのセルにカンマ区切りで入ります。

```
handmade,gift for her,leather wallet,birthday gift
```

セルにカンマが含まれるので、CSV では二重引用符で囲む必要があります。保存時にスプレッドシートが自動で行います。注意すべき点：

- セル内のタグが 13 個を超えている
- 20 文字を超えるタグがある
- 編集後に二重のカンマや、カンマの前後のスペースが残っている

---

## 一括出品アプリが求めることがある項目

Etsy のエクスポートには、出品の設定がすべて入っているわけではありません。Etsy の API で出品を作成する他社製アプリは、追加の列を求めることがよくあります。作った人（`who_made`）、作られた時期（`when_made`）、クラフト用品かどうか（`is_supply`）、配送プロファイル、ショップのセクションなどです。使える値は Etsy の API に由来し、時期によって変わります（`when_made` の年の範囲など）。そのアプリのテンプレートにある値をそのまま使ってください。

## スプレッドシートで編集した後によくある問題

### 記号やカンマが入った価格

`$14.99` や `14,99` のような価格は普通の数値ではありません。

**対処法**：検索と置換で `$`、`€`、`£` を削除し、小数点のカンマをピリオドに置き換えます。

### タイトルが長すぎる

タイトルが 140 文字を超えています。

**対処法**：Excel で `=LEN(A2)` の補助列を追加して 140 文字を超えるタイトルを探し、短くします。

### タグが多すぎる、または長すぎる

出品のタグが 13 個を超えている、または 20 文字を超えるタグがあります。

**対処法**：タグを数え（カンマの数 + 1）、各タグを 20 文字以内に収めます。

### 画像リンクが壊れている

画像のセルに `mug.jpg` のような値や、`https://` のないリンクが入っています。

**対処法**：`https://` で始まる完全な画像 URL を使います。
