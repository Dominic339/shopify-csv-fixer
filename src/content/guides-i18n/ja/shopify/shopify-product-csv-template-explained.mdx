## テンプレートの概要

Shopify 公式の商品 CSV テンプレートの列は、**商品レベル**（商品ごとに1回、最初の行＝親行に入れる）と**バリエーションレベル**（その商品のすべての行に入れる）の2種類に分かれます。バリエーションが複数ある商品は、同じ Handle を持つ複数の行を使います。

最新のテンプレートは Shopify の管理画面からダウンロードできます：商品管理 → インポート → サンプル CSV をダウンロード。

---

## 識別のための列

### Handle（必須）

Handle は、URL に使える商品の一意な識別子です。次の条件を満たす必要があります。
- ストア内のすべての商品の中で一意である
- 半角英小文字、数字、ハイフンだけを使う
- 最初のインポート後は変更しない（Handle を変えると商品の URL が新しくなる）

**例**：`blue-leather-wallet`

同じ商品の行はすべて同じ Handle にします。Shopify はこれを使ってバリエーション行をまとめます。

### Title（親行で必須）

ストアに表示される商品名です。商品の最初の行に入れ、バリエーション行では空にします。

**例**：`Blue Leather Wallet`

### Body (HTML)

商品説明です。HTML を含められます。説明にカンマや山かっこが含まれる場合は、値全体をダブルクォートで囲みます。説明の中の改行も、クォートで囲んだ値の中に入れる必要があります。

### Vendor

ブランド名や仕入先名です。プレーンテキストです。

### Type

独自の商品タイプ（整理用）です。Shopify の商品カテゴリではなく、絞り込みに使う自由入力の文字列です。

### Tags

カンマ区切りのタグの一覧です。タグにカンマが含まれる場合は、Tags セルの値全体をクォートで囲む必要があります。

**例**：`"summer, sale, leather"`

## 公開に関する列

### Published（真偽値）

商品をお客様に表示するかどうかです。`TRUE` または `FALSE`（大文字）を使います。

- `TRUE`：商品は有効で表示される
- `FALSE`：商品は下書き（ストアには表示されない）

### Published Scope

商品を公開する場所です。よく使う値は `web`（オンラインストア）、`global`（すべての販売チャネル）です。

---

## オプションの列

これらの列で、バリエーションの軸（サイズ、色、素材など）を定義します。

### Option1 Name / Option1 Value

`Option1 Name` は軸の名前（例：`Size`、`Color`）、`Option1 Value` は各行の具体的な値（例：`Small`、`Medium`、`Blue`）です。

ルール：
- `Option1 Name` は同じ商品のすべての行で同じにする
- `Option1 Value` はバリエーション行ごとに変わる
- オプションが1つだけなら Option1 だけを使い、2つ目・3つ目のオプションがない限り Option2 や Option3 の列は入れない

### Option2 Name / Option2 Value（任意）

2つ目の軸（例：色）です。商品に軸が2つある場合だけ必要です。

### Option3 Name / Option3 Value（任意）

3つ目の軸です。Shopify は1つの商品につき最大3つのオプションに対応しています。

---

## バリエーションの列

これらの列は、親行もバリエーション行も含めたすべての行に適用されます。

### Variant SKU

そのバリエーションの一意な識別子です。任意ですが、在庫管理をしている場合は SKU を一意にする必要があります。SKU による在庫管理をしていなければ空欄で構いません。

### Variant Price（必須）

そのバリエーションの販売価格です。通貨記号も桁区切りもない、単純な小数で書きます。

**例**：`19.99`

### Variant Compare At Price

取り消し線付きで表示される「通常価格」です。セール価格がなければ空欄にします。

### Variant Inventory Qty

在庫数です。整数で入れます。在庫切れなら `0` にします。このバリエーションの在庫管理をオフにしている場合は空欄にします。

### Variant Inventory Policy

在庫が0になったときの動作です。使える値は `deny`（購入を止める）と `continue`（在庫切れでも購入を許可する）です。

### Variant Fulfillment Service

そのバリエーションの発送方法です。通常の発送なら `manual`、外部サービスを使う場合はその API 名を入れます。

### Variant Requires Shipping（真偽値）

配送が必要な実物の商品は `TRUE`、デジタル商品は `FALSE` です。

### Variant Taxable（真偽値）

課税対象なら `TRUE`、非課税なら `FALSE` です。

### Variant Barcode

UPC、EAN、ISBN などのバーコードです。プレーンテキストです。Shopify は検証せず、そのまま保存します。

### Variant Weight / Variant Weight Unit

バリエーションの重さと単位です。重さは小数、単位は `kg`、`g`、`lb`、`oz` のいずれかです。

---

## 画像の列

### Image Src

商品画像の URL です。一般公開された HTTPS の URL である必要があります。対応形式：JPG、JPEG、PNG、GIF、WEBP。

- 親行：商品のメイン画像
- バリエーション行：そのバリエーションのオプションの組み合わせに対応する画像（例：青色の見本）

### Image Position

画像の表示順です。1から始まる整数で、メイン画像は1にします。

### Image Alt Text

画像の代替テキストです。アクセシビリティと SEO に使われます。

---

## SEO の列

### SEO Title

ページのタイトルタグです（ブラウザのタブや検索結果に表示されます）。空欄の場合は商品の Title が使われます。70文字未満がおすすめです。

### SEO Description

商品ページのメタディスクリプションです。160文字未満がおすすめです。

---

## ギフトカードの列

### Gift Card（真偽値）

その商品がギフトカードの場合だけ `TRUE` にします。ほとんどの商品は `FALSE` か空欄です。

---

## 単一商品とバリエーションのある商品

**単一商品（バリエーション1つ**）：1つの商品につき1行です。必須の列をすべて入力します。オプションの列は任意です。

**バリエーションのある商品**：1つの商品につき、同じ Handle を持つ複数の行を使います。最初の行が親行（Title、Image Src、Body HTML などを持つ）で、2行目以降がバリエーション行です（Title は空。商品レベルのデータは Handle によるまとまりから引き継がれます）。
