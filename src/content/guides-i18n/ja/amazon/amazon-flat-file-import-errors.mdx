## Amazon はフラットファイルをどう検証するか

Amazon のフラットファイルは商品カテゴリごとに決められた厳密な列構成に従います。また Amazon の Inventory Loader ガイドでは、アップロード前にファイルをタブ区切りテキスト（.txt）で保存するよう案内しています。フラットファイルをアップロードすると、Amazon は次の順に検証します：

1. **テンプレートの照合**：列の見出しが、そのファイルの種類に対応するテンプレートと一致しているかを確認します
2. **必須項目の検証**：必須の列すべてに値が入っているかを確認します
3. **データ型の検証**：数値、真偽値、決められた選択肢の値を確認します
4. **ビジネスルール**：ASIN、SKU、コンディションのコード、価格の範囲を確認します
5. **カタログの照合**：商品 ID を Amazon のカタログと照合します

処理が終わると、Amazon は **処理レポート** を作成します（セラーセントラルの［カタログ］→［アップロードによる一括商品登録］）。必ず確認してください。失敗したすべての行と、具体的なエラーが一覧になっています。

## エラー：seller_sku が無効または未入力

**原因**：`seller_sku` が空欄、40文字を超えている、使えない文字を含んでいる、またはカタログにある既存の SKU と重複しています。

**seller_sku のルール**：
- 最大40文字
- Amazon のガイドでは英数字の文字列とされていますが、Amazon 自身の例の SKU `dt-black` にはハイフンも含まれています
- スペースやその他の記号は、うまく扱えないツールがあるため避けてください
- Amazon の出品者アカウント全体で一意であること

**対処法**：すべての行に一意の SKU を付けます。重複は `=COUNTIF($A:$A, A2)` のような数式で見つけられます。40文字を超える SKU は短くします。

---

## エラー：item_name がない／商品名が長すぎる

**原因**：`item_name` が空欄、または Amazon の商品名の文字数制限を超えています（カテゴリによって異なりますが、一般的には200〜500文字）。

**対処法**：
- すべての商品行に `item_name` を入れる
- Excel の `=LEN(B2)` で、カテゴリの上限を超える商品名を探す
- 正確な文字数の上限は、使っているテンプレートで確認する

---

## エラー：condition_type が無効

**原因**：`condition_type` 列に、Amazon が認めている一覧にない値が入っています。

**使える値**：

| 値 | 説明 |
|---|---|
| `New` | 新品、未開封 |
| `UsedLikeNew` | 中古（ほぼ新品） |
| `UsedVeryGood` | 中古（非常に良い） |
| `UsedGood` | 中古（良い） |
| `UsedAcceptable` | 中古（可） |
| `CollectibleLikeNew` | コレクター商品（ほぼ新品） |
| `CollectibleVeryGood` | コレクター商品（非常に良い） |
| `CollectibleGood` | コレクター商品（良い） |
| `CollectibleAcceptable` | コレクター商品（可） |
| `Refurbished` | 出品者による再生品 |
| `Club` | クラブ（メディアカテゴリ） |

**対処法**：標準外のコンディション値を、上の一覧のいずれかに置き換えます。Inventory Loader では `item-condition` に数字を使います。新品は `11`、中古（ほぼ新品、非常に良い、良い、可）は `1` から `4`、コレクター商品は同じ順で `5` から `8` です。Amazon のガイドでは `9` は「使用しない」とされています。

---

## エラー：価格が無効

**原因**：`price` 列に通貨記号（`$`）が入っている、小数点にカンマを使っている、0、マイナス、または空欄になっています。

**Amazon の価格のルール**：
- 普通の小数：`19.99`
- 通貨記号は付けない
- 正の数（0より大きい）
- 小数点はピリオド
- 桁区切りは入れない：`1,250.00` ではなく `1250.00`

**対処法**：通貨記号を取り除き、小数点のカンマをピリオドに置き換えます。保存する前に、Excel で価格の列を「数値」の書式にしておきます。

---

## エラー：fulfillment_center_id／出荷チャネルが無効

**原因**：出荷チャネルの列に、認識されない値が入っています。

**使える値**：

| 値 | 説明 |
|---|---|
| `DEFAULT` | 出品者による出荷（FBM） |
| `AMAZON_NA` | フルフィルメント by Amazon（FBA、米国） |

正確な列名と使える値は、フラットファイルのテンプレートによって少し異なります。使っているテンプレートを確認してください。

**対処法**：FBM には `DEFAULT`、米国の FBA には `AMAZON_NA` を使います。`FBA`、`FBM` などの略称は使いません。FBA の行では `quantity` を空欄にしてください。Amazon のガイドによると、数量を入れるとその SKU は出品者出荷に切り替わります。

---

## エラー：product_id／ASIN が見つからない

**原因**：`product_id`（ASIN、UPC、EAN、ISBN）が Amazon のカタログのどの商品とも一致しない、または `product_id_type` が入力した ID の種類と合っていません。

**product_id_type の値**：

| 値 | ID の種類 |
|---|---|
| `1` | ASIN |
| `2` | ISBN |
| `3` | UPC |
| `4` | EAN |

**対処法**：
- 商品 ID が正しく、Amazon のカタログで有効になっているかを確認する
- `product_id_type` を `product_id` に入れた ID の種類に合わせる
- まだ ASIN がない新商品は、既存の出品に在庫を追加するのではなく、新しい出品を作る必要がある場合がある

---

## エラー：商品カテゴリに合わないテンプレート

**原因**：まだ Amazon のカタログにない商品に Inventory Loader を使いました。Inventory Loader は既存の商品の出品を作成・更新するだけで、新しい商品にはカテゴリ別の在庫ファイル（衣類、シューズ、ジュエリーなど）が必要です。

Amazon にはカテゴリ別のテンプレートがあり、追加の必須項目があります。違うテンプレートを使うと、カテゴリ固有の必須項目がすべて抜け落ちます。

**対処法**：
- セラーセントラルで「在庫」→「アップロードによる一括商品登録」→「在庫ファイルをダウンロード」に進む
- 商品カテゴリを選んで、正しいテンプレートを取得する
- カテゴリ専用のフラットファイルをダウンロードし、データを移し替える

専用のテンプレートがある主なカテゴリ：服、靴、ジュエリー、家電、本、音楽、ビデオ、スポーツ＆アウトドア。

## 処理レポートの読み方

アップロード後、セラーセントラルで処理レポートを開きます（［カタログ］→［アップロードによる一括商品登録］→［アップロードステータスの確認］）。セラーセントラルのメニューは配置が変わることがあるので、見つからない場合はセラーセントラルで「アップロードによる一括商品登録」を検索してください。

レポートの最初には、処理されたレコード数と成功したレコード数の概要があります。

その下に、問題ごとに 1 行ずつ、ファイル内の行番号（`original-record-number`）、`sku`、`error-code`、`error-type`（Error または Warning）、`error-message` が並びます。Error はその行の処理を止め、Warning は処理を通しますが確認すべき点を示します。
