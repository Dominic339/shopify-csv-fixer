## はい/いいえの値はファイルによって異なる

Amazon は、すべてのアップロードファイルで同じはい/いいえの形式を使っているわけではありません。列が受け付ける値は、記入しているファイルによって決まります。

| ファイル | 列の例 | 使える値 |
|---|---|---|
| カテゴリの出品テンプレート（商品タイプに合わせてセラーセントラルからダウンロード） | `batteries_required`、`are_batteries_included` | テンプレートの **Valid Values** タブがその列に挙げている値。電池の項目では多くの場合 `true` / `false` |
| Inventory Loader（`sku`、`product-id`、`add-delete` を含む出品情報ファイル） | `will-ship-internationally` | 米国内のみは `n` または `1`、海外発送は `y` または `2` |
| Inventory Loader | `expedited-shipping` | はい/いいえではなく、配送オプションの一覧（下記参照） |

Amazon の Inventory Loader ガイドは `batteries_required` と `are_batteries_included` の選択肢を `true` または `false` としており、Amazon の Listings API も true/false で保存しています。

**最もよくある間違い**：テンプレートの一覧にない言葉を入力することです。たとえば Valid Values タブが `true` / `false` としている列に `Yes`、`Y`、`1` と書いたり、ある Amazon ファイルの書き方を別のファイルにそのまま持ち込んだりすることです。

## まず Valid Values タブを確認する

セラーセントラルからダウンロードするカテゴリテンプレートには、ファイルごとの答えが書かれたタブが 2 つあります。

1. **Data Definitions**：各列の説明と、必須かどうかが書かれています。
2. **Valid Values**：プルダウンのある各列で使える値が、正確に一覧になっています。

Valid Values タブで列名を探し、表記どおりに値をコピーしてください。テンプレートは時期によって変わり、カテゴリやマーケットプレイスでも異なるので、何か月も前に保存したものではなく、これからアップロードする版を確認します。予想していた列がテンプレートにない場合、その商品タイプではその列を使いません。

## Inventory Loader の配送列

Inventory Loader ファイル（`sku`、`product-id`、`add-delete` 列があるファイル）で出品を更新する場合、2 つの配送列ははい/いいえ項目に見えますが、独自のルールに従います。Amazon の Inventory Loader ガイドでは次のように定義されています。

| 列名 | 期待される値 | 何を決めるか |
|---|---|---|
| `will-ship-internationally` | 米国内のみは `n` または `1`、海外発送は `y` または `2` | 出品を米国外に発送するかどうか |
| `expedited-shipping` | `Next`、`Second`、`Domestic`、`International`、`Plus` をカンマ区切りで、なしは `N` | どの速い配送オプションを提供するか |

つまり `expedited-shipping` ははい/いいえ項目ではなく、そこに `y` を入れてもどのオプションにも一致しません。翌日配送と 2 日配送を提供するなら `Next,Second` と書き、提供しないならセルを空のままにします。

## スプレッドシートがはい/いいえの値を変える仕組み

### Excel

1. **チェックボックスと数式**：チェックボックスのセルや `=IF(A2>0, TRUE, FALSE)` のような数式は、Excel 独自の `TRUE` / `FALSE` を出力します。これが通用するのはテンプレートの一覧に true/false がある場合だけで、Inventory Loader の `will-ship-internationally` 列では決して通用しません。
2. **手入力の言葉**：手で入力した `Yes`、`No`、`Y` はそのまま残るので、ファイル内に表記の揺れが生まれます。
3. **CSV を直接開く**：CSV をダブルクリックで開くと、Excel が列の型を推測します。`true` のようなテキストが Excel のブール値に変わり、`TRUE` として保存されることがあります。

### Google Sheets

Google スプレッドシートも同じ動きをします。チェックボックスの列や数式は、出力先の列が何を求めていても `TRUE` / `FALSE` を出力します。

## 無効な値を見つける

### 列ごとにフィルターをかける

1. Excel に書式を変えられないよう、**データ → テキストまたは CSV から** でファイルを開きます。
2. はい/いいえ列（たとえば `batteries_required`）のフィルターボタンをクリックします。
3. 表示された値を Valid Values タブと比べます。それ以外の値はすべて問題で、Data Definitions タブが必須としている列の空のセルも同様です。

### 補助列の数式

項目の隣に列を追加し、使える値を数式に並べます。true/false の列なら次のとおりです。

```
=IF(OR(LOWER(A2)="true", LOWER(A2)="false", A2=""), "OK", "INVALID: "&A2)
```

Inventory Loader の `will-ship-internationally` では、代わりに `y`、`n`、`1`、`2` を確認します。`INVALID` と表示された行をフィルターで絞り込むと、問題のある値がすべて見つかります。

## 無効な値をまとめて直す

### Excel の検索と置換

1. **Ctrl+H**（検索と置換）を押します。
2. **検索する文字列** に間違った値、たとえば `Yes` を入力します。
3. **置換後の文字列** に Valid Values タブの値、たとえば `true` を入力します。
4. **オプション** をクリックし、セル全体だけが変わるよう **セル内容が完全に同一であるものを検索する** にチェックを入れます。
5. **すべて置換** をクリックし、`No` やほかに見つかった表記についても繰り返します。

> **重要**：置換する前に、それぞれの値の意味を決めておきます。`batteries_required` の `Yes` と別の列の `Yes` では、置換すべき値が違うことがあります。

### 数式の結果を値に置き換える

はい/いいえ列が数式で計算されている場合：

1. 列を選択してコピーします（**Ctrl+C**）。
2. 右クリック → **形式を選択して貼り付け → 値**。
3. 数式が普通のテキストになるので、そのあと検索と置換で直せます。

### Google Sheets

1. 列を選択します。
2. **編集 → 検索と置換**（Ctrl+H）。
3. **大文字と小文字の区別** と **セルの内容全体で一致を確認** にチェックを入れ、間違った値を検索して使える値に置き換えます。

## 次回から問題を防ぐ

### テンプレートのプルダウンを使う

Amazon のカテゴリテンプレートには、Valid Values タブから作られたプルダウンが付いています。テンプレートの上に CSV を貼り付けるのではなく、テンプレートそのものにデータを入力すれば、プルダウンが値を一覧の中に保ってくれます。

### 自分でプルダウンを追加する

プルダウンのないファイルでは、見出しの下の列のセルを選択し、**データ → データの入力規則** を開いて **リスト** を選び、使える値を入力します。たとえば `true,false`（`will-ship-internationally` なら `y,n,1,2`）です。

### アップロードの前に毎回確認する

1. 完成したファイルを（Excel ではなく）テキストエディタで開き、はい/いいえ列に目を通します。
2. すべての値がその列の一覧にあることを確認します。
3. Data Definitions タブが必須としている列はすべて埋めます。

Inventory Loader でアップロードする場合は、StriveFormats の修正ツールが Amazon のガイドに沿って `will-ship-internationally` と `expedited-shipping` を確認します。
