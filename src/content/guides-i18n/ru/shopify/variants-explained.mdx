## Как Shopify описывает варианты в CSV

В CSV товаров Shopify товар с несколькими вариантами записывается как **несколько строк с одинаковым Handle**. Первая строка — «родительская»: в ней данные уровня товара. Каждая следующая строка с тем же Handle — строка варианта.

### Минимальный пример: футболка двух размеров

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Variant SKU,Image Src
blue-shirt,Blue T-Shirt,Size,Small,19.99,BLUE-SM,https://cdn.example.com/shirt.jpg
blue-shirt,,Size,Medium,21.99,BLUE-MD,
```

На что обратить внимание:
- У обеих строк Handle `blue-shirt`.
- Во второй строке пустые Title и Image Src и новое значение Option1 Value.
- Каждая строка — это один вариант, который можно купить (одно сочетание значений опций).

---

## Родительская строка

Первая строка для каждого Handle — родительская. Она задаёт поля уровня товара:

| Столбец | Обязателен в родительской | Примечание |
|---|---|---|
| Handle | Да | Уникальное короткое имя товара; строчные буквы и только дефисы |
| Title | Да | Название товара |
| Body HTML | Нет | Описание товара; нужно только в родительской строке |
| Vendor | Нет | Название бренда |
| Type | Нет | Тип товара (для коллекций) |
| Tags | Нет | Теги через запятую |
| Published | Нет | true или false |
| Option1 Name | Да (если есть опции) | Название первой опции (например, «Size») |
| Option1 Value | Да (если есть опции) | Значение для первого варианта (например, «Small») |
| Image Src | Нет | URL основного изображения |

**В родительской строке обязательно должен быть Title.** Если Title пустой, Shopify не распознает строку как родительскую, и результат импорта может оказаться неверным.

---

## Строки вариантов

Каждая строка после первой с тем же Handle — строка варианта. Строки вариантов:
- Имеют тот же Handle, что и родительская.
- Имеют пустой Title (или такой же — вне родительской строки Shopify его игнорирует).
- Имеют своё значение Option1 Value (и Option2 Value, Option3 Value, если они есть).
- Имеют свои Variant Price, Variant SKU, Variant Inventory Qty и т. д.

### Столбцы для каждого варианта

| Столбец | Примечание |
|---|---|
| Variant Price | Обязателен для каждого варианта; десятичное число (без символа валюты) |
| Variant SKU | Необязателен, но очень желателен; должен быть уникальным во всём магазине |
| Variant Grams | Вес в граммах |
| Variant Inventory Qty | Начальный остаток |
| Variant Inventory Policy | `deny` или `continue` (continue — разрешить продажу без остатка) |
| Variant Fulfillment Service | Обычно `manual` |
| Variant Requires Shipping | true или false |
| Variant Taxable | true или false |
| Variant Barcode | EAN, UPC или другой штрихкод |

## Несколько опций (размер И цвет)

Shopify поддерживает до трёх опций через столбцы Option1, Option2 и Option3.

Пример: футболка с размером и цветом

```
Handle,Title,Option1 Name,Option1 Value,Option2 Name,Option2 Value,Variant Price,Variant SKU
blue-shirt,Blue T-Shirt,Size,Small,Color,Blue,19.99,BLUE-SM-BLU
blue-shirt,,Size,Small,Color,Red,19.99,BLUE-SM-RED
blue-shirt,,Size,Medium,Color,Blue,21.99,BLUE-MD-BLU
blue-shirt,,Size,Medium,Color,Red,21.99,BLUE-MD-RED
```

- Option1 Name и Option2 Name достаточно указать только в родительской строке (первой для каждого Handle). Повторять их в строках вариантов не вредно.
- Для каждого сочетания опций нужна отдельная строка.
- Товару с 3 размерами и 4 цветами нужно 12 строк вариантов.

## Частые ошибки

### Ошибка 1: разные Handle у одного товара

**Признак:** То, что должно быть одним товаром с вариантами, после импорта появляется как несколько отдельных товаров.

**Решение:** У всех строк одного товара должен быть в точности одинаковый Handle. Опечатка (`blue-shirt` вместо `blue-shirt-`) заставит Shopify создать новый товар.

### Ошибка 2: Title в каждой строке

**Признак:** Импорт проходит, но Shopify создаёт дубликаты товаров или считает строки вариантов отдельными товарами.

**Решение:** Title должен быть только в первой строке каждого Handle. Во всех строках вариантов оставляйте Title пустым.

### Ошибка 3: нет столбца Option1 Name

**Признак:** Ошибка импорта «Option1 Name is required» или все варианты отображаются как одна опция с названием «Default Title».

**Решение:** Всегда добавляйте `Option1 Name` в строку заголовков и указывайте значение хотя бы в родительской строке. Если у товара нет настоящих опций, укажите в Option1 Name `Title`, а в Option1 Value — `Default Title`.

### Ошибка 4: значения опций не совпадают между строками

**Признак:** Shopify создаёт больше вариантов, чем ожидалось, или названия опций дублируются.

**Решение:** Option1 Name должен быть одним и тем же текстом во всех строках Handle. Если в родительской строке указано `Size`, в каждой строке варианта тоже должно быть `Size` (или пусто). Смесь `Size`, `size` и `Sizes` даёт несогласованные данные об опциях.

### Ошибка 5: пустой Variant Price

**Признак:** Импорт падает с ошибкой «Variant Price is required» или варианты создаются с ценой 0.00.

**Решение:** Variant Price обязателен в каждой строке. Значение не наследуется: даже если у всех вариантов одна цена, её нужно указать в каждой строке.

### Ошибка 6: новый вариант затирает существующие

**Признак:** После частичного импорта (добавления одного нового варианта) все остальные варианты пропадают.

**Решение:** Обновляя товар через импорт CSV, включайте в файл **все** существующие варианты, а не только новый. Импорт Shopify заменяет весь набор вариантов для Handle. Пропущенные варианты будут удалены.

## Советы для больших каталогов

- **Создавайте строки вариантов автоматически.** Для товаров с большим числом сочетаний (3 размера × 4 цвета × 2 материала = 24 строки) используйте формулу в таблице или скрипт вместо ручного ввода.
- **Используйте единые шаблоны SKU.** SKU вида `ОСНОВА-РАЗМЕР-ЦВЕТ` (например, `SHIRT-SM-BLU`) упрощает поиск и сортировку вариантов.
- **Сначала проверьте на одном товаре.** Импортируйте один товар (родительскую строку и все варианты), прежде чем загружать весь каталог. Проверьте структуру вариантов в админке Shopify, прежде чем продолжать.
