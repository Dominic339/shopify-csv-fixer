## Столбцы изображений в CSV Shopify

CSV товаров Shopify поддерживает три столбца для изображений:

| Столбец | Обязателен | Примечание |
|---|---|---|
| Image Src | Нет | Общедоступный HTTPS-адрес файла изображения |
| Image Position | Нет | Целое число (1, 2, 3...), задающее порядок |
| Image Alt Text | Нет | Описание изображения |

Эти столбцы находятся в той же строке, что и данные товара или варианта. В каждой строке может быть один URL изображения.

---

## Одно изображение на товар

Самый простой случай — одно изображение на товар. Укажите URL в столбце `Image Src` **родительской строки** (первой строки этого Handle):

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Image Src,Image Alt Text
blue-shirt,Blue T-Shirt,Size,Small,19.99,https://cdn.example.com/blue-shirt.jpg,Blue t-shirt front view
blue-shirt,,Size,Medium,21.99,,
```

В строках вариантов (второй и следующих с тем же Handle) столбец Image Src пустой.

---

## Несколько изображений на товар

Чтобы добавить к товару больше одного изображения, добавьте **дополнительные строки с тем же Handle**, содержащие только данные изображения. У таких строк пустые Title и поля варианта — они нужны только для передачи дополнительных URL изображений.

```
Handle,Title,Option1 Name,Option1 Value,Variant Price,Image Src,Image Position,Image Alt Text
blue-shirt,Blue T-Shirt,Size,Small,19.99,https://cdn.example.com/blue-shirt-front.jpg,1,Blue t-shirt front view
blue-shirt,,Size,Medium,21.99,,,
blue-shirt,,,,,,https://cdn.example.com/blue-shirt-back.jpg,2,Blue t-shirt back view
blue-shirt,,,,,,https://cdn.example.com/blue-shirt-detail.jpg,3,Blue t-shirt fabric detail
```

Главные правила:
- На один товар поддерживается до **250 изображений**.
- Каждый URL изображения стоит в отдельной строке с тем же Handle.
- В строках только с изображением пустые Variant Price, значения опций и Title.
- Не используйте одну строку и для варианта, и для дополнительного изображения: одна строка — одна задача.

## Image Position

`Image Position` задаёт порядок изображений в галерее товара. Это целое число, начиная с 1.

- `1` — основное изображение (показывается первым).
- `2`, `3` и т. д. — дополнительные изображения в этом порядке.

Если не указать Image Position, Shopify назначит позиции в том порядке, в котором изображения идут в CSV. Явно заданные позиции сохраняют ваш порядок независимо от порядка строк.

**Пример:** сначала показать фото в интерьере, затем фото товара:

```
Handle,Image Src,Image Position,Image Alt Text
blue-shirt,https://cdn.example.com/lifestyle.jpg,1,Model wearing blue shirt
blue-shirt,https://cdn.example.com/product.jpg,2,Blue shirt on white background
```

## Требования к URL изображений

Shopify скачивает изображения по указанному URL во время импорта. URL должен соответствовать этим требованиям:

- **Должен использовать HTTPS.** Обычные HTTP-адреса отклоняются или могут вызывать предупреждения о смешанном содержимом.
- **Должен быть общедоступным.** URL за авторизацией, проверками Cloudflare или ограничениями по IP работать не будут.
- **Без пробелов.** Пробелы нужно закодировать как `%20` или изменить адрес.
- **Должен вести на файл изображения.** Shopify принимает JPEG, PNG, GIF, WEBP и SVG. URL не обязан заканчиваться расширением, если сервер возвращает правильный content-type, но большинство процессов импорта надёжнее работают с адресами с расширением.
- **Без истекающих параметров.** Если вы используете подписанные ссылки (из S3, Cloudinary и т. п.) с ограниченным сроком действия, убедитесь, что они остаются действительными на всё время импорта.

## Частые ошибки импорта изображений

### Изображение не появляется после импорта

**Вероятные причины:**
1. URL вернул HTTP-статус, отличный от 200 (404, 403, 500). Shopify без предупреждения пропускает недоступные изображения.
2. URL использовал HTTP, а не HTTPS.
3. В URL был пробел, из-за которого запрос сломался.

**Как проверить:** Вставьте URL прямо в браузер. Если изображение открывается, URL рабочий. Если видите страницу входа, 403 или 404, изображение не общедоступно.

### Основным стало не то изображение

**Причина:** Image Position не был указан, а изображения шли в CSV в неправильном порядке.

**Решение:** Явно укажите `Image Position` = `1` в строке с URL основного изображения.

### Изображения попадают не к тому товару

**Причина:** Опечатка в Handle: в строке изображения Handle немного отличался от Handle в строке товара.

**Решение:** Следите, чтобы Handle совпадали в точности. Даже один лишний пробел или другой регистр буквы создаёт новый товар.

### Старые изображения не удаляются

**Поведение:** При повторном импорте импорт CSV в Shopify **добавляет** изображения к товару. Существующие изображения он не удаляет. Чтобы удалить изображения, воспользуйтесь админкой Shopify или API.

### Слишком много изображений

**Поведение:** Если для одного Handle указать больше 250 URL изображений, Shopify импортирует только первые 250, а остальные без предупреждения пропустит.

## Рекомендации по альтернативному тексту

Альтернативный текст (столбец `Image Alt Text`) решает две задачи:
1. **Доступность:** программы экранного доступа зачитывают альтернативный текст людям с нарушениями зрения.
2. **SEO:** поисковые системы индексируют альтернативный текст и по нему понимают, что изображено на картинке.

**Хороший альтернативный текст:**
- Описывает, что на изображении: `"Синяя хлопковая футболка, вид спереди, на белом фоне"`
- Содержит название товара и ключевые характеристики
- Уникален для каждого изображения (не повторяется на всех изображениях товара)

**Избегайте:**
- Переспама ключевыми словами: `"купить синюю футболку дешёвые футболки хлопковые футболки"`
- Общих слов: `"image1"`, `"фото"`, `""` (пусто)
- Одинакового альтернативного текста для всех изображений товара

## Шпаргалка: шаблоны строк с изображениями

**Одно изображение, без альтернативного текста:**
```
Handle,Title,...,Image Src
my-product,My Product,...,https://example.com/img1.jpg
```

**Несколько изображений с позициями:**
```
Handle,Title,...,Image Src,Image Position,Image Alt Text
my-product,My Product,...,https://example.com/img1.jpg,1,Front view
my-product,,,...,https://example.com/img2.jpg,2,Side view
my-product,,,...,https://example.com/img3.jpg,3,Detail view
```

**Изображение варианта (изображение, привязанное к конкретной строке варианта):**
Укажите Image Src в той же строке, что и вариант. Shopify привяжет это изображение к этому варианту:
```
Handle,Option1 Value,Variant Price,Image Src
my-product,Blue,19.99,https://example.com/blue.jpg
my-product,Red,19.99,https://example.com/red.jpg
```
