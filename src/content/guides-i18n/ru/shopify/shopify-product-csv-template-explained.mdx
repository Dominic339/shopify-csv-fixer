## Обзор шаблона

В официальном шаблоне CSV товаров Shopify есть два вида столбцов: **уровня товара** (заполняются один раз на товар, в первой, родительской строке) и **уровня варианта** (заполняются в каждой строке товара). Товар с несколькими вариантами занимает в файле несколько строк, и у всех один и тот же Handle.

Скачайте текущий шаблон в админке Shopify: «Товары → Импорт → Скачать пример CSV». В текущем шаблоне используются новые названия колонок (`URL handle`, `Description`, `Price`, `Product image URL`, `Published on online store` и др.). Shopify по-прежнему принимает старые названия из этого руководства.

---

## Идентификационные столбцы

### Handle (`URL handle` в текущем шаблоне)

Handle — уникальный идентификатор товара, пригодный для URL. Он должен:
- Быть уникальным среди всех товаров магазина
- Состоять только из строчных латинских букв, цифр и дефисов
- Не меняться после первого импорта (изменение Handle создаёт новый URL товара)

**Пример:** `blue-leather-wallet`

У всех строк одного товара должен быть одинаковый Handle. По нему Shopify группирует строки вариантов.

### Title (обязателен в родительской строке)

Название товара, которое видят покупатели. Укажите его в первой строке товара и оставьте пустым в строках вариантов.

**Пример:** `Blue Leather Wallet`

### Body (HTML)

Описание товара. Может содержать HTML. Если в описании есть запятые или угловые скобки, заключите всё значение в двойные кавычки. Переносы строк внутри описания тоже должны находиться внутри значения в кавычках.

### Vendor

Название бренда или поставщика. Обычный текст.

### Type

Ваш собственный тип товара (для организации). Это не категория товара Shopify, а произвольный текст для фильтрации.

### Tags

Список тегов через запятую. Если тег содержит запятую, всё содержимое ячейки Tags нужно заключить в кавычки.

**Пример:** `"summer, sale, leather"`

## Столбцы публикации

### Published (логический)

Публикуется ли товар в вашем интернет-магазине. Принимает `true` или `false`, пустая ячейка считается `true`.

- `true`: товар опубликован в интернет-магазине
- `false`: товар не показывается в интернет-магазине (он остаётся в админке; статус черновика задаётся отдельно в столбце Status)

### Status

Можно ли продавать товар: `active` (по умолчанию), `draft` или `archived`.

## Столбцы опций

Эти столбцы задают измерения вариантов (размер, цвет, материал и т. д.).

### Option1 Name / Option1 Value

`Option1 Name` — название измерения (например, `Size`, `Color`). `Option1 Value` — конкретное значение в каждой строке (например, `Small`, `Medium`, `Blue`).

Правила:
- `Option1 Name` должен быть одинаковым во всех строках одного товара
- `Option1 Value` меняется от строки к строке варианта
- Если опция одна, используйте только Option1 — добавляйте столбцы Option2 и Option3, только если есть вторая или третья опция

### Option2 Name / Option2 Value (необязательно)

Второе измерение (например, цвет). Нужно только если у товара два измерения.

### Option3 Name / Option3 Value (необязательно)

Третье измерение. Shopify поддерживает до 3 опций на товар.

## Столбцы вариантов

Эти столбцы относятся к каждой строке (и родительской, и строкам вариантов).

### Variant SKU

Уникальный идентификатор конкретного варианта. Необязателен, но если вы ведёте учёт остатков, SKU должны быть уникальными. Оставьте пустым, если не ведёте учёт по SKU.

### Variant Price (`Price` в текущем шаблоне)

Цена продажи этого варианта. Обычное десятичное число без символа валюты и разделителей тысяч. Пустая цена импортируется как 0.00.

**Пример:** `19.99`

### Variant Compare At Price

«Старая» цена, которая показывается зачёркнутой. Оставьте пустым, если скидки нет.

### Variant Inventory Qty

Количество единиц на складе, целым числом. Действует только для магазинов с одной локацией; магазины с несколькими локациями обновляют остатки через CSV запасов Shopify.

### Variant Inventory Policy

Что происходит, когда остаток доходит до нуля. Допустимые значения: `deny` (запретить покупку) или `continue` (разрешить покупку без остатка).

### Variant Fulfillment Service

Как выполняется заказ этого варианта. `manual` — обычная обработка, или API-имя стороннего сервиса.

### Variant Requires Shipping (логический)

`true` для физических товаров, которые нужно доставлять; `false` для цифровых.

### Variant Taxable (логический)

`true`, если вариант облагается налогом; `false`, если освобождён от него.

### Variant Barcode

Штрихкод UPC, EAN или ISBN. Задайте колонке текстовый формат, чтобы таблица не удаляла ведущие нули и не превращала число в 1.23E+11.

### Variant Grams / Variant Weight Unit

`Variant Grams` (`Weight value (grams)` в текущем шаблоне) — вес в граммах, целым числом без единиц: 5,125 кг записывается как `5125`. `Variant Weight Unit` (`Weight unit for display`) задаёт только единицу, которую видят покупатели: `g`, `kg`, `lb` или `oz`.

## Столбцы изображений

### Image Src

URL изображения товара. Это должен быть общедоступный адрес `https://` без защиты паролем.

- В родительской строке — основное изображение товара
- В строках вариантов — изображение для сочетания опций этого варианта (например, образец синего цвета)

### Image Position

Порядок отображения изображения. Целое число, начиная с 1. Основное изображение должно иметь 1.

### Image Alt Text

Альтернативный текст изображения — для доступности и SEO.

---

## Столбцы SEO

### SEO Title

Заголовок страницы (виден во вкладке браузера и в результатах поиска). Если пусто, используется Title товара. Рекомендуется до 70 символов.

### SEO Description

Метаописание страницы товара. Shopify допускает до 320 символов; при пустой ячейке используется описание товара.

---

## Столбец подарочной карты

### Gift Card (логический)

`true`, только если товар является подарочной картой. У большинства товаров должно быть `false` или пусто. Shopify не создаёт подарочные карты через импорт CSV, поэтому новые карты создавайте в админке.

---

## Простой и вариативный товар

**Простой товар (один вариант):** одна строка на товар. Заполните все обязательные столбцы. Столбцы опций необязательны.

**Вариативный товар:** несколько строк на товар с одинаковым Handle. Первая строка — родительская (с Title, Image Src, Body HTML и т. д.). Следующие — строки вариантов (Title пустой; данные товара они получают через группировку по Handle).
