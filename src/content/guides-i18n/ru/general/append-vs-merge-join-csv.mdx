## Три операции, три смысла

Когда говорят «объединить файлы CSV», обычно имеют в виду одну из трёх разных операций. Если выбрать не ту, данные потеряются или сломается структура.

| Операция | Что меняется | Число строк | Число колонок |
|---|---|---|---|
| **Добавление** | Появляются новые строки | Растёт | Не меняется |
| **Слияние** | Два файла с одинаковой структурой становятся одним | Растёт | Не меняется |
| **Соединение** | Появляются колонки из связанного файла | Не меняется | Растёт |

## Добавление: больше строк

**Что делает:** строки второго CSV ставятся в конец первого. Колонки в обоих файлах должны совпадать полностью.

**Когда использовать:**
- Чтобы собрать выгрузку, разбитую на страницы (файл 1 = строки 1–500, файл 2 = строки 501–1000).
- Чтобы перед загрузкой добавить новую партию товаров в существующий файл каталога.
- Чтобы собрать файлы разных региональных команд, которые выгружают данные в одном формате.

**Как правильно добавить строки в Excel:**

1. Откройте основной файл.
2. Откройте второй файл.
3. Во втором файле **удалите строку заголовков** (правый щелчок по строке 1 → Удалить).
4. Выделите все оставшиеся данные (Ctrl+A; поправьте выделение, если захватилось лишнее).
5. Скопируйте (Ctrl+C).
6. Перейдите в основной файл и щёлкните первую пустую ячейку под последней строкой данных.
7. Вставьте (Ctrl+V).
8. Сохраните как CSV UTF-8.

**Серьёзная ошибка, которой нужно избегать:** если пропустить шаг 3 (удаление заголовков), посреди файла окажутся повторные строки заголовков, и на этом спотыкается любая платформа импорта.

**Как добавить строки в Google Таблицах:**

Так же: удалите строку заголовков второго файла, скопируйте только строки с данными и вставьте их в конец основного листа.

## Слияние: объединение файлов с одинаковыми колонками (из разных источников)

**Что делает:** по сути то же, что добавление, но о «слиянии» обычно говорят, когда файлы пришли из разных источников и описывают один и тот же тип данных (например, два списка товаров от поставщиков в одном формате).

**Когда использовать:**
- Чтобы свести фиды товаров от двух разных поставщиков в один файл для загрузки.
- Чтобы объединить выгрузки разных отделов, которые используют один и тот же шаблон CSV платформы.

**Что дополнительно учесть при слиянии (по сравнению с простым добавлением):**
- **Проверьте повторяющиеся строки.** Если товар есть в обоих файлах, в объединённом он окажется дважды. Ищите дубли по Handle (Shopify), SKU (WooCommerce/Amazon) или Item ID (eBay). В Excel: **Данные → Удалить дубликаты**, затем выберите ключевую колонку.
- **Приведите названия колонок к одному виду.** Если у поставщика A колонка называется `Barcode`, а у поставщика B — `UPC`, перед слиянием нужно перейти на то название, которое ожидает платформа.
- **Приведите значения к одному виду.** Цены могут быть в разных валютах, а статусы записаны по-разному (Published, TRUE или 1).

## Соединение: колонки из связанного файла

**Что делает:** ставит два файла рядом и добавляет к первому колонки из второго, сопоставляя строки по общей ключевой колонке (например, SKU или Handle).

**Когда использовать:**
- У вас есть список товаров из ERP (Handle, Title, SKU, Price) и отдельный файл остатков (SKU, Quantity, Warehouse Location), и вы хотите добавить остаток к каждой строке товара.
- Вы выгружаете товары без изображений из одной системы, а URL изображений лежат в отдельном файле с привязкой по SKU.
- Перед импортом вы хотите добавить в каталог данные поставщика (закупочную цену, артикул поставщика).

### Соединение с помощью ВПР в Excel

Допустим:
- **Файл A** (основной): колонки A=Handle, B=Title, C=Price
- **Файл B** (справочный): колонки A=Handle, B=Quantity

Нужно добавить Quantity из файла B в файл A.

1. В файле A добавьте заголовок новой колонки: `Quantity` (в колонке D).
2. В ячейку D2 введите:
   ```
   =ВПР(A2;'[FileB.csv]FileB'!$A:$B;2;ЛОЖЬ)
   ```
3. Файл B должен быть открыт в Excel. Открывая CSV, Excel называет лист по имени файла, поэтому в `FileB.csv` лист называется `FileB`. Если ключ совпал, Quantity заполнится. Если совпадения нет, появится `#Н/Д`: такого Handle нет в файле B.
4. Протяните формулу вниз на все строки.
5. Когда всё сходится, выделите колонку D, скопируйте её и выберите **Специальная вставка → Значения**, чтобы заменить формулы постоянными значениями.
6. Закройте файл B.
7. Сохраните файл A как CSV UTF-8.

### Соединение в Google Таблицах

Используйте `ВПР` (или `VLOOKUP`) с тем же синтаксисом. Можно также подтянуть данные из другой Google Таблицы функцией `IMPORTRANGE`, а затем работать со вспомогательной колонкой.

### Соединение на Python (большие файлы)

```python
import csv

# Загрузить справочный файл в словарь с Handle в качестве ключа
lookup = {}
with open("inventory.csv", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for row in reader:
        lookup[row["Handle"]] = row["Quantity"]

# Добавить Quantity в основной файл
with open("products.csv", encoding="utf-8") as infile, \
     open("products_with_qty.csv", "w", newline="", encoding="utf-8") as outfile:
    reader = csv.DictReader(infile)
    fieldnames = reader.fieldnames + ["Quantity"]
    writer = csv.DictWriter(outfile, fieldnames=fieldnames)
    writer.writeheader()
    for row in reader:
        row["Quantity"] = lookup.get(row["Handle"], "")
        writer.writerow(row)
```

## Частые ошибки при объединении файлов CSV

### Ошибка 1: повторные строки заголовков после добавления

**Симптом:** импорт обрывается посреди файла с ошибками вроде «нераспознанная строка».
**Решение:** перед добавлением всегда удаляйте строку заголовков у всех файлов, кроме первого.

### Ошибка 2: разный порядок колонок в добавляемых файлах

**Симптом:** после добавления данные оказываются не в тех колонках.
**Решение:** порядок колонок в обоих файлах должен совпадать, а не только их названия. Если в файле B колонки идут в другом порядке, перед добавлением переставьте их так же, как в файле A.

### Ошибка 3: соединение по неуникальному ключу

**Симптом:** ВПР возвращает неверный остаток (берёт первое совпадение и игнорирует дубли).
**Решение:** перед соединением убедитесь, что ключевая колонка (SKU, Handle) в справочном файле уникальна. Используйте **Данные → Удалить дубликаты** или проверьте через СЧЁТЕСЛИ.

### Ошибка 4: разная кодировка после объединения

**Симптом:** «кракозябры» в строках из одного из исходных файлов.
**Решение:** перед объединением сохраните все исходные файлы в UTF-8. Перекодируйте в VS Code каждый файл, который не в UTF-8 (см. руководство по кодировкам).

### Ошибка 5: пустые строки между добавленными частями

**Симптом:** импорт останавливается на пустой строке и игнорирует все следующие.
**Решение:** после добавления пролистайте объединённый файл и удалите пустые строки между частями.

## Короткая шпаргалка

```
Нужно больше строк? → Добавление или слияние
Нужно больше колонок? → Соединение

Файлы из одной системы с одинаковыми колонками? → Добавление
Из разных систем, но с одним шаблоном колонок? → Слияние (проверьте дубли)
Данные о товарах в одном файле, а дополнительные данные в другом? → Соединение
```
