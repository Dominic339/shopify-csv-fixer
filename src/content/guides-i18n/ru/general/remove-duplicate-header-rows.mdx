## Что такое повторяющиеся строки заголовков?

Повторяющаяся строка заголовков появляется, когда первая строка CSV (названия столбцов) снова встречается где-то среди данных. Например:

```
Handle,Title,Vendor,Variant Price
blue-shirt,Blue T-Shirt,Acme,19.99
Handle,Title,Vendor,Variant Price   ← повторная строка заголовков
red-shirt,Red T-Shirt,Acme,21.99
```

Когда инструмент импорта встречает `Handle` в строке данных, он не может прочитать её как товар. Большинство платформ молча пропускают такую строку или выдают ошибку формата. Некоторые считают её неудачной строкой.

---

## Откуда берутся повторяющиеся заголовки

### Объединение нескольких выгруженных файлов

Самая частая причина: два CSV объединяют копированием и вставкой в Excel или Google Таблицах. Строка заголовков второго файла оказывается в середине объединённого файла.

### Постраничный экспорт

Некоторые платформы выгружают данные по страницам (например, по 500 строк в файле). Если скачать все страницы и склеить их, строка заголовков каждого файла попадёт в результат.

### Системы отчётов по расписанию

Автоматические системы, которые каждый день дописывают строки в CSV, иногда повторяют заголовок в начале каждого добавленного блока.

### «Обновить всё» или выгрузки Power Query в Excel

Обновление подключений к данным в Excel может снова вставить строку заголовков, если запрос настроен неправильно.

## Поиск повторяющихся строк заголовков

### В Excel

1. Откройте CSV (**Данные → Из текстового/CSV-файла**, а не двойным щелчком, чтобы сохранить форматирование).
2. Щёлкните любую ячейку с данными.
3. Выберите **Данные → Фильтр**, чтобы включить фильтры.
4. Щёлкните стрелку в столбце **Handle** (или в вашем первом столбце).
5. В поле поиска введите точное название заголовка (например, `Handle`).
6. Если в результате фильтра появились строки, это повторяющиеся строки заголовков.

### В Google Таблицах

1. Выделите все данные (**Ctrl+A**).
2. Выберите **Данные → Создать фильтр**.
3. Щёлкните стрелку в первом столбце.
4. В текстовом поле фильтра введите название заголовка (например, `Handle`).
5. Все строки с этим значением — повторяющиеся заголовки.

### Пометить их формулой

В пустом столбце рядом с каждой строкой добавьте эту формулу, чтобы пометить дубли:

```
=ЕСЛИ(A2="Handle";"ПОВТОР ЗАГОЛОВКА";"")
```

Замените `"Handle"` настоящим названием вашего первого столбца. Отфильтруйте по `ПОВТОР ЗАГОЛОВКА`, чтобы найти все случаи.

## Удаление повторяющихся строк заголовков

### Способ 1: отфильтровать и удалить (Excel / Таблицы)

1. Отфильтруйте первый столбец так, чтобы остались только строки со значением заголовка (например, `Handle`).
2. Выделите все видимые отфильтрованные строки (щёлкните номер строки первого результата, затем Shift+щелчок по последнему).
3. Правый щелчок → **Удалить строки**.
4. Снимите фильтр (Данные → Очистить фильтр или Фильтр → Отключить).
5. Убедитесь, что данные не пострадали.

### Способ 2: отсортировать, удалить и вернуть порядок (Excel)

Сортировка собирает все повторяющиеся строки заголовков вместе, но меняет порядок товаров, поэтому после неё всегда возвращайте исходный порядок. Файлы для Shopify, WooCommerce и eBay зависят от порядка строк.

1. Добавьте вспомогательный столбец с номерами строк (1, 2, 3...), чтобы сохранить исходный порядок.
2. Отсортируйте по первому столбцу от А до Я.
3. Повторяющиеся строки заголовков теперь стоят подряд, там, где `Handle` оказывается по алфавиту среди ваших значений (сортировка Excel не различает регистр, поэтому ищите их среди значений на H).
4. Выделите этот блок строк и удалите его.
5. Отсортируйте по вспомогательному столбцу, чтобы вернуть исходный порядок.
6. Удалите вспомогательный столбец.

### Способ 3: текстовый редактор (большие файлы)

Для файлов, слишком больших для Excel (больше примерно 100 000 строк), используйте VS Code или Notepad++:

**VS Code:**
1. Откройте файл.
2. Нажмите **Ctrl+H** (Найти и заменить).
3. Включите режим **регулярных выражений** (значок `.*`).
4. В поле «Найти» введите: `^Handle,Title,Vendor,Variant Price\r?\n`
   (замените своими настоящими заголовками, при необходимости экранируя символы)
5. Поле «Заменить» оставьте пустым.
6. Нажмите **Заменить все**.
7. Удалив все дубли, вручную верните заголовок первой строкой.

> Будьте осторожны с заменой по регулярным выражениям. Всегда храните исходный файл как резервную копию и после замены проверьте, что заголовок встречается ровно один раз.

**Notepad++ (Windows):**
1. Откройте файл → **Поиск → Замена** (Ctrl+H).
2. Выберите режим **Регулярные выражения**.
3. Используйте тот же шаблон, что и в VS Code выше.
4. Заменить всё, затем вручную верните строку заголовков.

## После удаления повторяющихся заголовков

Когда файл очищен:

1. Проверьте, что заголовок встречается ровно один раз, в строке 1.
2. Посчитайте строки. Их должно быть столько, сколько было изначально, минус число удалённых повторяющихся заголовков.
3. Выборочно проверьте несколько строк рядом с местами, где были дубли, чтобы убедиться, что данные целы.
4. Сохраните как **CSV UTF-8** (в Excel: **Файл → Сохранить как → CSV UTF-8**).

## Как избежать повторяющихся заголовков при следующем объединении

Когда объединяете несколько CSV вручную:

1. Откройте первый файл (ваш «базовый» файл) в Excel или Таблицах.
2. Откройте каждый дополнительный файл.
3. **Удалите строку заголовков** в дополнительном файле перед копированием его данных.
4. Копируйте только строки с данными.
5. Вставьте их в конец базового файла.

Если вы объединяете CSV скриптами, всегда пропускайте строку заголовков каждого файла после первого. `csv.DictReader` читает заголовок каждого файла как названия столбцов, поэтому он никогда не попадает в данные:

```python
# Пример на Python: предполагается, что у всех файлов одинаковые столбцы
import csv

files = ["export_page1.csv", "export_page2.csv"]

with open("combined.csv", "w", newline="", encoding="utf-8") as outfile:
    writer = None
    for filename in files:
        # utf-8-sig убирает BOM, который иначе изменил бы название первого столбца
        with open(filename, newline="", encoding="utf-8-sig") as infile:
            reader = csv.DictReader(infile)
            if writer is None:
                writer = csv.DictWriter(outfile, fieldnames=reader.fieldnames)
                writer.writeheader()
            for row in reader:
                writer.writerow(row)
```

Если столбцы у файлов разные, используйте скрипт из руководства по объединению двух файлов CSV — он сохраняет все столбцы.
