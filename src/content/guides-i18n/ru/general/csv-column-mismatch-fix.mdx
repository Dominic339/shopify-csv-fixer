## Что такое несовпадение столбцов?

Несовпадение столбцов возникает, когда названия в строке заголовков вашего CSV не совпадают с тем, что ожидает платформа импорта. По названиям столбцов платформа раскладывает данные по нужным полям товара. Если название неверно хотя бы на один пробел или одну букву, платформа либо игнорирует столбец (данные молча пропадают), либо отклоняет весь импорт.

Это одна из самых частых причин проблем вида «ничего не импортировалось» или «все поля пустые».

---

## Частые причины

### 1. Переименованные столбцы

Вы переименовали обязательный столбец так, как понятно вам, но не платформе.

| Что вы написали | Что ожидает платформа |
|---|---|
| `Product Title` | `Title` (Shopify) |
| `product_name` | `Name` (WooCommerce) |
| `Item Name` | `item_name` (Amazon) |
| `Listing Title` | `TITLE` (выгрузка Etsy) |
| `Listing Title` | `Title` (eBay) |

**Решение:** используйте точное название столбца из платформы. Не добавляйте слов и не переименовывайте ради понятности.

### 2. Неверный регистр

Некоторые импортёры сравнивают названия столбцов с учётом регистра, поэтому безопасно только в точности повторить написание из шаблона.

| Неверно | Верно |
|---|---|
| `handle` | `Handle` (Shopify) |
| `TITLE` | `Title` (Shopify) |
| `Variant price` | `Variant Price` (Shopify) |
| `regular_price` | `Regular price` (WooCommerce) |

**Решение:** сравнивайте посимвольно. Даже `Regular Price` и `Regular price` (строчная p) могут различаться для импортёра. WooCommerce при импорте показывает экран сопоставления, где для любого нераспознанного столбца можно выбрать нужное поле.

### 3. Пробелы в начале или в конце

Табличные редакторы могут незаметно добавить пробел до или после названия столбца. Платформа видит `" Title"` (с пробелом в начале) как совершенно другой столбец, чем `"Title"`.

**Как обнаружить:** откройте CSV в простом текстовом редакторе (не в таблице) и посмотрите на первую строку как есть. Любой пробел до или после названия столбца там виден.

**Исправление в Excel:** не используйте «Найти и заменить» для пробелов: так пропадут и пробелы внутри названий вроде `Variant Price`. Вместо этого в пустой строке введите `=СЖПРОБЕЛЫ(A1)` и протяните формулу вправо на все столбцы, затем скопируйте эту строку и вставьте её поверх строки 1 через Специальная вставка > Значения. Потом удалите вспомогательную строку.

**Исправление на Python:**

```python
import csv

# utf-8-sig также убирает BOM, который strip() оставил бы на месте
with open("input.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    # Убрать пробелы из всех названий столбцов
    fieldnames = [h.strip() for h in reader.fieldnames or []]
    rows = [dict(zip(fieldnames, row.values())) for row in reader]

with open("output.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    writer.writerows(rows)
```

### 4. BOM портит название первого столбца

Если файл сохранён как «UTF-8 с BOM», перед названием первого столбца стоят 3 невидимых байта. Заголовок, который в Excel выглядит как `Handle`, может прийти в инструмент, не ожидающий BOM, как `﻿Handle` и уже не совпадёт.

**Решение:** если импортёр сообщает, что первый столбец не распознан, пересохраните файл без BOM. В VS Code: нажмите на индикатор кодировки → «Save with Encoding» → выберите UTF-8 (без BOM).

### 5. Проблемы с порядком столбцов

Некоторые платформы требуют столбцы в определённом порядке (eBay File Exchange, некоторые шаблоны плоских файлов Amazon). Если переставить столбцы в Excel, такой импорт может сломаться, даже когда названия верны.

**Решение:** скачайте с платформы свежий шаблон и вставьте данные в него, а не меняйте порядок столбцов в своём файле.

## Как сравнить заголовки с шаблоном платформы

1. Скачайте официальный шаблон CSV платформы
2. Откройте оба файла в текстовом редакторе (не в Excel)
3. Скопируйте обе строки заголовков (строка 1) в инструмент сравнения или сравните вручную
4. Ищите: другой текст, лишние пробелы, другой регистр, лишние или отсутствующие столбцы

**Онлайн-инструменты сравнения:** вставьте обе строки заголовков и сравните их рядом.

**Сравнение на Python:**

```python
import csv

with open("platform_template.csv", encoding="utf-8-sig") as f:
    expected = next(csv.reader(f))

with open("your_file.csv", encoding="utf-8-sig") as f:
    actual = next(csv.reader(f))

# utf-8-sig уже убрал BOM; теперь убираем пробелы
expected = [h.strip() for h in expected]
actual = [h.strip() for h in actual]

missing = set(expected) - set(actual)
extra = set(actual) - set(expected)
print("Missing from your file:", missing)
print("Extra in your file:", extra)
```

## Что делать с лишними столбцами

Если в файле есть столбцы, которые платформа не распознаёт:

- **Большинство платформ** (Shopify, WooCommerce): лишние столбцы молча игнорируются, так что проблемы нет
- **Плоские файлы Amazon**: столбцы, которых нет в шаблоне, могут быть отклонены
- **eBay File Exchange**: нераспознанные столбцы могут вызвать предупреждения или ошибки

**Решение для строгих платформ:** удалите все столбцы, которых нет в официальном шаблоне.

---

## Что делать с отсутствующими необязательными столбцами

Если в файле нет необязательных столбцов:

- Платформа использует для этих полей значение по умолчанию
- Для необязательных полей это почти всегда допустимо
- Для обязательных полей отсутствие столбца приводит к сбою импорта, и ошибка будет в каждой строке
