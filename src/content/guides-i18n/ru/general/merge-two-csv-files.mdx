## Когда нужно объединять файлы CSV?

Объединение двух файлов CSV в один — частый шаг перед импортом в интернет-магазин. Это может понадобиться, чтобы:

- Свести товары двух поставщиков в одну загрузку каталога
- Совместить выгрузку товаров за прошлый месяц с новинками
- Разбить большой импорт на небольшие части, а потом собрать их обратно
- Свести в один CSV товаров строки вариантов из разных источников

В этом руководстве описаны четыре надёжных способа: Power Query в Excel, Google Таблицы, командная строка и Python. Каждый сохраняет строку заголовков из первого файла и добавляет только строки данных из второго.

---

## Прежде чем начать: выровняйте заголовки

В обоих файлах должны быть одинаковые заголовки столбцов в одинаковом порядке. Если столбцы различаются, при объединении данные попадут не в те поля и импорт испортится.

Короткий чек-лист перед объединением:

- [ ] Откройте оба файла и сравните первую строку (заголовки) бок о бок
- [ ] Названия столбцов совпадают точно (некоторые платформы учитывают регистр)
- [ ] Столбцы в обоих файлах идут в одном порядке
- [ ] Ни в одном файле нет итоговых строк или строк-подвалов
- [ ] Оба файла сохранены в UTF-8

Если заголовки идут в разном порядке, перед объединением переставьте столбцы в одном из файлов. Способ на Python с DictWriter (способ 4 ниже) сам справляется с разным порядком столбцов.

## Способ 1: Power Query в Excel (Windows, рекомендуется)

Power Query в Excel объединяет несколько CSV без формул и макросов. Он сам справляется с разницей в кодировке и переводах строк между файлами и никогда не повторяет строку заголовков.

### Шаги

1. Откройте пустую книгу Excel.
2. Перейдите на вкладку **Данные**, нажмите **Получить данные**, затем **Из файла** и **Из текстового/CSV-файла**.
3. Выберите **первый файл CSV** и нажмите **Импорт**. В окне предварительного просмотра нажмите **Преобразовать данные** (а не Загрузить).
4. В редакторе Power Query перейдите в **Главная** > **Создать источник** > **Файл** > **Текстовый или CSV-файл**, выберите **второй файл CSV** и нажмите **ОК**. Теперь оба файла видны как запросы на левой панели.
5. Выделите первый запрос и перейдите в **Главная** > **Добавить запросы** > **Добавить запросы в новый**.
6. В диалоговом окне выберите **Две таблицы**, а затем второй запрос из списка.
7. На левой панели появится новый объединённый запрос. Нажмите **Закрыть и загрузить**, чтобы вывести его на новый лист.
8. Сделав объединённый лист активным, перейдите в **Файл** > **Сохранить как** и выберите формат **CSV UTF-8 (разделитель — запятая)**. Excel сохраняет только активный лист. Простой «CSV (разделители — запятые)» использует старую кодировку и может испортить кириллицу и другие символы.

### Почему Power Query

- Определяет кодировку каждого файла и позволяет исправить её в предварительном просмотре, если догадка неверна.
- Добавляет строку заголовков ровно один раз, а не по разу на каждый файл.
- Не добавляет пустых строк между файлами.
- Справляется с большими файлами — до предела Excel в 1 048 576 строк на лист. Для большего числа строк используйте командную строку или Python.

## Способ 2: Google Таблицы (в браузере, небольшие файлы)

Google Таблицы — быстрый вариант, если у вас нет Excel. Он хорошо подходит для файлов, где всего меньше примерно 50 000 строк.

### Шаги

1. Откройте Google Диск и загрузите первый CSV: щёлкните правой кнопкой по пустому месту, выберите **Загрузить файлы**, укажите CSV, затем щёлкните правой кнопкой по загруженному файлу и выберите **Открыть с помощью > Google Таблицы**.
2. Запомните номер последней строки с данными (например, строка 500, если в файле 499 строк данных и одна строка заголовков).
3. Так же откройте второй CSV в новой вкладке браузера.
4. Во второй таблице щёлкните номер строки **2** (первая строка данных под заголовками). Нажмите **Ctrl+Shift+End**, чтобы расширить выделение до последней строки и столбца с данными.
5. Нажмите **Ctrl+C**, чтобы скопировать. Перейдите на первую вкладку и щёлкните первую пустую строку под данными.
6. Нажмите **Ctrl+V**, чтобы вставить строки данных (без заголовков).
7. Перейдите в **Файл** > **Скачать** > **Значения, разделённые запятыми (.csv)**.

### Обратите внимание

- Google Таблицы выгружают UTF-8 без BOM, поэтому объединённый файл можно загружать как есть.
- Очень большие файлы (более 100 000 строк) могут замедлить или подвесить Таблицы. В таком случае используйте командную строку или Python.
- Проверьте, что вставленные строки встали точно под нужные столбцы. Один сдвиг на столбец портит всё объединение.

## Способ 3: командная строка (самый быстрый, любой размер)

Если у вас есть терминал, объединение в командной строке занимает меньше секунды независимо от размера файла. В macOS и Linux ничего устанавливать не нужно.

### macOS или Linux

```bash
# Объединить file1.csv и file2.csv в merged.csv
# tail -n +2 пропускает строку заголовков второго файла
cat file1.csv <(tail -n +2 file2.csv) > merged.csv
```

Если `file1.csv` не заканчивается переводом строки, его последняя строка и первая строка `file2.csv` окажутся в одной строке. Проверьте это место в результате.

### Windows (командная строка)

```bat
:: Сначала скопировать первый файл
copy file1.csv merged.csv

:: Добавить все строки второго файла, кроме заголовков
more +1 file2.csv >> merged.csv
```

Примечание: команда Windows `more +1` пропускает первую строку. Но она также заменяет табуляции пробелами, может испортить текст не в ASCII (включая кириллицу) и зависает на очень больших файлах, поэтому проверьте результат или используйте в Windows Python (способ 4).

### Проверка результата

После объединения в командной строке откройте результат в текстовом редакторе и убедитесь, что:

- Строка заголовков встречается ровно один раз (в самом верху)
- Между данными двух файлов нет пустой строки
- Последняя строка file1 и первая строка данных file2 идут подряд
- В конце нет лишнего перевода строки (большинство импортёров это терпит, но без него аккуратнее)

## Способ 4: Python (любая система, разные столбцы)

`csv.DictWriter` в Python — самый надёжный способ объединения. Он справляется с разным порядком столбцов, со столбцами, которые есть только в одном файле, и с большими файлами. Программистом быть не нужно: установите Python и запустите скрипт ниже.

### Скрипт

```python
import csv

files_to_merge = ["file1.csv", "file2.csv"]
output_file = "merged.csv"

# Собрать все названия столбцов в порядке их первого появления
fieldnames = []
for fname in files_to_merge:
    with open(fname, newline="", encoding="utf-8-sig") as f:
        for h in csv.DictReader(f).fieldnames or []:
            if h not in fieldnames:
                fieldnames.append(h)

with open(output_file, "w", newline="", encoding="utf-8") as out:
    # restval="" оставляет столбец пустым в строках из файла, где его нет
    writer = csv.DictWriter(out, fieldnames=fieldnames, restval="")
    writer.writeheader()
    for fname in files_to_merge:
        # utf-8-sig убирает BOM, если он есть
        with open(fname, newline="", encoding="utf-8-sig") as f:
            for row in csv.DictReader(f):
                writer.writerow(row)

print(f"Done: merged {len(files_to_merge)} files into {output_file}")
```

Сохраните этот файл как `merge.py` в той же папке, где лежат ваши CSV. Откройте в этой папке терминал или командную строку и выполните:

```
python merge.py
```

### Почему Python?

- Работает в Windows, macOS и Linux.
- Автоматически убирает BOM (utf-8-sig). Любой файл не в UTF-8 сначала перекодируйте (см. раздел о кодировках ниже).
- Справляется с разным порядком столбцов, потому что DictWriter сопоставляет их по названию, а не по позиции. Столбцы, которых нет в одном файле, остаются пустыми, а столбцы, которые есть только в одном файле, сохраняются.
- Обрабатывает файлы построчно, не загружая всё в память, поэтому работает и с очень большими файлами.

## Когда объединять НЕ нужно

Объединение подходит для того, чтобы ставить друг под другом строки файлов с одинаковой структурой. Не объединяйте, когда:

- **У файлов разная структура.** Если в file1 30 столбцов, а в file2 25 других, наивное объединение даст файл со съехавшими данными. Используйте способ на Python с DictWriter (способ 4), который сохраняет все столбцы и оставляет пропуски пустыми, или сначала приведите структуры к одной.
- **Нужно соединить файлы по ключу (JOIN, как в SQL).** Объединение ставит строки друг под другом; оно не сопоставляет строки двух файлов по общему SKU, Handle или ID. Для соединения по ключу используйте `csv.DictReader` в Python со словарём или инструмент вроде pandas.
- **В одном из файлов есть итоги, сводки или сводные таблицы.** Перед объединением выгрузите только исходные строки данных. Итоговые строки, формулы СУММ и строки со средними после объединения станут данными о товарах.
- **Файлы получены из разных шаблонов выгрузки.** Выгрузка товаров Shopify и выгрузка остатков Shopify имеют разные столбцы, и их нельзя объединить добавлением строк.

## Исправление разных заголовков перед объединением

Если в файлах одинаковые столбцы, но названия разные (например, `Title` и `Product Title` или `Price` и `Variant Price`), перед объединением приведите их к одному виду.

### Вручную в Excel или Google Таблицах

1. Откройте оба файла рядом.
2. Сравните строку 1 (заголовки) в каждом файле.
3. Переименуйте в одном файле нестандартные заголовки так, чтобы они совпадали с другим. Правьте ячейку прямо в ней (клавиша F2 в Excel).
4. Сохраните оба файла как CSV, прежде чем объединять.

### Автоматически на Python

```python
import csv

# Сопоставить нестандартные названия из file2 со стандартными из file1
RENAME = {
    "Product Title": "Title",
    "Price": "Variant Price",
    "SKU": "Variant SKU",
}

with open("file2.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.DictReader(f)
    # Переименовать заголовки
    fieldnames = [RENAME.get(h, h) for h in (reader.fieldnames or [])]
    rows = list(reader)

with open("file2_normalized.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.DictWriter(f, fieldnames=fieldnames)
    writer.writeheader()
    for row in rows:
        writer.writerow({RENAME.get(k, k): v for k, v in row.items()})
```

## Как выстроить столбцы в одном порядке

Если названия столбцов одинаковые, а порядок разный, способ на Python с DictWriter (способ 4) справится сам, потому что сопоставляет по названию. В Excel или Таблицах переставьте вручную:

**В Excel:**
1. Вставьте в одном из файлов пустую строку над строкой 1.
2. Пронумеруйте столбцы в том порядке, который нужен в итоговом файле (1, 2, 3...).
3. Отсортируйте столбцы по этой строке с номерами (Данные > Сортировка > Параметры > Сортировать столбцы диапазона, по строке 1).
4. Удалите вспомогательную строку с номерами.

**В Google Таблицах:**
1. Вставьте пустую строку сверху.
2. Впишите нужные позиции столбцов.
3. На вспомогательном листе используйте `=CHOOSECOLS(Sheet1!A:Z; 3; 1; 2)` (с номерами столбцов в нужном порядке) или вручную вырежьте и вставьте столбцы в правильном порядке.
4. Скачать > CSV.

## Удаление повторных строк заголовков из объединённого файла

Если в объединённом файле случайно оказалась повторная строка заголовков посередине (частая история, когда несколько раз объединяют выгрузки из одного инструмента), удалите её на Python:

```python
import csv

with open("merged.csv", newline="", encoding="utf-8-sig") as f:
    reader = csv.reader(f)
    rows = list(reader)

if not rows:
    raise ValueError("File is empty")

header = rows[0]
# Оставить только строки, не совпадающие с заголовками (кроме первой)
clean = [header] + [r for r in rows[1:] if r != header]

with open("merged_clean.csv", "w", newline="", encoding="utf-8") as f:
    writer = csv.writer(f)
    writer.writerows(clean)

print(f"Removed {len(rows) - len(clean)} duplicate header row(s).")
```

## Разные кодировки и разделители в файлах

Если один файл в UTF-8, а другой в Windows-1251 или Windows-1252 (ANSI), в объединённом файле появятся «кракозябры» везде, где в файле ANSI были кириллица, буквы с диакритикой, типографские кавычки или символы валют.

**Перед объединением перекодируйте файл ANSI в UTF-8:**

В macOS или Linux (для русских файлов ANSI обычно `windows-1251`):
```bash
iconv -f windows-1252 -t utf-8 file2_ansi.csv > file2_utf8.csv
```

На Python:
```python
with open("file2_ansi.csv", encoding="windows-1252") as f:
    content = f.read()
with open("file2_utf8.csv", "w", encoding="utf-8") as f:
    f.write(content)
```

Если у обоих файлов одна кодировка, но разные разделители (запятые и точки с запятой), перед объединением смените разделитель в одном из них. См. раздел о разделителях в руководстве по основам CSV.

## Решение проблем с объединёнными файлами

| Проблема | Причина | Решение |
|---|---|---|
| Лишняя пустая строка посередине объединённого файла | Во втором файле в конце был перевод строки или итоговая строка | Удалите пустую строку или добавьте в Python `if any(row.values()):` перед `writer.writerow(row)` |
| Повторная строка заголовков посередине | Не пропущены заголовки второго файла | Используйте `tail -n +2` (командная строка) или добавление в Power Query (пропускает их автоматически) |
| Данные не в тех столбцах | Порядок столбцов в файлах разный | Сначала переставьте столбцы в одном файле или используйте способ на Python с DictWriter |
| «Кракозябры» в объединённом файле | У файлов разные кодировки | Сначала перекодируйте оба файла в UTF-8 через iconv на Mac/Linux: `iconv -f windows-1252 -t utf-8 file2.csv > file2_utf8.csv` |
| После загрузки не распознан первый столбец | В объединённом файле есть BOM, который платформа читает неверно | Откройте в VS Code и пересохраните как UTF-8 без BOM |

## Чего не стоит делать

- **Не полагайтесь на ручное копирование при больших или сложных файлах.** Легко пропустить строку, вставить со сдвигом на столбец или случайно повторить заголовки. Способ 2 подходит для небольших файлов, если вы проверяете результат; в остальных случаях используйте Power Query, командную строку или Python.
- **Не открывайте оба файла в Excel двойным щелчком, чтобы вырезать и вставлять строки.** При таком открытии CSV Excel меняет формат дат, длинных чисел и ведущих нулей и незаметно портит данные.
- **Не объединяйте файлы с разным числом столбцов, не исправив сначала заголовки.** В результате данные съедут.

## Чек-лист после объединения

Перед импортом объединённого файла проверьте:

- [ ] Строка заголовков встречается ровно один раз (в строке 1, без повторов посередине)
- [ ] Число строк верное: (строки file1 − 1 заголовок) + (строки file2 − 1 заголовок) = всего строк данных
- [ ] Между данными двух файлов нет лишней пустой строки
- [ ] Нет повторяющихся SKU или Handle, которые не должны повторяться (проверьте в корректоре CSV)
- [ ] Есть все столбцы из обоих исходных файлов (если вы использовали DictWriter с разной структурой)
- [ ] Файл сохранён в UTF-8
- [ ] Расширение — .csv, а содержимое — простой текст через запятую

## После объединения: проверьте перед импортом

После объединения пропустите итоговый файл через корректор CSV перед импортом. Объединение может принести проблемы, которых не было ни в одном из исходных файлов:

- Лишняя строка заголовков посередине (корректор отмечает её как проблему структуры)
- Повторяющиеся SKU или Handle (находит проверка дублей)
- Несогласованная кодировка (находит анализ кодировки в корректоре)

Загрузите объединённый CSV в корректор и дайте ему проверить весь файл, прежде чем отправлять его на свою платформу.
