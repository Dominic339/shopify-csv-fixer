## Общий чек-лист перед импортом

Проходите эти пункты для каждого CSV, на какой бы платформе вы ни работали.

### Структура файла

- [ ] У файла расширение `.csv`, и это простой текст через запятую (а не переименованный в `.csv` файл `.xlsx`; проверьте, открыв его в текстовом редакторе)
- [ ] Строка 1 содержит заголовки столбцов, над ней нет пустых строк или строки с названием
- [ ] Нигде в файле нет пустых строк (в Excel их можно найти через вспомогательный столбец с `=СЧЁТЗ(A2:Z2)` и фильтр по 0; не используйте «Выделить группу ячеек > Пустые ячейки»: так выделяются все пустые ячейки, а не только пустые строки)
- [ ] Внизу нет строк с итогами, суммами или формулами
- [ ] Нет объединённых ячеек (они экспортируются пустыми во всех ячейках, кроме первой)
- [ ] В каждой строке столько же полей, сколько в заголовке (считайте поля, а не запятые: запятые внутри значений в кавычках не разделяют столбцы)

### Кодировка

- [ ] Файл сохранён в **UTF-8** (проверьте в строке состояния VS Code)
- [ ] Ни в одном поле нет «кракозябр» (â€™, Ã©, Â£)
- [ ] Если платформа не распознаёт первый столбец, проверьте в текстовом редакторе, нет ли перед его заголовком невидимого BOM

### Заголовки

- [ ] Названия столбцов точно совпадают с написанием платформы, включая регистр
- [ ] Ни в одном названии столбца нет пробелов в начале или в конце
- [ ] Нет повторяющихся названий столбцов
- [ ] Все обязательные столбцы на месте (см. чек-листы для платформ ниже)

### Типы данных

- [ ] Столбцы с ценами содержат только числа (без `$`, `EUR` и других символов)
- [ ] Поля да/нет используют формат платформы (TRUE/FALSE, 1/0, y/n)
- [ ] Обязательные текстовые поля не пусты ни в одной строке
- [ ] Поля SKU и идентификаторов уникальны во всём файле
- [ ] URL изображений абсолютные (начинаются с `https://`) и общедоступны

## Чек-лист для Shopify

- [ ] `Handle` есть в каждой строке и не пуст
- [ ] Строки вариантов имеют тот же `Handle`, что и строка товара
- [ ] `Title` указан в первой строке каждого товара; в строках вариантов он может быть пустым
- [ ] `Variant Price` — простое число без символа валюты (пустая цена импортируется как 0.00)
- [ ] Поля да/нет (`Published`, `Requires Shipping`, `Gift Card`) используют `true` или `false`
- [ ] У товаров с вариантами есть `Option1 Name` в первой строке и `Option1 Value` в каждой строке варианта
- [ ] Нет лишних столбцов опций без значений (например, `Option3 Name` без `Option3 Value`)
- [ ] URL изображений — общедоступные ссылки `https://` на файлы изображений (JPEG, PNG, GIF или WebP)
- [ ] В поле `Tags` теги разделены запятыми (в кавычках, если тегов несколько)

## Чек-лист для WooCommerce

- [ ] В столбце `Type` допустимое значение: `simple`, `variable`, `variation`, `grouped` или `external`
- [ ] Значения `SKU` уникальны (SKU необязателен, но дубли приводят к ошибке)
- [ ] `Regular price` — простое десятичное число (без символов валют)
- [ ] `In stock?` использует `1` или `0`, а `Backorders allowed?` — `1`, `0` или `notify`
- [ ] У строк вариаций заполнен `Parent`: SKU вариативного товара или `id:` и его ID товара
- [ ] Столбцы атрибутов названы по схеме `Attribute 1 name` / `Attribute 1 value(s)`
- [ ] `Tax status` — `taxable`, `shipping` или `none`
- [ ] URL изображений — абсолютные адреса HTTPS

## Чек-лист для Etsy

У Etsy нет загрузки CSV. Эти пункты относятся к выгрузке объявлений, которую вы будете править, переносить или передавать приложению массовой публикации.

- [ ] `TITLE` не пуст и не длиннее 140 символов
- [ ] `PRICE` — простое положительное число без символа валюты
- [ ] `QUANTITY` — целое число до 999
- [ ] В `TAGS` не больше 13 тегов через запятую, каждый не длиннее 20 символов
- [ ] В `MATERIALS` не больше 13 значений
- [ ] Столбцы изображений (`IMAGE1`, `IMAGE2`, ...) содержат полные адреса `https://`
- [ ] Значения `SKU` уникальны, если вы используете SKU
- [ ] Столбцы, которые добавляет приложение массовой публикации (например, `who_made`, `when_made` и `is_supply`), используют значения из шаблона этого приложения

## Чек-лист для eBay

- [ ] Столбец `Action` заполнен в каждой строке, например `Add`, `Revise`, `Relist` или `End`
- [ ] `Category` — допустимый числовой ID категории eBay
- [ ] `Title` не длиннее 80 символов
- [ ] `StartPrice` — положительное десятичное число (без символов валют)
- [ ] `ConditionID` использует числовые ID состояния eBay (например, `1000` — новый, `3000` — б/у)
- [ ] `Duration` содержит допустимое значение (`GTC` для объявлений с фиксированной ценой; `Days_3`, `Days_5`, `Days_7` или `Days_10` для аукционов)
- [ ] `PicURL` содержит HTTPS-адреса изображений через вертикальную черту `|` (до 24)
- [ ] `Quantity` — положительное целое число

## Чек-лист для Amazon

Эти пункты относятся к файлу предложений Inventory Loader. У шаблонов категорий свои столбцы, описанные на вкладке Data Definitions шаблона.

- [ ] Файл сохранён как текст с разделителем-табуляцией (`.txt`), а не как CSV
- [ ] `sku` не пуст, уникален и не длиннее 40 символов
- [ ] `product-id` и `product-id-type` согласованы (`1` = ASIN, `2` = ISBN, `3` = UPC, `4` = EAN)
- [ ] `price` — положительное десятичное число (без символов валют)
- [ ] `quantity` — целое число (0 или больше), для предложений FBA остаётся пустым
- [ ] `item-condition` использует числовые коды Amazon (`11` — новый, `10` — восстановленный, от `1` до `8` — б/у и коллекционные)
- [ ] `add-delete` — `a` (добавить или обновить), `d` (удалить предложение) или `x` (удалить предложение и данные товара)
- [ ] `fulfillment-center-id` — `DEFAULT` для предложений, которые вы отправляете сами, или значение FBA для вашего региона (например, `AMAZON_EU`)

## Сначала проверьте на небольшой партии

Прежде чем загружать весь каталог, проверьте файл на 3–5 строках:

1. Скопируйте 3 строки данных в новый файл (с той же строкой заголовков)
2. Загрузите этот небольшой тестовый файл
3. Проверьте результат импорта: все ли поля попали на свои места и правильно ли выглядят товары
4. Если всё прошло, импортируйте весь файл

Небольшая тестовая партия помогает гораздо легче найти проблемы, пока они не затронули сотни строк.

## Что делать, если импорт всё равно не проходит

1. Внимательно прочитайте сообщение об ошибке. В отчётах платформ обычно указан столбец или строка с ошибкой
2. Поищите точный текст ошибки вместе с названием платформы, чтобы найти нужную документацию
3. Загрузите файл в StriveFormats для автоматической проверки. Он находит проблемы, которые сообщения платформы не объясняют понятно
