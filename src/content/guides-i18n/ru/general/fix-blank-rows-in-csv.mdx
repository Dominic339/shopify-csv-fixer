## Почему пустые строки мешают импорту

Пустая строка в CSV — это строка, в которой все поля пусты (или которая состоит из одних запятых без значений). Многие импортёры просто пропускают полностью пустую строку, но в зависимости от платформы пустая строка может вместо этого:

- **Создать пустую запись товара** (пустые Title и Price), которая не проходит проверку обязательных полей
- **Остановить импорт** на пустой строке и молча проигнорировать всё, что идёт дальше
- **Выдать ошибку проверки** для каждого обязательного поля, которого нет в пустой строке

Где пустые строки появляются чаще всего:

- В **конце файла** (табличные программы часто добавляют её сами)
- **Между товарами** (вы удалили строку, но оставили пустую)
- **Между разделами**, если вы оформляли таблицу с визуальными промежутками
- **После очистки содержимого ячеек**: клавиша Delete очищает ячейки строки, но сама пустая строка остаётся

## Как найти пустые строки

### В текстовом редакторе

Откройте файл в VS Code или Блокноте. Пустые строки заметны сразу: это строки из одних запятых или совсем пустые:

```
Handle,Title,Price
blue-shirt,Blue T-Shirt,19.99
                          ← пустая строка (одни запятые или ничего)
red-shirt,Red T-Shirt,21.99
```

### В Excel

Нажмите `Ctrl+End`, чтобы перейти к последней ячейке используемого диапазона. Если последняя строка находится за вашими данными (пустая строка), Excel включил пустые строки в используемый диапазон.

Чтобы найти все пустые строки, добавьте после последнего столбца вспомогательный столбец, введите в строке 2 `=СЧЁТЗ(A2:Z2)` (расширьте диапазон на все ваши столбцы) и протяните формулу вниз. Строки со значением `0` полностью пусты.

Не ищите пустые ячейки в одном столбце вроде `Title`: в файле Shopify строки вариантов намеренно оставляют `Title` пустым, и это не пустые строки.

## Удаление пустых строк в Excel

**Способ 1: удалить пустые строки в конце**

1. Нажмите `Ctrl+End`, чтобы увидеть, где, по мнению Excel, кончаются данные
2. Если это ниже вашей последней строки с данными, выделите лишние строки под данными
3. Правый щелчок → Удалить
4. Снова нажмите `Ctrl+End` и убедитесь, что используемый диапазон теперь правильный

**Способ 2: удалить все пустые строки с помощью вспомогательного столбца**

1. Добавьте описанный выше вспомогательный столбец с `=СЧЁТЗ(A2:Z2)`
2. Включите фильтр (Данные → Фильтр) и оставьте только строки, где во вспомогательном столбце `0`
3. Выделите эти строки, правый щелчок → Удалить строку
4. Снимите фильтр и удалите вспомогательный столбец

Не используйте «Выделить группу ячеек → Пустые ячейки» для одного столбца: так удалится каждая строка, где этот столбец случайно пуст, включая нормальные строки вариантов.

## Удаление пустых строк в Google Таблицах

Используйте тот же вспомогательный столбец и фильтр:

1. Добавьте вспомогательный столбец с `=СЧЁТЗ(A2:Z2)` и протяните его вниз
2. Добавьте фильтр (Данные → Создать фильтр)
3. В фильтре вспомогательного столбца оставьте только `0`
4. Выделите видимые строки и удалите их (правый щелчок → Удалить выбранные строки)
5. Отключите фильтр и удалите вспомогательный столбец

Сортировка тоже переносит пустые строки вниз, но сортируйте только файлы, где порядок строк не важен. Товары Shopify, вариации WooCommerce и объявления eBay с вариантами зависят от того, чтобы их строки оставались по порядку.

## Удаление пустых строк на Python

Для больших файлов Python — самый быстрый путь:

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f_in, \
     open("output.csv", "w", newline="", encoding="utf-8") as f_out:
    reader = csv.reader(f_in)
    writer = csv.writer(f_out)
    for row in reader:
        # Оставить строку, если хоть в одном поле есть что-то кроме пробелов
        if any(cell.strip() for cell in row):
            writer.writerow(row)
```

Так удаляются и строки из одних пробелов (они выглядят пустыми, но содержат пробелы или табуляции).

## Строки из одних пробелов

Некоторые строки выглядят в таблице пустыми, но на самом деле содержат пробелы или табуляции в одной или нескольких ячейках. Простая проверка «пуста ли строка?» их не находит.

**Как найти их на Python:**

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.reader(f)
    for i, row in enumerate(reader, 1):
        if not any(cell.strip() for cell in row):
            print(f"Blank or whitespace-only row at line {i}")
```

Решение из предыдущего раздела (с `cell.strip()`) удаляет их автоматически.

## Как избежать пустых строк в будущих выгрузках

- **В Excel:** перед сохранением в CSV нажмите `Ctrl+End` и проверьте, что последняя строка с данными действительно последняя используемая. Удалите все строки ниже.
- **В Google Таблицах:** при скачивании CSV попадают все строки до последней непустой ячейки, поэтому держите данные компактно.
- **При удалении строк:** в Excel щёлкните правой кнопкой по номерам строк → Удалить (не просто нажимайте Delete на содержимом ячеек, иначе останется пустая строка).
- **После фильтрации:** CSV-выгрузка из Excel включает строки, скрытые фильтром, поэтому перед выгрузкой снимите фильтры и проверьте, что на самом деле есть на листе.
