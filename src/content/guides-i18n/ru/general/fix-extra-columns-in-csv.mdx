## Откуда в CSV берутся лишние столбцы

Лишние столбцы появляются в файлах CSV по нескольким типичным причинам:

- **Формулы или вспомогательные столбцы**: столбцы для ваших собственных расчётов, которые никогда не предназначались для импорта
- **Столбцы с заметками или для внутреннего учёта**: например, `Internal Notes`, `Last Edited By` или `Supplier Cost`
- **Остатки выгрузки**: ваша учётная система выгружает больше полей, чем нужно платформе
- **Объединённые файлы разных платформ**: вы соединили столбцы из двух разных шаблонов, и появились дубли или лишние столбцы
- **Запятая в конце каждой строки**: создаёт невидимый пустой столбец в конце

---

## Принимает ли ваша платформа лишние столбцы?

Это зависит от платформы:

| Платформа | Что происходит с лишними столбцами |
|---|---|
| Shopify | Молча игнорируются, проблемы нет |
| WooCommerce | Не импортируются: экран сопоставления ставит для незнакомых столбцов «Do not import» |
| Etsy | Нет загрузки CSV; у приложений массовой публикации свои правила |
| eBay File Exchange | Нераспознанные столбцы могут вызвать предупреждения или ошибки |
| Плоские файлы Amazon | Столбцы, которых нет в шаблоне, могут быть отклонены |

В Shopify и WooCommerce лишние столбцы обычно безвредны. Для eBay, Amazon или приложения массовой публикации для Etsy перед загрузкой удалите столбцы, которых нет в официальном шаблоне.

## Как найти лишние столбцы

**Сравните с официальным шаблоном:**

1. Скачайте официальный шаблон CSV платформы
2. Откройте свой файл и шаблон в текстовом редакторе (не в Excel)
3. Сравните строку 1 (заголовки) двух файлов
4. Любой столбец вашего файла, которого нет в шаблоне, лишний

**Python: список лишних столбцов**

```python
import csv

with open("official_template.csv", encoding="utf-8-sig") as f:
    expected = set(h.strip() for h in next(csv.reader(f)))

with open("your_file.csv", encoding="utf-8-sig") as f:
    actual = [h.strip() for h in next(csv.reader(f))]

extras = [col for col in actual if col not in expected]
print("Extra columns:", extras)
```

## Удаление лишних столбцов в Excel

1. Откройте CSV в Excel
2. Щёлкните букву каждого лишнего столбца, чтобы выделить его
3. Правый щелчок → Удалить
4. Для нескольких несмежных столбцов: удерживайте Ctrl, щёлкните буквы нужных столбцов, затем правый щелчок → Удалить
5. Сохраните как CSV UTF-8 (разделитель — запятая), а не XLSX

**Удаление последнего столбца, если он пустой (след запятой в конце строки):**

1. Нажмите Ctrl+End, чтобы найти последнюю использованную ячейку
2. Если последний столбец пуст во всём файле, выделите и удалите его
3. Сохраните как CSV

## Удаление лишних столбцов в Google Таблицах

1. Щёлкните букву столбца, чтобы выделить его
2. Правый щелчок → Удалить столбец
3. Повторите для всех лишних столбцов
4. Файл → Скачать → Значения, разделённые запятыми

## Удаление лишних столбцов на Python (большие файлы)

Для больших файлов, которые медленно или неудобно открывать в таблице:

```python
import csv

# Столбцы, которые нужно оставить (точные названия платформы)
KEEP = [
    "Handle", "Title", "Vendor", "Type", "Tags",
    "Variant Price", "Variant SKU", "Variant Inventory Qty",
    "Image Src", "Published",
]

# utf-8-sig не даёт BOM прилипнуть к названию первого столбца
with open("input.csv", newline="", encoding="utf-8-sig") as f_in, \
     open("output.csv", "w", newline="", encoding="utf-8") as f_out:
    reader = csv.DictReader(f_in)
    # Записывать только столбцы, которые есть и в KEEP, и в файле
    fields = [h for h in (reader.fieldnames or []) if h in KEEP]
    writer = csv.DictWriter(f_out, fieldnames=fields, extrasaction="ignore")
    writer.writeheader()
    for row in reader:
        writer.writerow(row)
```

## Запятые в конце строк (скрытый лишний столбец)

Запятая в конце каждой строки создаёт пустой столбец на позиции N+1. Это выглядит так:

```
Handle,Title,Price,
blue-shirt,Blue T-Shirt,19.99,
```

Пустой столбец после последней запятой — это лишний столбец без названия и без значений.

**Исправление на Python:** удалите ровно одну запятую в конце каждой строки. Если удалить все запятые в конце, пропадут и настоящие пустые ячейки в конце строки.

```python
with open("input.csv", encoding="utf-8", newline="") as f:
    lines = f.read().splitlines()

with open("output.csv", "w", encoding="utf-8", newline="") as f:
    for line in lines:
        f.write((line[:-1] if line.endswith(",") else line) + "\n")
```

**Исправление в VS Code:** используйте «Найти и заменить» в режиме регулярных выражений. Найдите `,$` и замените на пустую строку. Делайте это, только если каждая строка, включая заголовки, заканчивается лишней запятой.

## Как избежать лишних столбцов в будущих выгрузках

- Удаляйте вспомогательные столбцы из таблицы перед выгрузкой (или держите их на отдельном листе)
- Начинайте с официального шаблона платформы и добавляйте только те столбцы, которые в нём есть
- Если вы пользуетесь своей учётной системой, настройте выгрузку так, чтобы в неё попадали только поддерживаемые столбцы
- Держите «чистую» версию шаблона таблицы только с нужными столбцами
