## Как работают атрибуты WooCommerce в CSV

Атрибуты товаров WooCommerce задают параметры, по которым товар различается, — обычно размер, цвет или материал. При импорте CSV атрибуты представлены пронумерованными группами столбцов. Каждая группа из четырёх столбцов описывает один атрибут.

Шаблон названий столбцов такой:
- `Attribute 1 name`
- `Attribute 1 value(s)`
- `Attribute 1 visible`
- `Attribute 1 global`

Для второго атрибута повторите шаблон: `Attribute 2 name`, `Attribute 2 value(s)` и т. д.

Если WordPress работает на русском, при экспорте используются русские названия столбцов; импорт принимает как их, так и английские. В этом руководстве указаны английские названия.

---

## Справочник столбцов

| Столбец | Формат | Описание |
|---|---|---|
| `Attribute N name` | Текст | Название атрибута (например, `Color`, `Size`) |
| `Attribute N value(s)` | Текст через вертикальную черту | Значение или значения для этой строки (например, `Blue` или `Blue | Red`) |
| `Attribute N visible` | `1` или `0` | `1` = показывается на странице товара; `0` = скрыт |
| `Attribute N global` | `1` или `0` | `1` = глобальный атрибут таксономии; `0` = локальный атрибут |

## Простые товары с несколькими значениями атрибута

Для простого товара, который продаётся в нескольких цветах (но не как отдельные вариации), перечислите все значения в столбце `Attribute 1 value(s)` через вертикальную черту `|`:

```
Name,Type,SKU,Regular price,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global
Blue Scarf,simple,SCARF-001,14.99,Color,Blue | Navy | Teal,1,1
```

Так создаётся один товар с атрибутом Color, который показывает на странице товара все три цвета.

## Вариативные товары с вариациями

У вариативных товаров атрибуты работают иначе. В родительской строке перечисляются все возможные значения атрибута. Каждая строка вариации содержит только значение этой конкретной вариации.

**Родительская строка (Type: variable):**

```
Name,Type,SKU,Regular price,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global
T-Shirt,variable,TSHIRT,20.00,Size,S | M | L | XL,1,1
```

**Строки вариаций (Type: variation):**

```
Name,Type,SKU,Regular price,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global
,variation,TSHIRT-S,18.00,Size,S,1,1
,variation,TSHIRT-M,18.00,Size,M,1,1
,variation,TSHIRT-L,20.00,Size,L,1,1
,variation,TSHIRT-XL,20.00,Size,XL,1,1
```

Столбец `Name` в строках вариаций пустой — WooCommerce формирует название вариации из значений атрибутов.

## Два атрибута (размер + цвет)

Для товара с двумя атрибутами:

**Родительская строка:**

```
Name,Type,SKU,Attribute 1 name,Attribute 1 value(s),Attribute 1 visible,Attribute 1 global,Attribute 2 name,Attribute 2 value(s),Attribute 2 visible,Attribute 2 global
Running Shoe,variable,SHOE,Size,7 | 8 | 9 | 10,1,1,Color,Black | White,1,1
```

**Строки вариаций:**

```
,variation,SHOE-7-BLK,Size,7,1,1,Color,Black,1,1
,variation,SHOE-7-WHT,Size,7,1,1,Color,White,1,1
,variation,SHOE-8-BLK,Size,8,1,1,Color,Black,1,1
```

Каждая строка вариации указывает ровно одно значение для каждого атрибута (а не список через вертикальную черту).

## Глобальные и локальные атрибуты

### Глобальные атрибуты (`Attribute N global: 1`)

Глобальные атрибуты задаются в таксономии атрибутов WooCommerce (Товары → Атрибуты в админке WordPress). Используйте глобальные атрибуты, когда:
- у нескольких товаров одни и те же значения атрибута (одинаковые цвета, одинаковые размеры)
- нужно фильтровать товары по атрибуту на страницах магазина
- вы используете виджет многоуровневой навигации WooCommerce

При импорте с `global: 1` WooCommerce создаёт значение атрибута, если его ещё нет. Названия атрибутов должны совпадать в точности (с учётом регистра), чтобы WooCommerce сопоставил их с существующей таксономией.

### Локальные атрибуты (`Attribute N global: 0`)

Локальные атрибуты относятся только к одному товару. Используйте их для характеристик конкретного товара, которые больше нигде не применяются (например, `Material: 100% cashmere` у одного определённого товара).

Локальные атрибуты нельзя использовать для фильтрации вариаций и в многоуровневой навигации.

## Частые ошибки импорта атрибутов

### Столбцы атрибутов не распознаются

**Причина:** названия столбцов не совпадают с шаблоном в точности — лишние или пропущенные пробелы, неправильная нумерация или сокращённые названия.

Неправильно: `Attribute1 name`, `attribute 1 name`, `Attr 1 name`
Правильно: `Attribute 1 name`

**Решение:** используйте точные названия столбцов с пробелом между `Attribute` и номером.

### Атрибуты вариации не совпадают с родительскими

**Причина:** название атрибута в строке вариации не совпадает с названием в родительской строке, или вариация указывает значение, которого нет в списке значений родителя.

**Решение:** названия атрибутов должны быть одинаковыми в родительской строке и строках вариаций. Значения вариаций должны входить в список значений родительской строки.

### Вертикальная черта с пробелами

**Причина:** вперемешку используются ` | ` (с пробелами вокруг черты) и `|` (без пробелов). WooCommerce обрезает пробелы в значениях, но несогласованность может приводить к несовпадениям.

**Решение:** используйте `|` с пробелами или без них, но единообразно во всём файле. WooCommerce обрезает пробелы вокруг каждого значения.
