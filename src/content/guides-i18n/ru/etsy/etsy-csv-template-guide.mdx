## Что такое CSV объявлений Etsy (и чем он не является)

Etsy позволяет выгрузить активные объявления в CSV: откройте **Менеджер магазина → Настройки → Параметры → Скачать данные** и выберите выгрузку объявлений в CSV. По данным справки Etsy, файл содержит для каждого объявления:

- Заголовок
- Описание
- Цену и код валюты
- Количество
- Теги
- Материалы
- URL изображений
- SKU (если вы добавляли SKU к объявлениям)

**У Etsy нет загрузки объявлений из CSV.** Правка файла ничего не меняет в магазине, и Etsy не даёт загрузить его обратно. Продавцы используют выгрузку, чтобы:

- Проверять и приводить в порядок данные объявлений в таблице
- Хранить резервную копию каталога
- Переносить объявления на другую платформу, например в Shopify или WooCommerce
- Передавать данные стороннему приложению массовой публикации, которое работает через API Etsy

Для массовых изменений внутри Etsy используйте массовое редактирование на странице «Объявления» в Менеджере магазина.

## Колонки выгрузки

В файле у каждого поля своя колонка с заголовком вроде `TITLE`, `DESCRIPTION`, `PRICE`, `CURRENCY_CODE`, `QUANTITY`, `TAGS`, `MATERIALS` и `SKU`. У каждой фотографии отдельная колонка (`IMAGE1`, `IMAGE2` и так далее) с URL изображения.

| Колонка | Что содержит | Формат |
|---|---|---|
| `TITLE` | Заголовок объявления | До 140 символов |
| `DESCRIPTION` | Описание объявления | Простой текст |
| `PRICE` | Цена в валюте магазина | Простое число, например `14.99` |
| `CURRENCY_CODE` | Валюта магазина | Трёхбуквенный код, например `USD` |
| `QUANTITY` | Доступное количество | Целое число, до 999 |
| `TAGS` | Поисковые теги | Через запятую, до 13 |
| `MATERIALS` | Материалы | Через запятую, до 13 |
| `IMAGE1`, `IMAGE2`, ... | URL фотографий | Полные адреса `https://` |
| `SKU` | Ваш SKU | Текст |

Сохраняйте названия колонок без изменений, если файл потом будет читать какой-либо инструмент.

## Ограничения, которые должно соблюдать каждое поле

Эти ограничения применяет редактор объявлений Etsy. Файл, который их нарушает, нельзя снова превратить в корректные объявления, каким бы инструментом вы ни пользовались:

- **Заголовок:** не больше 140 символов. Поиск Etsy показывает только начало, поэтому ставьте самые важные слова вперёд.
- **Теги:** до 13 на объявление, каждый не длиннее 20 символов с пробелами. Используйте буквы, цифры и пробелы: большинство символов в тегах Etsy не принимает.
- **Материалы:** до 13 на объявление.
- **Количество:** целое число до 999 на объявление.
- **Цена:** простое число в валюте магазина, без символа валюты.

---

## Формат цен

- Используйте простое десятичное число: `14.99`
- Без символов валют (`$`, `€`, `£`)
- В качестве десятичного разделителя ставьте точку, а не запятую, даже если ваша таблица использует запятые
- Валюту задаёт магазин, а `CURRENCY_CODE` её только фиксирует

---

## Теги

Теги записываются в одной ячейке через запятую:

```
handmade,gift for her,leather wallet,birthday gift
```

Поскольку в ячейке есть запятые, в CSV она должна быть в двойных кавычках. Таблицы делают это сами при сохранении. На что обращать внимание:

- Больше 13 тегов в ячейке
- Тег длиннее 20 символов
- Двойные запятые или пробелы вокруг запятых, оставшиеся после правки

---

## Поля, которые может запросить приложение массовой публикации

Выгрузка Etsy содержит не все настройки объявления. Сторонние приложения, которые создают объявления через API Etsy, часто требуют дополнительные колонки: кто изготовил товар (`who_made`), когда он изготовлен (`when_made`), относится ли он к материалам для творчества (`is_supply`), профиль доставки и раздел магазина. Допустимые значения берутся из API Etsy и со временем меняются (например, диапазоны лет для `when_made`), поэтому используйте ровно те значения, что указаны в шаблоне этого приложения.

## Частые проблемы после правки в таблице

### Цены с символами или запятыми

Цена вроде `$14.99` или `14,99` — это не простое число.

**Решение:** через «Найти и заменить» удалите `$`, `€` и `£`, а десятичные запятые замените точками.

### Слишком длинный заголовок

В заголовке больше 140 символов.

**Решение:** добавьте в Excel вспомогательную колонку с `=LEN(A2)` (в русском Excel `=ДЛСТР(A2)`), чтобы найти заголовки длиннее 140 символов, и сократите их.

### Слишком много тегов или слишком длинные теги

У объявления больше 13 тегов, или какой-то тег длиннее 20 символов.

**Решение:** посчитайте теги (запятые + 1) и следите, чтобы каждый был не длиннее 20 символов.

### Битые ссылки на изображения

В ячейке изображения записано, например, `mug.jpg` или ссылка без `https://`.

**Решение:** используйте полный URL изображения, начинающийся с `https://`.
