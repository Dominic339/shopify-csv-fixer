## Значения да/нет зависят от файла

Amazon не использует один формат да/нет во всех своих файлах загрузки. То, что принимает колонка, зависит от файла, который вы заполняете:

| Файл | Примеры колонок | Допустимые значения |
|---|---|---|
| Шаблон категории (скачивается в Seller Central для вашего типа товара) | `batteries_required`, `are_batteries_included` | То, что вкладка **Valid Values** шаблона указывает для этой колонки. Для полей о батареях обычно `true` / `false` |
| Inventory Loader (файл предложений с `sku`, `product-id`, `add-delete`) | `will-ship-internationally` | `n` или `1` только для США, `y` или `2` для международной доставки |
| Inventory Loader | `expedited-shipping` | Не да/нет: список вариантов доставки (см. ниже) |

Руководство Amazon по Inventory Loader указывает для `batteries_required` и `are_batteries_included` варианты `true` или `false`, и Listings API Amazon тоже хранит их как true/false.

**Самая частая ошибка:** ввести слово, которого нет в списке шаблона, например `Yes`, `Y` или `1` в колонке, для которой вкладка Valid Values указывает `true` / `false`, или перенести правило из одного файла Amazon в другой.

## Сначала проверьте вкладку Valid Values

В каждом шаблоне категории, скачанном из Seller Central, есть две вкладки, которые решают этот вопрос для вашего файла:

1. **Data Definitions:** описывает каждую колонку и указывает, обязательна ли она.
2. **Valid Values:** перечисляет точные значения, которые принимает каждая колонка с выпадающим списком.

Найдите название колонки на вкладке Valid Values и скопируйте значения оттуда, в точности как они написаны. Шаблоны со временем меняются и различаются по категориям и площадкам, поэтому проверяйте ту версию, которую собираетесь загрузить, а не сохранённую несколько месяцев назад. Если колонки, которую вы ожидали, нет в шаблоне, ваш тип товара её не использует.

## Колонки доставки в Inventory Loader

Если вы обновляете предложения файлом Inventory Loader (тем, где есть колонки `sku`, `product-id` и `add-delete`), две колонки доставки похожи на поля да/нет, но подчиняются своим правилам. Руководство Amazon по Inventory Loader определяет их так:

| Название колонки | Ожидаемые значения | Что определяет |
|---|---|---|
| `will-ship-internationally` | `n` или `1` только для США, `y` или `2` для международной доставки | Отправляете ли вы предложение за пределы США |
| `expedited-shipping` | `Next`, `Second`, `Domestic`, `International` и `Plus` через запятую или `N`, если ничего | Какие варианты ускоренной доставки вы предлагаете |

Значит, `expedited-shipping` — не поле да/нет, и `y` в нём не соответствует ни одному варианту. Напишите `Next,Second`, чтобы предложить доставку за один и два дня, или оставьте ячейку пустой, если ничего не предлагаете.

## Как таблицы меняют значения да/нет

### Excel

1. **Флажки и формулы:** ячейки с флажками и формулы вроде `=IF(A2>0, TRUE, FALSE)` дают собственные `TRUE` / `FALSE` Excel (в русском Excel они отображаются как ИСТИНА / ЛОЖЬ). Это работает, только если в списке вашего шаблона есть true/false, и никогда не работает в колонке `will-ship-internationally` из Inventory Loader.
2. **Введённые слова:** набранные вручную `Yes`, `No` или `Y` остаются как есть, и в файле оказывается смесь написаний.
3. **Прямое открытие CSV:** при двойном щелчке по CSV Excel угадывает типы колонок. Текст вроде `true` может превратиться в логическое значение Excel и сохраниться как `TRUE`.

### Google Sheets

Google Таблицы ведут себя так же: колонки с флажками и формулы дают `TRUE` / `FALSE`, что бы ни ожидала целевая колонка.

## Поиск недопустимых значений

### Отфильтруйте каждую колонку

1. Откройте файл через **Данные → Из текстового/CSV-файла**, чтобы Excel его не переформатировал.
2. Нажмите кнопку фильтра в колонке да/нет (например, `batteries_required`).
3. Сравните показанные значения со вкладкой Valid Values. Любое другое значение — проблема, как и пустая ячейка в колонке, которую вкладка Data Definitions отмечает как обязательную.

### Формула во вспомогательной колонке

Добавьте колонку рядом с полем и перечислите в формуле допустимые значения. Для колонки true/false:

```
=IF(OR(LOWER(A2)="true", LOWER(A2)="false", A2=""), "OK", "INVALID: "&A2)
```

В русском Excel эти функции называются ЕСЛИ, ИЛИ и СТРОЧН. Для `will-ship-internationally` из Inventory Loader проверяйте вместо этого `y`, `n`, `1` и `2`. Отфильтруйте строки с `INVALID`, чтобы найти все проблемные значения.

## Массовое исправление недопустимых значений

### Найти и заменить в Excel

1. Нажмите **Ctrl+H** (Найти и заменить).
2. В поле **Найти** введите неверное значение, например `Yes`.
3. В поле **Заменить на** введите значение со вкладки Valid Values, например `true`.
4. Нажмите **Параметры** и отметьте **Ячейка целиком**, чтобы менялись только целые ячейки.
5. Нажмите **Заменить все**, затем повторите для `No` и любых других найденных написаний.

> **Важно:** прежде чем заменять, решите, что означает каждое значение. `Yes` в `batteries_required` и `Yes` в другой колонке могут требовать разных замен.

### Замените результаты формул значениями

Если колонки да/нет вычисляются формулами:

1. Выделите колонку и скопируйте её (**Ctrl+C**).
2. Щелчок правой кнопкой → **Специальная вставка → Значения**.
3. Формулы станут обычным текстом, который затем можно исправить через «Найти и заменить».

### Google Sheets

1. Выделите колонку.
2. **Правка → Найти и заменить** (Ctrl+H).
3. Отметьте **Учитывать регистр** и **Совпадение с содержимым всей ячейки**, найдите неверное значение и замените его допустимым.

## Как избежать проблем в следующий раз

### Используйте выпадающие списки шаблона

Шаблоны категорий Amazon содержат выпадающие списки, построенные по вкладке Valid Values. Вводите данные прямо в шаблон, а не вставляйте поверх него CSV, и выпадающие списки удержат значения в пределах списка.

### Добавьте свой выпадающий список

Для файла без выпадающих списков выделите ячейки колонки под заголовком, откройте **Данные → Проверка данных**, выберите **Список** и введите допустимые значения, например `true,false` (или `y,n,1,2` для `will-ship-internationally`).

### Проверяйте перед каждой загрузкой

1. Откройте итоговый файл в текстовом редакторе (не в Excel) и просмотрите колонки да/нет.
2. Убедитесь, что каждое значение есть в списке для этой колонки.
3. Заполните все колонки, которые вкладка Data Definitions отмечает как обязательные.

Если вы загружаете файлы через Inventory Loader, корректор StriveFormats сам проверит `will-ship-internationally` и `expedited-shipping` по руководству Amazon.
