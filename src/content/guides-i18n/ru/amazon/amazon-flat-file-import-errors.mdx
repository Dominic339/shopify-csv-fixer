## Как Amazon проверяет плоские файлы

Плоские файлы Amazon — это CSV-файлы с разделителями-табуляциями или запятыми, которые подчиняются строгим схемам столбцов, заданным для каждой категории товаров. Когда вы загружаете плоский файл, Amazon пропускает его через несколько этапов проверки:

1. **Соответствие шаблону** — проверяет, совпадают ли заголовки столбцов с ожидаемым шаблоном для этого типа файла
2. **Обязательные поля** — проверяет, что во всех обязательных столбцах есть значения
3. **Типы данных** — проверяет числа, логические значения и значения из фиксированных списков
4. **Бизнес-правила** — проверяет ASIN, SKU, коды состояния и диапазоны цен
5. **Проверка каталога** — сопоставляет идентификаторы товаров с каталогом Amazon

После обработки Amazon формирует **отчёт об обработке** (в Seller Central в разделе «Запасы» → «Добавить товары с помощью загрузки»). Всегда просматривайте отчёт об обработке: в нём перечислены все строки с ошибками и конкретная ошибка для каждой.

## Ошибка: недопустимый или отсутствующий seller_sku

**Причина:** `seller_sku` пустой, длиннее 40 символов, содержит недопустимые символы или повторяет SKU, который уже есть в вашем каталоге.

**Правила для seller_sku:**
- Не более 40 символов
- Без пробелов (используйте дефисы или подчёркивания)
- Латинские буквы и цифры, а также `-`, `_`, `.`
- Должен быть уникальным во всём аккаунте продавца Amazon

**Решение:** убедитесь, что у каждой строки уникальный SKU. Найти дубликаты поможет формула `=СЧЁТЕСЛИ($A:$A; A2)`. Сократите SKU длиннее 40 символов.

## Ошибка: нет item_name / слишком длинное название

**Причина:** `item_name` пустой или превышает ограничение Amazon на длину названия (зависит от категории, обычно 200–500 символов).

**Решение:**
- Заполните `item_name` в каждой строке товара
- Используйте в Excel `=ДЛСТР(B2)`, чтобы найти названия, которые превышают лимит вашей категории
- Уточните точный лимит символов в своём шаблоне

## Ошибка: недопустимый condition_type

**Причина:** в столбце `condition_type` значение, которого нет в списке допустимых у Amazon.

**Допустимые значения:**

| Значение | Описание |
|---|---|
| `New` | Совершенно новый, в заводской упаковке |
| `UsedLikeNew` | Б/у — как новый |
| `UsedVeryGood` | Б/у — очень хорошее |
| `UsedGood` | Б/у — хорошее |
| `UsedAcceptable` | Б/у — приемлемое |
| `CollectibleLikeNew` | Коллекционный — как новый |
| `CollectibleVeryGood` | Коллекционный — очень хорошее |
| `CollectibleGood` | Коллекционный — хорошее |
| `CollectibleAcceptable` | Коллекционный — приемлемое |
| `Refurbished` | Восстановлен продавцом |
| `Club` | Club (медиакатегория) |

**Решение:** замените нестандартные значения состояния на одно из списка выше. `New` пишется с заглавной буквы; `new` (строчными) отклоняется.

## Ошибка: недопустимая цена

**Причина:** в столбце `price` есть символ валюты (`$`), используется десятичная запятая, значение равно нулю, отрицательное или пустое.

**Правила цен Amazon:**
- Обычное десятичное число: `19.99`
- Без символов валют
- Должна быть положительной (больше 0)
- Точка в качестве десятичного разделителя

**Решение:** уберите символы валют и замените десятичные запятые на точки. В русской версии Excel десятичный разделитель — запятая, поэтому после сохранения проверьте в текстовом редакторе, что в ценах стоит точка.

---

## Ошибка: недопустимый fulfillment_center_id / канал выполнения

**Причина:** в столбце канала выполнения заказов нераспознанное значение.

**Допустимые значения:**

| Значение | Описание |
|---|---|
| `DEFAULT` | Выполнение продавцом (FBM) |
| `AMAZON_NA` (или `AMAZON`) | Выполнение Amazon (FBA) |

Точное название столбца и допустимые значения немного различаются в зависимости от шаблона плоского файла. Сверьтесь со своим шаблоном.

**Решение:** используйте `DEFAULT` для FBM и `AMAZON_NA` или `AMAZON` для FBA. Не используйте `FBA`, `FBM` и другие сокращения.

## Ошибка: product_id / ASIN не найден

**Причина:** `product_id` (ASIN, UPC, EAN или ISBN) не совпадает ни с одним товаром в каталоге Amazon, или `product_id_type` не соответствует типу указанного идентификатора.

**Значения product_id_type:**

| Значение | Тип идентификатора |
|---|---|
| `1` | ASIN |
| `2` | ISBN |
| `3` | UPC |
| `4` | EAN |

**Решение:**
- Проверьте, что идентификатор товара правильный и активен в каталоге Amazon
- Укажите в `product_id_type` тип идентификатора, который стоит в `product_id`
- Для новых товаров, у которых ещё нет ASIN, возможно, придётся создать новое предложение, а не добавлять запасы к существующему

## Ошибка: неподходящий шаблон для категории товара

**Причина:** вы использовали общий шаблон Inventory Loader для категории, которой нужен собственный плоский файл (например, одежда, обувь, ювелирные изделия).

У Amazon есть шаблоны для отдельных категорий с дополнительными обязательными полями. При неправильном шаблоне все обязательные поля этой категории оказываются незаполненными.

**Решение:**
- В Seller Central откройте «Запасы» → «Добавить товары с помощью загрузки» → «Скачать файл запасов»
- Выберите категорию товара, чтобы получить нужный шаблон
- Скачайте плоский файл для этой категории и перенесите в него свои данные

Распространённые категории с собственными шаблонами: одежда, обувь, ювелирные изделия, электроника, книги, музыка, видео, спорт и отдых.

## Как читать отчёт об обработке

После загрузки скачайте отчёт об обработке в Seller Central («Запасы» → «Добавить товары с помощью загрузки» → «Отслеживать статус загрузки» → «Просмотреть отчёт об обработке»).

В отчёте три вкладки:
- **Summary** — общее число строк, успешных и с ошибками
- **Results** — по одной строке на каждую запись файла, со статусом и сообщением об ошибке
- **Original** — исходные загруженные данные

Чтобы найти строки с ошибками, отфильтруйте вкладку Results по столбцу `status`. В строках `FAILURE` есть `error-code` и `error-message`, которые точно объясняют, что пошло не так.
