## Что такое CategoryID?

Колонка `Category` (или `CategoryID`, в зависимости от версии шаблона File Exchange) в CSV для массовой загрузки eBay — это **числовой идентификатор** категории eBay, к которой относится товар. У каждого активного объявления на eBay должна быть категория, и по этому ID eBay определяет:

- Где объявление появляется при просмотре категорий.
- Какие характеристики товара (обязательные поля) относятся к объявлению.
- В каких поисковых запросах покупателей показывается товар.

Пустой или неверный CategoryID — одна из самых частых причин, по которым загрузка через File Exchange полностью не проходит или создаёт объявления с неполными характеристиками.

---

## CategoryID и путь категории

В CSV нужен **номер** (CategoryID), а не понятный человеку путь категории. Например:

| Путь категории | CategoryID |
|---|---|
| Clothing, Shoes & Accessories > Men > Men's Clothing > Shirts > T-Shirts | 15687 |
| Cameras & Photo > Digital Cameras | 31388 |
| Health & Beauty > Vitamins & Dietary Supplements | 180959 |

Текст пути в CSV использовать нельзя. Нужен числовой ID.

---

## Почему CategoryID важен для характеристик

Система характеристик товаров eBay (бренд, размер, цвет, материал и т. д.) зависит от категории. Неверная категория означает, что:
- Обязательные характеристики правильной категории не запрашиваются и не проверяются.
- Объявление может опуститься в результатах поиска, если не хватает обязательных характеристик.
- Покупатели, фильтрующие по характеристикам в вашей категории, не найдут объявление.

Всегда выбирайте самую конкретную категорию (нижнюю категорию, которая точно описывает товар), а не широкую родительскую.

## Как найти правильный CategoryID

### Способ 1: подсказки категорий eBay (Seller Hub)

1. В Seller Hub вручную создайте черновик объявления для одного из товаров.
2. На шаге «Категория» найдите свой тип товара через поле поиска.
3. eBay предложит категории по вашим ключевым словам.
4. Выберите самую конкретную подходящую категорию.
5. Запишите название категории и найдите её ID одним из способов ниже.

### Способ 2: справочник ID категорий eBay

В справке Seller Hub Reports есть ссылка на справочник названий и ID категорий для массовой загрузки:

1. Откройте **Seller Hub → Отчёты → Загрузки** и перейдите в справку по шаблонам загрузки.
2. Найдите справочник названий и ID категорий и отыщите свой тип товара.
3. Разработчики также могут получить полное дерево категорий через API eBay (например, Taxonomy API).

### Способ 3: посмотрите на URL работающего объявления

Если у вас есть своё объявление или объявление конкурента в той же категории:

1. Откройте страницу категории на eBay (нажмите на название категории в цепочке над объявлением).
2. У страниц категорий адреса вида `https://www.ebay.com/b/Levis-Mens-Jeans/11483/bn_700176`.
3. Число после названия категории (`11483`, мужские джинсы) и есть ID категории.

### Способ 4: скачайте шаблон категории

В разделе **Seller Hub → Отчёты → Загрузки** eBay позволяет скачать шаблон объявлений для конкретной категории. Выбранный там ID категории и нужно использовать в файле.

## CategoryID в CSV File Exchange

В шаблонах объявлений eBay колонка называется `*Category` (звёздочка обозначает обязательную колонку), а в шаблоне черновиков — `Category ID`.

```
*Action(SiteID=US|Country=US|Currency=USD|Version=1193),*Title,*Category,*StartPrice,...
Add,Men's Blue Cotton T-Shirt,15687,19.99,...
Add,Men's Slim Fit Jeans,11483,45.00,...
```

**Правила:**
- Значение должно быть положительным целым числом, соответствующим действующей нижней категории eBay.
- Родительские и промежуточные категории обычно не принимаются. Используйте самую конкретную категорию.
- Категория должна действовать на вашей площадке eBay (категории США отличаются от категорий Великобритании, Германии, Австралии и т. д.).

## Массовое заполнение CategoryID

Для больших каталогов, где большинство товаров относится к нескольким категориям:

### В Excel: задайте категории с помощью ЕСЛИ или ВПР

Если у вас есть вспомогательная колонка с кодом типа товара:

```
=IF(B2="T-Shirts", 15687, IF(B2="Jeans", 11483, ""))
```

Или создайте справочную таблицу (тип товара → CategoryID) и используйте ВПР:

```
=VLOOKUP(B2, CategoryTable!$A:$B, 2, FALSE)
```

В русском Excel функции называются `ЕСЛИ` и `ВПР`, а аргументы разделяются точкой с запятой.

### В Excel: заполните вниз группы с одинаковой категорией

1. Отсортируйте список товаров по типу товара.
2. Введите CategoryID у первого товара каждой группы.
3. Выделите диапазон от этой ячейки до последнего товара группы.
4. Нажмите **Ctrl+D**, чтобы заполнить вниз.

### С помощью фильтра

1. Отфильтруйте каталог по колонке типа товара.
2. Выделите все видимые ячейки в колонке CategoryID.
3. Введите CategoryID и нажмите **Ctrl+Enter**, чтобы заполнить все выделенные ячейки сразу.

## Проверка CategoryID перед загрузкой

Неверный CategoryID создаёт объявления не в той категории. Это частая ошибка, и её трудно заметить:

1. **Выборочная проверка:** возьмите 5 значений CategoryID из CSV и найдите их на eBay, чтобы убедиться, что они соответствуют ожидаемому пути категории.
2. **Сверка со справочником типов товаров:** ведите простую таблицу «тип товара → CategoryID» и пересматривайте её, когда добавляете новые типы.
3. **Тестовая загрузка:** сначала загрузите тестовый файл на 1–3 строки. Посмотрите на созданные объявления и убедитесь, что они в правильной категории.
4. **Изучите файл результатов eBay:** после каждой загрузки на странице загрузок Seller Hub Reports появляется файл результатов. Проверьте его на ошибки строк, связанные с недопустимыми ID категорий.

## Частые ошибки

| Сообщение об ошибке | Вероятная причина |
|---|---|
| "Category is required" | Колонка CategoryID пуста |
| "Invalid category" | ID не является действующей нижней категорией eBay |
| "Category not allowed for this listing type" | Ограничение категории для фиксированной цены или аукциона |
| Ошибки характеристик после загрузки | Неверная категория, поэтому характеристики не подходят к вашим товарам |
