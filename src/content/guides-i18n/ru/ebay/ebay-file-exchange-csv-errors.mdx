## Как eBay проверяет массовую загрузку

Массовая загрузка объявлений на eBay сейчас идёт через **Seller Hub → Отчёты → Загрузки**, где также можно скачать шаблоны CSV в формате File Exchange. При загрузке файла eBay проверяет:

1. **Структуру файла**: строку INFO в самом начале и строку заголовков под ней
2. **Колонку Action**: что сделать с каждой строкой объявления
3. **Типы данных**: цены — числа, количества — целые числа, URL — полные веб-адреса
4. **Бизнес-правила**: допустимые ID категорий, ID состояния, разрешённые в категории, допустимые сроки
5. **Правила содержимого**: длину заголовка и правила объявлений

После обработки на странице загрузок появляется файл результатов. В нём видно, какие строки прошли, какие нет и почему. Всегда проверяйте его: eBay часто импортирует часть строк и отклоняет остальные.

## Ошибка: шаблон не распознан (строка INFO)

Текущие шаблоны eBay начинаются со строки вроде этой, расположенной над заголовками колонок:

```
#INFO,Version=1.0.0,Template=fx_category_template_EBAY_US
```

Эта первая строка INFO нужна eBay при загрузке. Остальные строки, начинающиеся с `#INFO` или `INFO` (подсказки в шаблоне), можно оставить или удалить.

**Решение:**
- Не удаляйте первую строку шаблона, даже если она похожа на примечание.
- Если вы работаете в Excel на Mac, проверьте, что перед `#INFO` в первой строке ничего нет. Excel может добавить туда невидимые символы, и тогда eBay отклоняет файл. Откройте CSV в текстовом редакторе, чтобы их увидеть.

StriveFormats читает строку заголовков под строками INFO и при скачивании возвращает эти строки наверх, уже без лишних символов.

## Ошибка: Action отсутствует или недопустим

В каждой строке объявления нужен Action. Исключение — строки вариаций (`Relationship` = `Variation`): они стоят под родительским объявлением и оставляют Action пустым.

Допустимые значения:

| Значение | Смысл |
|---|---|
| `Add` | Создать новое объявление |
| `VerifyAdd` | Проверить новое объявление и увидеть сборы, не публикуя его |
| `Revise` | Изменить поля активного объявления |
| `Relist` | Повторно выставить завершённое объявление |
| `End` | Завершить активное объявление (с `EndCode`) |
| `Status` | Изменить статус проданного товара, например отметить его как отправленный |
| `AddToItemDescription` | Добавить текст в конец описания активного объявления |
| `Draft` | Сохранить объявление в черновиках (только шаблон черновиков) |

**Решение:** в каждой строке объявления должно быть одно из значений выше, написанное точно так же. eBay сравнивает их точно, поэтому `verifyadd` — не то же самое, что `VerifyAdd`.

## Ошибка: недопустимая категория

**Причина:** значение в `Category` (или `Category ID`) не является допустимым числовым ID категории eBay, или категория упразднена.

ID категорий eBay — это числа (например, `15687` для мужских футболок на eBay в США). Время от времени они меняются, когда eBay перестраивает свои категории.

**Решение:**
- Найдите правильный ID категории в дереве категорий eBay
- Не переносите ID категорий из старых шаблонов, не проверив, что они ещё действуют
- Некоторые категории требуют дополнительных характеристик, поэтому проверьте, что нужно категории

В руководстве [eBay CategoryID: что это и как его задать](/guides/ebay/categoryid-and-file-exchange) описано, как найти ID.

## Ошибка: слишком длинный заголовок

**Причина:** значение в `Title` длиннее 80 символов — это предел eBay для заголовков объявлений.

**Решение:**

В Excel добавьте вспомогательную колонку: `=LEN(B2)` (замените B2 на ячейку колонки заголовка; в русском Excel функция называется `ДЛСТР`). Отфильтруйте строки длиннее 80 символов и сократите эти заголовки.

На Python:

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for i, row in enumerate(reader, 2):
        title_len = len(row.get("Title", ""))
        if title_len > 80:
            print(f"Row {i}: Title is {title_len} chars (max 80): {row['Title'][:60]}...")
```

## Ошибка: недопустимый ID состояния

**Причина:** значение в `ConditionID` не является допустимым ID состояния eBay или не разрешено в категории товара.

Распространённые ID состояния из таблицы состояний eBay:

| ID | Состояние | Примечания |
|---|---|---|
| `1000` | New | Также показывается как Brand New, New with tags или New with box |
| `1500` | New other | Новый без ярлыка или коробки, вскрытая упаковка |
| `1750` | New with defects | |
| `2000` | Certified Refurbished | Только для одобренных продавцов в некоторых категориях |
| `2500` | Seller refurbished | В некоторых категориях заменён уровнями восстановления ниже |
| `2010` / `2020` / `2030` | Excellent / Very Good / Good - Refurbished | Только для одобренных продавцов в некоторых категориях |
| `2750` | Like New | |
| `3000` | Used | Также показывается как Pre-owned |
| `4000` | Very Good | |
| `5000` | Good | |
| `6000` | Acceptable | |
| `7000` | For parts or not working | Только в категориях, где это уместно |

Какие ID можно использовать, зависит от категории, и названия, которые видят покупатели, тоже различаются по категориям.

**Решение:** замените названия состояний числовым ID. StriveFormats сам переводит названия состояний eBay (например, «Used» или «Open box») в их ID.

## Ошибка: недопустимый StartPrice

**Причина:** поле `StartPrice` содержит символ валюты (`$9.99`), использует десятичную запятую (`9,99`), отрицательное или пустое.

**Решение:**
- Удалите символы валют с помощью «Найти и заменить»
- Замените десятичные запятые точками
- Убедитесь, что каждая цена — положительное десятичное число
- Перед сохранением задайте колонке в Excel числовой формат

---

## Ошибка: недопустимый Duration

**Причина:** поле `Duration` содержит значение, которое eBay не принимает для формата объявления.

**Допустимые значения:**

| Формат | Duration |
|---|---|
| `FixedPrice` | `GTC` (Good 'Til Cancelled). У объявлений с фиксированной ценой больше нет срока в днях |
| `Auction` | `Days_1`, `Days_3`, `Days_5`, `Days_7` или `Days_10` |

**Решение:** используйте `GTC` для объявлений с фиксированной ценой и одно из значений `Days_` для аукционов.

## Ошибка: URL изображения недоступен

**Причина:** поле `PicURL` содержит URL, который eBay не может скачать: изображение требует входа, находится на вашем компьютере или за перенаправлением.

Seller Hub Reports на eBay принимает до **24 изображений** на объявление в `PicURL`, разделённых вертикальной чертой `|`. Каждый URL может быть длиной до 2048 символов, а пробелы в URL нужно записывать как `%20`.

**Решение:**
- Откройте каждый URL в приватном окне браузера. Изображение должно открыться сразу, без входа
- Используйте полные URL с `https://`
- Замените пробелы на `%20` (StriveFormats сделает это за вас)
- Избегайте сокращателей ссылок и сервисов перенаправления

## Ошибка: номер товара или UPC отображается как 1.23457E+11

**Причина:** Excel перевёл длинное число (`ItemID` или штрихкод в `P:UPC`) в экспоненциальную запись. Цифры после первых нескольких потеряны, поэтому eBay не находит объявление или не может сопоставить товар.

**Решение:** заново введите полные номера из своих записей. Справка eBay рекомендует перед сохранением задавать колонкам с номерами товаров числовой формат с 0 знаков после запятой. Текстовый формат тоже подходит. StriveFormats отмечает каждую ячейку, где это произошло.

## Ошибка: недопустимое количество

**Причина:** `Quantity` пустое, содержит дробную часть (например, `1.5`) или отрицательное.

**Решение:** используйте целые числа. У новых объявлений количество должно быть не меньше 1. В объявлениях с вариациями указывайте количество каждой вариации в её собственной строке, а не в родительской.

## Проверьте перед загрузкой всего файла

1. Скопируйте 2–3 строки в новый файл, сохранив строку INFO и строку заголовков.
2. Задайте им Action `VerifyAdd` и загрузите файл. eBay проверит строки и покажет сборы, ничего не публикуя.
3. Исправьте то, что покажет файл результатов, и верните Action `Add` для полного файла.
