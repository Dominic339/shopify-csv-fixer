## Universal Pre-Import Checklist

Run through these checks on every CSV, regardless of platform.

### File structure

- [ ] The file has a `.csv` extension and is plain comma-separated text (not `.xlsx` renamed to `.csv`; open it in a text editor to check)
- [ ] Row 1 contains column headers, with no blank rows or title row above it
- [ ] No blank rows anywhere in the file (to find them in Excel, add a helper column with `=COUNTA(A2:Z2)` and filter for 0; don't use Go To Special > Blanks, which selects every empty cell, not just empty rows)
- [ ] No summary, total, or formula rows at the bottom
- [ ] No merged cells (merged cells export as blanks in all cells except the first)
- [ ] Every row has the same number of fields as the header (count fields, not commas: commas inside quoted values don't separate columns)

### Encoding

- [ ] File is saved as **UTF-8** (check in VS Code status bar)
- [ ] No garbled characters (â€™, Ã©, Â£) visible in any field values
- [ ] If the platform doesn't recognise the first column, check its header for an invisible BOM prefix (in a text editor)

### Headers

- [ ] Column names match the platform's exact spelling, including case
- [ ] No leading or trailing spaces in any column name
- [ ] No duplicate column names
- [ ] Required columns are present (see platform-specific checklists below)

### Data types

- [ ] Price columns contain only numbers (no `$`, `EUR`, or other symbols)
- [ ] Boolean fields use the correct format for the platform (TRUE/FALSE, 1/0, y/n)
- [ ] Required text fields are not blank on any row
- [ ] SKU/identifier fields are unique across the file
- [ ] Image URLs are absolute (start with `https://`) and publicly accessible

## Shopify-Specific Checklist

- [ ] `Handle` is present and non-blank on every row
- [ ] Variant rows share the same `Handle` as the parent product row
- [ ] `Title` is present on the parent (first) row for each product; blank on variant rows is OK
- [ ] `Variant Price` is a plain number with no currency symbol (a blank price imports as 0.00)
- [ ] Boolean fields (`Published`, `Requires Shipping`, `Gift Card`) use `true` or `false`
- [ ] Products with variants have `Option1 Name` on the first row and an `Option1 Value` on every variant row
- [ ] No extra option columns without values (e.g., `Option3 Name` without `Option3 Value`)
- [ ] Image URLs are public `https://` links to image files (JPEG, PNG, GIF or WebP)
- [ ] `Tags` field uses commas to separate tags (wrapped in quotes if present)

## WooCommerce-Specific Checklist

- [ ] `Type` column contains a valid value: `simple`, `variable`, `variation`, `grouped`, or `external`
- [ ] `SKU` values are unique (SKU is optional, but duplicates fail)
- [ ] `Regular price` is a plain decimal number (no currency symbols)
- [ ] `In stock?` uses `1` or `0`, and `Backorders allowed?` uses `1`, `0` or `notify`
- [ ] Variation rows have a `Parent` value: the variable product's SKU, or `id:` followed by its product ID
- [ ] Attribute columns follow the `Attribute 1 name` / `Attribute 1 value(s)` naming pattern
- [ ] `Tax status` is `taxable`, `shipping`, or `none`
- [ ] Image URLs are absolute HTTPS URLs

## Etsy-Specific Checklist

Etsy has no CSV upload. These checks are for a listing export you'll edit, migrate or hand to a bulk-listing app.

- [ ] `TITLE` is non-blank and 140 characters or fewer
- [ ] `PRICE` is a plain positive number with no currency symbol
- [ ] `QUANTITY` is a whole number up to 999
- [ ] `TAGS` holds 13 or fewer comma-separated tags, each 20 characters or fewer
- [ ] `MATERIALS` holds 13 or fewer entries
- [ ] Image columns (`IMAGE1`, `IMAGE2`, ...) hold full `https://` URLs
- [ ] `SKU` values are unique, if you use SKUs
- [ ] Columns a bulk-listing app adds (such as `who_made`, `when_made` and `is_supply`) use the values in that app's template

## eBay-Specific Checklist

- [ ] The `Action` column has a value on every row, such as `Add`, `Revise`, `Relist` or `End`
- [ ] `Category` is a valid numeric eBay category ID
- [ ] `Title` is 80 characters or fewer
- [ ] `StartPrice` is a positive decimal number (no currency symbols)
- [ ] `ConditionID` uses eBay's numeric condition IDs (e.g., `1000` for New, `3000` for Used)
- [ ] `Duration` uses an allowed value (`GTC` for fixed-price listings; `Days_3`, `Days_5`, `Days_7` or `Days_10` for auctions)
- [ ] `PicURL` holds HTTPS image URLs, separated by a pipe `|` (up to 24)
- [ ] `Quantity` is a whole positive integer

## Amazon-Specific Checklist

These checks are for the Inventory Loader offer file. Category listing templates have their own columns, listed in the template's Data Definitions tab.

- [ ] The file is saved as tab-delimited text (`.txt`), not CSV
- [ ] `sku` is non-blank, unique, and 40 characters or fewer
- [ ] `product-id` and `product-id-type` agree (`1` = ASIN, `2` = ISBN, `3` = UPC, `4` = EAN)
- [ ] `price` is a positive decimal number (no currency symbols)
- [ ] `quantity` is a whole number (0 or more), left blank for FBA offers
- [ ] `item-condition` uses Amazon's numeric codes (`11` = New, `10` = Refurbished, `1` to `8` for used and collectible)
- [ ] `add-delete` is `a` (add or update), `d` (delete the offer) or `x` (delete the offer and its product data)
- [ ] `fulfillment-center-id` is `DEFAULT` for offers you ship yourself, or the FBA value for your region (such as `AMAZON_NA`)

## Test With a Small Batch First

Before uploading your entire catalog, test with 3-5 rows:

1. Copy 3 data rows into a new file (keep the same header row)
2. Upload the small test file
3. Review the import result. Check that all fields mapped correctly and the products look right
4. If it passes, import the full file

Testing with a small batch makes it much easier to identify problems before they affect hundreds of rows.

## What to Do If the Import Still Fails

1. Read the error message carefully. Platform error reports usually name the column or row that failed
2. Search for the exact error message plus the platform name to find platform-specific documentation
3. Upload the file to StriveFormats for automated validation. It catches issues the platform error messages don't explain clearly
