## What Etsy's Listing CSV Is (and Isn't)

Etsy lets you download your active listings as a CSV: open **Shop Manager → Settings → Options → Download Data** and choose the CSV download for your listings. According to Etsy's help, the file includes each listing's:

- Title
- Description
- Price and currency code
- Quantity
- Tags
- Materials
- Image URLs
- SKU (if you've added SKUs to your listings)

**Etsy has no CSV upload for listings.** Editing the file doesn't change anything in your shop, and Etsy doesn't offer a way to import it back. Sellers use the export to:

- Audit and clean up listing data in a spreadsheet
- Keep a backup of their catalogue
- Move listings to another platform, such as Shopify or WooCommerce
- Feed a third-party bulk listing app that works through Etsy's API

For bulk changes inside Etsy itself, use the bulk editing options in Shop Manager's Listings page.

## The Columns in the Export

In the file, each field has its own column, with headers such as `TITLE`, `DESCRIPTION`, `PRICE`, `CURRENCY_CODE`, `QUANTITY`, `TAGS`, `MATERIALS` and `SKU`. Photos get one column each (`IMAGE1`, `IMAGE2` and so on), holding the image's URL.

| Column | What it holds | Format |
|---|---|---|
| `TITLE` | Listing title | Up to 140 characters |
| `DESCRIPTION` | Listing description | Plain text |
| `PRICE` | Price in your shop currency | Plain number, like `14.99` |
| `CURRENCY_CODE` | Shop currency | Three-letter code, like `USD` |
| `QUANTITY` | Quantity available | Whole number, up to 999 |
| `TAGS` | Search tags | Comma-separated, up to 13 |
| `MATERIALS` | Materials | Comma-separated, up to 13 |
| `IMAGE1`, `IMAGE2`, ... | Photo URLs | Full `https://` URLs |
| `SKU` | Your SKU | Text |

Keep the column names exactly as they are if a tool will read the file back.

## Limits Each Field Must Respect

These are the limits Etsy's listing editor enforces. A file that breaks them can't be turned back into valid listings, whichever tool you use:

- **Title:** 140 characters at most. Etsy search shows only the start of it, so put the most important words first.
- **Tags:** up to 13 per listing, each 20 characters or fewer, including spaces. Stick to letters, numbers and spaces; Etsy refuses most symbols in tags.
- **Materials:** up to 13 per listing.
- **Quantity:** a whole number up to 999 per listing.
- **Price:** a plain number in your shop currency, with no currency symbol.

---

## Price Formatting

- Use a plain decimal number: `14.99`
- No currency symbols (`$`, `€`, `£`)
- Use a period (not a comma) as the decimal separator, even if your spreadsheet uses commas
- The currency is set by your shop, and `CURRENCY_CODE` only records it

---

## Tags

Tags sit in one cell, separated by commas:

```
handmade,gift for her,leather wallet,birthday gift
```

Because the cell contains commas, it must be wrapped in double quotes in the CSV. Spreadsheet apps do this for you when they save. Problems to watch for:

- More than 13 tags in the cell
- A tag longer than 20 characters
- Double commas or spaces around commas left behind after editing

## Fields a Bulk Listing App May Ask For

Etsy's export doesn't include every listing setting. Third-party apps that create listings through Etsy's API often ask for extra columns, such as who made the item (`who_made`), when it was made (`when_made`), whether it's a craft supply (`is_supply`), the shipping profile and the shop section. Their accepted values come from Etsy's API and change over time (for example, the year ranges for `when_made`), so use the exact values listed in that app's own template.

## Common Problems After Editing in a Spreadsheet

### Prices with symbols or commas

A price like `$14.99` or `14,99` isn't a plain number.

**Fix:** Use Find & Replace to remove `$`, `€`, `£`, and change comma decimal separators to periods.

### Title too long

The title is over 140 characters.

**Fix:** In Excel, add a helper column with `=LEN(A2)` to find titles over 140 characters, then shorten them.

### Too many tags, or tags too long

A listing has more than 13 tags, or a tag is over 20 characters.

**Fix:** Count the tags (commas + 1) and keep each tag to 20 characters or fewer.

### Broken image links

An image cell holds something like `mug.jpg` or a link without `https://`.

**Fix:** Use the full image URL, starting with `https://`.
