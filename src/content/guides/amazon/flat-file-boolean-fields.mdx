## Yes/No Values Depend on the File

Amazon doesn't use one yes/no format across all of its upload files. What a column accepts depends on which file you are filling in:

| File | Example columns | Accepted values |
|---|---|---|
| Category listing template (downloaded from Seller Central for your product type) | `batteries_required`, `are_batteries_included` | Whatever the template's **Valid Values** tab lists for that column. For battery fields this is usually `true` / `false` |
| Inventory Loader (offer file with `sku`, `product-id`, `add-delete`) | `will-ship-internationally` | `n` or `1` for US only, `y` or `2` for international |
| Inventory Loader | `expedited-shipping` | Not yes/no: a list of shipping options (see below) |

Amazon's own Listings API also stores `batteries_required` as a true/false value, which matches what sellers see in their category templates.

**The most common mistake:** typing a word that isn't on the template's list, such as `Yes`, `Y` or `1` in a column whose Valid Values tab says `true` / `false`, or copying a convention from one Amazon file into another.

## Check the Valid Values Tab First

Every category template you download from Seller Central has two tabs that settle the question for your file:

1. **Data Definitions:** describes each column and says whether it is required.
2. **Valid Values:** lists the exact values each dropdown column accepts.

Find the column name in the Valid Values tab and copy the values from there, spelled exactly as shown. Templates change over time and differ between categories and marketplaces, so check the version you are about to upload rather than one you saved months ago. If a column you expected isn't in your template, your product type doesn't use it.

## Inventory Loader Shipping Columns

If you update offers with the Inventory Loader file (the one with `sku`, `product-id` and `add-delete` columns), two shipping columns look like yes/no fields but follow their own rules. Amazon's Inventory Loader guide defines them like this:

| Column name | Expected values | What it controls |
|---|---|---|
| `will-ship-internationally` | `n` or `1` for US only, `y` or `2` for international | Whether you ship the offer outside the US |
| `expedited-shipping` | `Next`, `Second`, `Domestic`, `International` and `Plus`, separated by commas, or `N` for none | Which faster shipping options you offer |

So `expedited-shipping` isn't a yes/no field, and a `y` there doesn't match any option. Write `Next,Second` to offer one-day and two-day shipping, or leave the cell blank if you offer none.

## How Spreadsheets Change Yes/No Values

### Excel

1. **Checkboxes and formulas:** checkbox cells and formulas like `=IF(A2>0, TRUE, FALSE)` produce Excel's own `TRUE` / `FALSE`. That only works if your template's list contains true/false, and it never works in the Inventory Loader's `will-ship-internationally` column.
2. **Typed words:** a hand-typed `Yes`, `No` or `Y` stays as typed, so the file ends up with a mix of spellings.
3. **Opening a CSV directly:** double-clicking a CSV lets Excel guess column types. Text such as `true` may be turned into Excel booleans and saved back as `TRUE`.

### Google Sheets

Sheets behaves the same way: checkbox columns and formulas produce `TRUE` / `FALSE`, whatever the target column expects.

## Finding Invalid Values

### Filter each column

1. Open your file via **Data → From Text/CSV** so Excel doesn't reformat it.
2. Click the filter dropdown on a yes/no column (for example `batteries_required`).
3. Compare the listed values with the Valid Values tab. Anything else is a problem, as is a blank cell in a column the Data Definitions tab marks as required.

### Helper column formula

Add a column next to the field and list the accepted values in the formula. For a true/false column:

```
=IF(OR(LOWER(A2)="true", LOWER(A2)="false", A2=""), "OK", "INVALID: "&A2)
```

For the Inventory Loader's `will-ship-internationally`, check for `y`, `n`, `1` and `2` instead. Filter for rows showing `INVALID` to find every problem value.

## Fixing Invalid Values in Bulk

### Find and replace in Excel

1. Press **Ctrl+H** (Find & Replace).
2. In **Find what**, enter the wrong value, for example `Yes`.
3. In **Replace with**, enter the value from the Valid Values tab, for example `true`.
4. Click **Options** and tick **Match entire cell contents**, so only whole cells change.
5. Click **Replace All**, then repeat for `No` and any other spelling you found.

> **Important:** decide what each value means before replacing. A `Yes` in `batteries_required` and a `Yes` in another column may need different replacements.

### Replace formula results with values

If your yes/no columns are computed by formulas:

1. Select the column and copy it (**Ctrl+C**).
2. Right-click → **Paste Special → Values**.
3. The formulas become plain text, which you can then fix with Find & Replace.

### Google Sheets

1. Select the column.
2. **Edit → Find and replace** (Ctrl+H).
3. Tick **Match case** and **Match entire cell contents**, search for the wrong value and replace it with the accepted one.

## Preventing Problems Next Time

### Use the template's own dropdowns

Amazon's category templates come with dropdowns built from the Valid Values tab. Enter data in the template itself instead of pasting a CSV over it, and the dropdowns keep values on the list.

### Add your own dropdown

For a file without dropdowns, select the column cells below the header, go to **Data → Data Validation**, choose **List**, and enter the accepted values, for example `true,false` (or `y,n,1,2` for `will-ship-internationally`).

### Check before every upload

1. Open the final file in a text editor (not Excel) and scan the yes/no columns.
2. Confirm every value is on the list for that column.
3. Fill in any column the Data Definitions tab marks as required.
