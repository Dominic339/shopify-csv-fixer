## How eBay Checks a Bulk Upload

eBay's bulk listing uploads now go through **Seller Hub → Reports → Uploads**, which takes the File Exchange-style CSV templates you download from the same page. When you upload a file, eBay checks:

1. **The file layout**: the INFO line at the top and the header row below it
2. **The Action column**: what to do with each listing row
3. **Data types**: prices as numbers, quantities as whole numbers, URLs as full web addresses
4. **Business rules**: valid category IDs, condition IDs allowed in that category, valid durations
5. **Content rules**: title length and listing policies

After processing, the upload's results file is available on the Uploads page. It lists which rows succeeded and which failed, and why. Always check it, because eBay often imports some rows while rejecting others.

## Error: Template Not Recognised (the INFO Line)

eBay's current templates start with a line like this, above the column headers:

```
#INFO,Version=1.0.0,Template=fx_category_template_EBAY_US
```

eBay needs that first INFO line when you upload. Other lines starting with `#INFO` or `INFO` (instructions in the template) can stay or go.

**Fix:**
- Don't delete the first line of the template, even though it looks like a note.
- If you use Excel on a Mac, check that nothing appears in front of `#INFO` on the first line. Excel can add invisible characters there, and eBay then rejects the file. Open the CSV in a text editor to see them.

## Error: Missing or Invalid Action Value

Every listing row needs an Action. The exception is variation rows (`Relationship` = `Variation`), which sit under their parent listing and leave Action blank.

Accepted values:

| Value | Meaning |
|---|---|
| `Add` | Create a new listing |
| `VerifyAdd` | Check a new listing and see its fees without posting it |
| `Revise` | Change fields on an active listing |
| `Relist` | Relist an ended listing |
| `End` | End an active listing (give an `EndCode` too) |
| `Status` | Change a sold item's status, such as marking it shipped |
| `AddToItemDescription` | Add text to the end of an active listing's description |
| `Draft` | Save a listing to your Drafts (drafts template only) |

**Fix:** Every listing row must use one of the values above, spelled exactly. eBay matches these exactly, so `verifyadd` is not the same as `VerifyAdd`.

## Error: Invalid Category

**Cause:** The `Category` (or `Category ID`) value is not a valid numeric eBay category ID, or the category has been retired.

eBay category IDs are numbers (for example, `15687` for Men's T-Shirts on eBay US). They change from time to time as eBay restructures its categories.

**Fix:**
- Look up the correct category ID in eBay's category tree
- Don't copy category IDs from old templates without checking that they're still active
- Some categories require extra item specifics, so check what the category needs

See [eBay CategoryID: what it is and how to set it](/guides/ebay/categoryid-and-file-exchange) for ways to find IDs.

## Error: Title Too Long

**Cause:** The `Title` value is longer than 80 characters, eBay's limit for listing titles.

**Fix:**

In Excel, add a helper column: `=LEN(B2)` (replace B2 with your Title column cell). Filter to rows where the length is over 80 and shorten those titles.

In Python:

```python
import csv

with open("input.csv", newline="", encoding="utf-8") as f:
    reader = csv.DictReader(f)
    for i, row in enumerate(reader, 2):
        title_len = len(row.get("Title", ""))
        if title_len > 80:
            print(f"Row {i}: Title is {title_len} chars (max 80): {row['Title'][:60]}...")
```

## Error: Invalid Condition ID

**Cause:** The `ConditionID` value is not a valid eBay condition ID, or it isn't allowed in the item's category.

Common condition IDs from eBay's condition table:

| ID | Condition | Notes |
|---|---|---|
| `1000` | New | Also shown as Brand New, New with tags or New with box |
| `1500` | New other | New without tags or box, open box |
| `1750` | New with defects | |
| `2000` | Certified Refurbished | Only for approved sellers in some categories |
| `2500` | Seller refurbished | Replaced by the refurbished grades below in some categories |
| `2010` / `2020` / `2030` | Excellent / Very Good / Good - Refurbished | Only for approved sellers in some categories |
| `2750` | Like New | |
| `3000` | Used | Also shown as Pre-owned |
| `4000` | Very Good | |
| `5000` | Good | |
| `6000` | Acceptable | |
| `7000` | For parts or not working | Only in categories where it makes sense |

Which IDs you can use depends on the category, and the names shown to buyers vary by category too.

## Error: Invalid StartPrice

**Cause:** The `StartPrice` field contains a currency symbol (`$9.99`), uses a comma decimal separator (`9,99`), is negative, or is blank.

**Fix:**
- Remove currency symbols with Find & Replace
- Replace comma decimal separators with periods
- Make sure every price is a positive decimal number
- Format the column as Number in Excel before saving

---

## Error: Invalid Duration

**Cause:** The `Duration` field contains a value eBay doesn't accept for the listing format.

**Accepted values:**

| Format | Duration |
|---|---|
| `FixedPrice` | `GTC` (Good 'Til Cancelled). Fixed-price listings no longer take a set number of days |
| `Auction` | `Days_1`, `Days_3`, `Days_5`, `Days_7` or `Days_10` |

**Fix:** Use `GTC` for fixed-price listings and one of the `Days_` values for auctions.

## Error: Picture URL Not Accessible

**Cause:** The `PicURL` field contains a URL eBay can't download: the image is behind a login, on your own computer, or behind a redirect.

eBay's Seller Hub Reports take up to **24 pictures** per listing in `PicURL`, separated by a pipe character `|`. Each URL can be up to 2048 characters, and spaces in a URL must be written as `%20`.

**Fix:**
- Open each URL in a private browser window. It should show the image directly, with no login
- Use full `https://` URLs
- Replace spaces with `%20` (StriveFormats does this for you)
- Avoid URL shorteners and redirect services

## Error: Item Number or UPC Shows as 1.23457E+11

**Cause:** Excel turned a long number (an `ItemID` or a `P:UPC` barcode) into scientific notation. The digits after the first few are gone, so eBay can't find the listing or match the product.

**Fix:** Re-enter the full numbers from your records. eBay's help suggests formatting item number columns as Number with 0 decimal places before saving. Formatting the column as Text also works. StriveFormats flags every cell where this has happened.

---

## Error: Invalid Quantity

**Cause:** `Quantity` is blank, has a decimal (for example `1.5`), or is negative.

**Fix:** Use whole numbers. New listings should have a quantity of at least 1. For variation listings, put each variation's quantity on its own row, not on the parent row.

## Test Before You Upload Everything

1. Copy 2 or 3 rows into a new file, keeping the INFO line and the header row.
2. Change their Action to `VerifyAdd` and upload. eBay checks the rows and shows the fees without posting anything.
3. Fix whatever the results file reports, then switch the Action back to `Add` for the full file.
